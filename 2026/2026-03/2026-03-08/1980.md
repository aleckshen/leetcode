For this question given the constraint `1 <= n <= 16` we can brute force and generate all possible string combinations of length `n`. We will do this with a recursive function `combinations` and check each generated string if its in `nums` or not. If it is we will return it, otherwise we will continue to check different combinations.

```python
class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        n = len(nums)
        s = set(nums)

        def combinations(i: int, curr: str):
            if i == n:
                if curr not in s:
                    return curr
                return None

            res = combinations(i + 1, curr + "0")
            if res:
                return res

            return combinations(i + 1, curr + "1")

        return combinations(0, "")
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n^2)`
