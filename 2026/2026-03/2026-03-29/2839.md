Looking at the constraints we know that `s1` and `s2` will always be of size `4`. Knowing this we can check the two pairs of string in `s1` and `s2` at index `0` and `0 + 2` and index `1` and `1 + 2`. If the current strings are equal in both `s1` and `s2` or we can switch them to both be equal then we can continue, otherwise we will return false.

```python
class Solution:
    def canBeEqual(self, s1: str, s2: str) -> bool:
        for i in range(2):
            if not (s1[i] == s2[i] and s1[i + 2] == s2[i + 2] or
                    s1[i] == s2[i + 2] and s1[i + 2] == s2[i]):
                    return False
        return True
```

> Time Complexity : `O(1)`
> 
> Space Complexity : `O(1)`
