We can recursively generate all possible combinations of happy strings. This will be stored in an array `happy`, once we've finished generating all combinations we can check if index `k` is in bounds. If it isn't we will return `""`, otherwise, we will sort `happy` and return the `k`the string (one indexed).

```python
class Solution:
    def getHappyString(self, n: int, k: int) -> str:
        happy = []

        def combs(curr):
            if len(curr) == n:
                happy.append(curr)
                return

            if curr[-1] == 'a':
                combs(curr + 'b')
                combs(curr + 'c')
            elif curr[-1] == 'b':
                combs(curr + 'a')
                combs(curr + 'c')
            else:
                combs(curr + 'a')
                combs(curr + 'b')

        combs('a')
        combs('b')
        combs('c')

        if k <= len(happy):
            return sorted(happy)[k - 1]
        return ""
```

> Time Complexity : `O(2^n * n)`
> 
> Space Complexity : `O(2^n * n)`
