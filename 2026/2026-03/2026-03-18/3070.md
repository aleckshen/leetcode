For this question we will calculate each sub matrix using a prefix array. We will set the prefix array to be the length of the columns, you could implement this either way with the prefix array length being set to rows or columns. We will iterate through each cell in the input grid and keep a running sum of the current total, we will also increment the current total at index `c` representing the column index to prefix array. This will ensure that the column keeps a accurate sum of the current column values encountered in each column, we will then add this prefix column sum to the running total sum. If the total is lesser than or equal to `k` then we will count a valid sub matrix, otherwise we will continue iterating. At the end we can return `count` representing the number of valid sub matrices.

```python
class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        ROWS = len(grid)
        COLS = len(grid[0])
        prefix = [0] * COLS
        count = 0
        
        for r in range(ROWS):
            total = 0
            for c in range(COLS):
                prefix[c] += grid[r][c]
                total += prefix[c]
                if total <= k:
                    count += 1

        return count
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(n)`
