For this question we can start by iterating through the input grid and calculate the total sum. For the splits we can calculate them horizontally and vertically. To start with horizontal splits we will iterate through the input grid row by row, at each point we will remove the current sum in the row from a temporary total sum variable `split` and add the current sum in the row to a variable named `curr` initialized to 0. If at any point `split` is equal to `curr` then we have found a valid split and return `True`. We can do the same for vertical splits. If none of these return `True`, then we will return `False`.

```python
class Solution:
    def canPartitionGrid(self, grid: List[List[int]]) -> bool:
        total = 0  
        for row in grid:
            total += sum(row)

        #horizontal
        split = total
        curr = 0
        for row in grid:
            rowSum = sum(row)
            split -= rowSum
            curr += rowSum
            if split == curr:
                return True

        #vertical
        split = total
        curr = 0
        for c in range(len(grid[0])):
            colSum = 0
            for r in range(len(grid)):
                colSum += grid[r][c]
            split -= colSum
            curr += colSum
            if split == curr:
                return True

        return False
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(1)`
