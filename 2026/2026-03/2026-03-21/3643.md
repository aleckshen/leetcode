For this question we will iterate through the matrix from column index `y`. We will iterate through the input matrix `x + k // 2` times where at each point we will store the current top row to swap in an array `top` and the current bottom row to swap in an array `bottom`. We will then iterate through the current top row in reverse and pop from the array `bottom`, this will insert the bottom row to the top one. We will also do the same for the bottom row. Once we finish iterating through the input matrix `x + k // 2` times we can return the input matrix `grid`.

```python
class Solution:
    def reverseSubmatrix(self, grid: List[List[int]], x: int, y: int, k: int) -> List[List[int]]:
        for r in range(x, x + k // 2):
            top = grid[r][y:y + k]
            bottom = grid[2 * x + k - 1 - r][y:y + k]

            for i in range(len(top) - 1, -1, -1):
                grid[r][y + i] = bottom.pop()

            for j in range(len(top) - 1, -1, -1):
                grid[2 * x + k - 1 - r][y + j] = top.pop()

        return grid
```

> Time Complexity : `O(k^2)`
> 
> Space Complexity : `O(k)`
