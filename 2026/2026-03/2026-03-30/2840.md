Lowkey realised I could do this by conting the frequency of letters instead oops.

```python
class Solution:
    def checkStrings(self, s1: str, s2: str) -> bool:
        even, odd = [], []
        for i in range(len(s1)):
            if i % 2 == 0:
                even.append(s1[i])
            else:
                odd.append(s1[i])

        even1, odd1, = [], []
        for i in range(len(s2)):
            if i % 2 == 0:
                even1.append(s2[i])
            else:
                odd1.append(s2[i])

        return sorted(even) == sorted(even1) and sorted(odd) == sorted(odd1)
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(n)`
