For this question we can convert the input integer to binary. We can then iterate through the binary string and flip the input bits onto a new string `res`.

```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        binary = bin(n)[2:]

        res = ""
        for bit in binary:
            if bit =='0':
                res += '1'
            else:
                res += '0'

        return int(res, 2)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
