This solution is a brute force approach where we will construct string `Si` with `n` steps. We will first initialize `s` to be `'0'`. At each step we will store the current `s` in a variable `prev`, then we will concatenate `'1'` to `s`. For the invert and reverse step we will use a temporary variable `temp` and iterate through the bits in `prev` to invert it. Then we will concatenate the reversed string of `temp` to `s`. Once we complete this step `n` times we will have constructed the string `Si` and we can return the `k`th bit.

```python
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        s = "0"
        for i in range(n):
            prev = s
            s += "1"

            temp = ""
            for bit in prev:
                if bit == "0":
                    temp += "1"
                else:
                    temp += "0"

            s += temp[::-1]

        return s[k - 1]
```

> Time Complexity : `O(2^n)`
> 
> Space Complexity : `O(2^n)`
