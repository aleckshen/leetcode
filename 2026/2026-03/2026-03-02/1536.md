For this question we want to find the minimum swaps to arrange a binary grid to be valid. First we need to check whether a grid is valid or not. To do this we can iterate through each row in the input grid and store the right most `1`. We can then sort the array storing the right most `1`'s. Given the sorted array of size `n` if we ennumerate through the list and each value is lesser than or equal to the index we are currently on then the grid can be swapped to be valid. If this condition is ever false we will return `-1`.

We can start to simulate the number of swaps required after verifying that the input grid can be swapped to be valid. We will essentially use insertion sort and count the number of swaps until the list of right most `1`'s are sorted. We can return the number of swaps which will represent the minimum swaps to arrange a binary grid to be valid.

```python
class Solution:
    def minSwaps(self, grid: List[List[int]]) -> int:
        rightMost = []

        for row in grid:
            right = -1
            for i in range(len(row)):
                if row[i] == 1:
                    right = i
            rightMost.append(right)
        
        sortedRight = sorted(rightMost)
        for i in range(len(sortedRight)):
            if sortedRight[i] > i:
                return -1

        swaps = 0
        for i in range(len(rightMost)):
            j = i
            while j < len(rightMost) and rightMost[j] > i:
                j += 1

            while j > i:
                rightMost[j], rightMost[j - 1] = rightMost[j - 1], rightMost[j]
                swaps += 1
                j -= 1

        return swaps
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n)`
