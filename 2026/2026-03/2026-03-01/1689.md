For this question we first notice that if we have a single number input then the minimum number of positive deci-binary numbers required to sum up to `n` will be `n` itself since we can only use `1`. If we were to extend this digit then we could start by calculating each digit individually from the right and merge with the digit to the left. Given two digits we have the available values `10` and `11`, we can then notice that the maximum value of a individual number in the input string would result in the answer. This is true given `n` digits aswell.

We can loop through the input string and take the maximum value of each individual number and return it as the result.

```python
class Solution:
    def minPartitions(self, n: str) -> int:
        res = -inf

        for num in n:
            res = max(int(num), res)

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
