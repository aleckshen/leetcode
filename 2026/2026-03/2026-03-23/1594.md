For my approach of the question I first built a 2D dp array with a each value being a list representing the minimum and maximum value at the current point in the grid. I first set the values for the top most row and left most column of the dp array, this was done by first setting the top left value of the dp array to the top left value of the grid (both min and max are the same here). Then we can set the values to be current value in the grid mulitplied by the previous value in the dp array, this is only possible for the top most row and left most column as there is only one path possible (only go right for top row, and only go down for left column). 

After doing this we can traverse the dp array (skipping the top most row and left most column) and calculate the smallest and largest value possibble at the current point. This is done by looking at the current value we are on in the input grid. If the value is lesser then or eqaul to zero, then we would achieve the smallest value by multiplying by the largest number, and we would find the largest value by multiplying by the smallest value. If the value we are on in the input grid is greater then zero then we calculate the smallest and largest values the opposite way.

After traversing through the input grid and setting the dp array we can check the bottom right most value. The largest value here will represent the biggest number we can achieve through traversing the  graph only by moving rightwards and downwards. If the value is greater then or equal to zero we will return it, otherwise we will return `-1`.

```python
class Solution:
    def maxProductPath(self, grid: List[List[int]]) -> int:
        MOD = 10**9 + 7 
        ROWS = len(grid)
        COLS = len(grid[0])
        dp = [[[0, 0] for _ in range(COLS)] for _ in range(ROWS)] # min max pairs

        dp[0][0][0], dp[0][0][1] = grid[0][0], grid[0][0]
        for c in range(1, COLS):
            dp[0][c][0], dp[0][c][1] = dp[0][c - 1][0] * grid[0][c], dp[0][c - 1][0] * grid[0][c]
        for r in range(1, ROWS):
            dp[r][0][0], dp[r][0][1] = dp[r - 1][0][0] * grid[r][0], dp[r - 1][0][0] * grid[r][0]

        for r in range(1, ROWS):
            for c in range(1, COLS):
                curr = grid[r][c]
                if curr <= 0:
                    small = curr * max( max(dp[r][c - 1]), max(dp[r - 1][c]) )
                    large = curr * min( min(dp[r][c - 1]), min(dp[r - 1][c]) )
                else:
                    small = curr * min( min(dp[r][c - 1]), min(dp[r - 1][c]) )
                    large = curr * max( max(dp[r][c - 1]), max(dp[r - 1][c]) )

                dp[r][c][0] = small
                dp[r][c][1] = large
        
        if max(dp[-1][-1]) >= 0:
            return max(dp[-1][-1]) % MOD
        return -1
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
