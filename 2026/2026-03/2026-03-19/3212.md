This question is pretty similar to yesterdays daily, we will also use a prefix array to store the cumaltive counts in each column. The prefix array will be two dimensional, storing frequency values of `x` and `y`, this will be set to the length of the columns. We will keep a running `x` and `y` frequency count for each row we iterate through, at each cell we encounter, we will check if the current value is `x` or `y`. If the current value is `x` we will increment the cumalitive `x` frequency sum of the current column we are on by 1, if the current value is `y` we will do the same for the `y` frequency sum (if the value is `.` we will ignore). At each point we will check if the running `x` frequency count is greater 0 and if the cumalitive `x` and `y` frequency counts are equal, if this is true we will count a valid sub matrix. After iterating through the input grid we can return the number of valid sub matrices found.

```python
class Solution:
    def numberOfSubmatrices(self, grid: List[List[str]]) -> int:
        ROWS = len(grid) 
        COLS = len(grid[0])
        pre = [[0, 0] for _ in range(COLS)] # [x freq, y freq]
        count = 0

        for r in range(ROWS):
            xcount = 0
            ycount = 0
            for c in range(COLS):
                if grid[r][c] == "X":
                    pre[c][0] += 1
                if grid[r][c] == 'Y':
                    pre[c][1] += 1

                xcount += pre[c][0]
                ycount += pre[c][1]

                if xcount > 0 and xcount == ycount:
                    count += 1

        return count
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(m)`
