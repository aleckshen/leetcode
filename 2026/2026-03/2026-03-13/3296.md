This solution uses binary search to find the minimum time needed to remove the mountain. Instead of simulating each layer removal, we guess a time `T` and check whether all workers together can remove at least `mountainHeight` layers within that time. For each worker, the time to remove layers increases (`w, 2w, 3w, ...`), so the total time for `k` layers follows a triangular pattern. Using a formula, we calculate how many layers each worker could remove within time `T`, add these up, and check if the total reaches the mountain height. If they can finish within `T`, we try a smaller time, otherwise, we try a larger time. Binary search continues until we find the smallest time that allows the workers to remove the entire mountain.

```python
class Solution:
    def minNumberOfSeconds(self, mountainHeight: int, workerTimes: List[int]) -> int:
        def can_finish(T):
            total = 0
            for w in workerTimes:
                k = int((math.sqrt(1 + 8*T/w) - 1) // 2)
                total += k
            return total >= mountainHeight

        left, right = 0, 10**18

        while left < right:
            mid = (left + right) // 2
            if can_finish(mid):
                right = mid
            else:
                left = mid + 1

        return left
```

> Time Complexity : `O(n * log T)`
> 
> Space Complexity : `O(1)`
