For this question we have two possible combinations of a alternating binary strings. We can either have the alternaring binarty string starting with bit `0` or we can have an alternating binary string starting with bit `1`. Given these two possile combinations, we can iterate through the input string `s` and take the minimum difference between these two combinations.

```python
class Solution:
    def minOperations(self, s: str) -> int:
        startZero = "0"
        startOne = "1"

        while len(startZero) < len(s):
            if len(startZero) % 2 == 0:
                startZero += "0"
                startOne += "1"
            else:
                startZero += "1"
                startOne += "0"

        diffZero = 0
        diffOne = 0
        for i in range(len(s)):
            if s[i] != startZero[i]:
                diffZero += 1
            if s[i] != startOne[i]:
                diffOne += 1

        return min(diffZero, diffOne)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
