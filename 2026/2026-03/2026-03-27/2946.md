For this question we first create a deep copy of the input array. We will then perform the required shifts `k` times on the deep copy. After doing this we can return true if the deep copy is equal to the input array, otherwise we will return false.

```python
class Solution:
    def areSimilar(self, mat: List[List[int]], k: int) -> bool:
        temp = []
        for row in mat:
            tempRow = []
            for num in row:
                tempRow.append(num)
            temp.append(tempRow)

        for i in range(k):
            for r in range(len(mat)):
                if r % 2 == 0:
                    val = temp[r].pop(0)
                    temp[r].append(val)
                else:
                    val = temp[r].pop()
                    temp[r].insert(0, val)
        
        return temp == mat
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(n * m)`
