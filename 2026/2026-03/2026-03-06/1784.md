We can find the index of the right most `1` and the index of the left most `0`. If the position of the right most `1` is lesser than the position of the right most `0` then the binary string `s` has at most one segment of ones.

```python
class Solution:
    def checkOnesSegment(self, s: str) -> bool:
        zero, one = inf, 0
        for i in range(len(s)):
            if s[i] == '1':
                one = i

        for i in range(len(s) - 1, -1, -1):
            if s[i] == '0':
                zero = i

        return one < zero
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
