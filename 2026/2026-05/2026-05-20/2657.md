For this question we will iterate through both input lists and keep track of the current values iterated over in a window for one of the input lists. For the other input list we can store the values in a set for efficient look up. At each point we will sum over the values in the current window thats also in the set and append that to a results list at the current index `i`.

```python
class Solution:
    def findThePrefixCommonArray(self, A: List[int], B: List[int]) -> List[int]:
        box = set()
        window = []

        res = [0] * len(A)
        for i in range(len(A)):
            common = 0
            window.append(A[i])
            box.add(B[i])
            for num in window:
                if num in box:
                    common += 1
            res[i] = common

        return res
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n)`
