AFor this question we can recursively check all possible jumps from index `start` while keeping a hash set of the indicies we've traversed to avoid duplicate paths. At each points we will either jump backwards or forwards, if we reach an index out of bounds or in the hash set we will return false, if the value in the array at the current index we are on is equal to zero then we will return false. Otherwise we will add the index to the hash set and continue traversing forwards and backwards.

```python
class Solution:
    def canReach(self, arr: List[int], start: int) -> bool:
        def jump(i, seen):
            if i >= len(arr) or i < 0 or i in seen:
                return False
            if arr[i] == 0:
                return True
            seen.add(i)

            forward = jump(i + arr[i], seen)
            back = jump(i - arr[i], seen) 
            return forward or back

        return jump(start, set())
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
