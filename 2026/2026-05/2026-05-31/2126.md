Sort the asteroids and iterate through it from the lightest asteroid. Check if at each point the total mass is greater than or equal to the current asteroid, if it isn't return then we return false, otherwise we increment the total mass by the current asteroid and continue iterating. If we successfully iterate through the entire sorted list of asteroids then we can return true.

```python
class Solution:
    def asteroidsDestroyed(self, mass: int, asteroids: List[int]) -> bool:
        asteroids.sort() 
        for ast in asteroids:
            if mass < ast:
                return False
            mass += ast
        return True
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
