For each number we iterate through we can convert it to a string to iterate through each digit. We can append each digit of a number as an integer to a results array `res`.

```python
class Solution:
    def separateDigits(self, nums: List[int]) -> List[int]:
        res = []  
        for num in nums:
            for digit in str(num):
                res.append(int(digit))

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
