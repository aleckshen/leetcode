For this solution we have to first find the pivot point in the input array, we can find this by iterating through the input array and checking if the current number is lesser than the previous number. Once we have found the pivot point we can concatenate the start to the pivot point on top of the pivot point to the end of the array. If no pivot point is found we instantly return true as it is already sorted with no rotations. If the concatenated array representing the sorted array with zero rotations is non-decreasing then we return true, else we return false.

```python
class Solution:
    def check(self, nums: List[int]) -> bool:
        if len(nums) == 1 or len(nums) == 2:
            return True

        pivot = None
        for i in range(1, len(nums)):
            if nums[i] < nums[i - 1]:
                pivot = i

        if not pivot:
            return True
        nonRotated = nums[pivot:len(nums)] + nums[:pivot]

        for i in range(1, len(nonRotated)):
            if nonRotated[i] < nonRotated[i - 1]:
                return False
        return True
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
