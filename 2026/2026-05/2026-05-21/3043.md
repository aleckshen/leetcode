Build a hashset of all prefixes from `arr1`. We check all possible prefixes in `arr2` and check if they are in the hashset we created. For each common prefix we can compare the maximum length of the prefix string with a global variable `res`, and return it if at least one common prefix is found otherwise we return 0.

```python
class Solution:
    def longestCommonPrefix(self, arr1: List[int], arr2: List[int]) -> int:
        prefix = set() 
        res = -inf

        for num in arr1:
            string = str(num)
            for i in range(len(string)):
                prefix.add(string[:i + 1])

        for num in arr2:
            string = str(num)
            for i in range(len(string)):
                if string[:i + 1] in prefix:
                    res = max(res, len(string[:i + 1]))
                
        if res == -inf:
            return 0
        return res
```

> Time Complexity : `O((n + m) * l^2)`
> 
> Space Complexity : `O(n * l^2)`
