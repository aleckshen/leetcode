We can iterate through every number in `nums1`, if this number is lesser than the current running common minimum and is also in `nums2` then we can update the running common minimum value. If there are no common values we return `-1`.

```python
class Solution:
    def getCommon(self, nums1: List[int], nums2: List[int]) -> int:
        res = inf
        nums1 = set(nums1)
        nums2 = set(nums2)

        for num in nums1:
            if num < res and num in nums2:
                res = num

        if res == inf:
            return -1
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
