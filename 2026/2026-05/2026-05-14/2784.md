For this question we can just sort the input list and check if every element is consecutive from `1` to `n - 1`. We also need a final check to ensure that the `n`th element is the same as `n - 1`, if all these conditions are true then we have a good array and we can return true, else we return false.

```python
class Solution:
    def isGood(self, nums: List[int]) -> bool:
        nums.sort()  
        n = len(nums)
        
        for i in range(n):
            if i == n - 1 or i == n - 2:
                if nums[i] != n - 1:
                    return False
            elif i + 1 != nums[i]:
                return False
        return True
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(1)`
