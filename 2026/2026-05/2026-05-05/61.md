Since `k` can be large we can first find the length of the list and compute `k = k % n`. After this we will reduce `k` to a number of lesser than `n`, then we can simulate the rotations.

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def rotateRight(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        if not head:
            return None
        if not head.next:
            return head

        n = 0 
        temp = head
        while temp:
            n += 1
            temp = temp.next
        k = k % n

        while k > 0:
            k -= 1
            tail = None
            last = head

            while last.next:
                tail = last
                last = last.next
            last.next = head
            tail.next = None
            head = last
        
        return head
```

> Time Complexity : `O(n * k % n)`
> 
> Space Complexity : `O(1)`
