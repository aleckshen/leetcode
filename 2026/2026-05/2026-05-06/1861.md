For this problem I start by iterating through the the original grid row by row, tracking two things for each row: the number of stones between each pair of obstacles (stored in `groups`), and the column positions of the obstacles themselves (stored in `position`). Once I finishing iterating through the input grid, I construct the rotated result grid by first placing all obstacles in their correct rotated positions, then filling in the stones column by column. For each column in the result, I grab the corresponding group of stone counts and use a pointer `x` to fill stones from the bottom up, jumping past obstacles as I go.

```python
class Solution:
    def rotateTheBox(self, boxGrid: List[List[str]]) -> List[List[str]]:
        groups = defaultdict(list) # groups of stones in each row per obstacle
        position = defaultdict(list)

        stones = 0
        for r in range(len(boxGrid)):
            for i, obj in enumerate(boxGrid[r]):
                if obj == "#":
                    stones += 1
                if obj == "*":
                    position[r].append(i)
                    groups[r].append(stones)
                    stones = 0
            groups[r].append(stones)
            stones = 0

        res = [["." for _ in range(len(boxGrid))] for _ in range(len(boxGrid[0]))]
        for key in position:
            for obstacle in position[key]:
                res[obstacle][len(boxGrid) - 1 - key] = "*"

        for c in range(len(res[0])):
            currGroup = groups[len(res[0]) - 1 - c]
            x = len(res) - 1
            for group in currGroup[::-1]:
                while group > 0:
                    res[x][c] = "#"
                    group -= 1
                    x -= 1
                while x > 0 and res[x][c] != "*":
                    x -= 1
                x -= 1
        
        return res
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(n * m)`
