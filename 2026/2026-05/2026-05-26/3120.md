We create two hash sets, one for the letters that have been already been calculated and one for the input list to avoid duplicates calculations. We iterate through each word in the input list and count a special character if both the lowercase and uppercase of that character exists. To ensure we don't count multiple special characters for the same character we also add the letter we just calculated for in a hashset `seen`.

```python
class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        res = 0
        seen = set()
        word = set(word)

        for letter in word:
            if letter.lower() in seen:
                continue
            if letter.lower() in word and letter.upper() in word:
                res += 1
            seen.add(letter.lower())

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
