For this solution to work in O(log n) we will need to use a binary search approach. First we calculate the midpoint value in the array, if `target` is equal to this value we will return the mid points index. Otherwise we will check if the left most value is lesser than or equal to the midpoint value. If this is true then we know the left half of the array is sorted, if the target is within this range we will set `r` to `mid - 1`, otherwise we will search in the right region of the array. If the left most value is greater than the midpoint value then we know that the right half of the array is sorted. In this case if the target is within this range we will set `l` to `mid + 1`, otherwise we will search in the left region of the array. This will eventually allow us to reach the target value in O(log n) time, or return `-1` once the pointers overlap if `target` does not exist in the input array.

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        l, r = 0, len(nums) - 1

        while l <= r:
            mid = (l + r) // 2
            if nums[mid] == target:
                return mid
            
            if nums[l] <= nums[mid]:
                if nums[l] <= target < nums[mid]:
                    r = mid - 1
                else:
                    l = mid + 1
            else:
                if nums[r] >= target > nums[mid]:
                    l = mid + 1
                else:
                    r = mid - 1

        return -1
```

> Time Complexity : `O(log n)`
> 
> Space Complexity : `O(1)`
