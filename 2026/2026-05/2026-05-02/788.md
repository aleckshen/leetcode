For each number from `1` to `n` if we have a valid digit (a digit that rotates to a new number) and no invalid numbers (digits that rotate to invalid state) then we can count the number as a good number.

```python
class Solution:
    def rotatedDigits(self, n: int) -> int:
        res = 0 
        valid = {"2", "5", "6", "9"}
        invalid = {"3", "4", "7"}

        for i in range(1, n + 1):
            isValid = False
            for num in str(i):
                if num in valid:
                    isValid = True
                if num in invalid:
                    isValid = False
                    break
            if isValid:
                res += 1

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
