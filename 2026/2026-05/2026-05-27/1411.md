```python
class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        seen = set()
        valid = set()
        invalid = set()

        for letter in word[::-1]:
            if letter.islower() and letter.upper() in seen:
                valid.add(letter)
            elif letter.lower() in seen:
                invalid.add(letter.lower())
            
            seen.add(letter)

        res = 0
        for letter in valid:
            if letter not in invalid:
                res += 1
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
