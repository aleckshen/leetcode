```python
class Solution:
    def minElement(self, nums: List[int]) -> int:
        for i in range(len(nums)):
            replace = 0
            for digit in str(nums[i]):
                replace += int(digit)
            nums[i] = replace

        return min(nums)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
