We can solve this problem with dp. First initialize a `dp` array of length `n` with `-inf` representing unreachable indices, then set `dp[0] = 0` since we start there. For each index `i` from `1` to `n - 1`, check every previous index `j` where `j < i`, if `|nums[i] - nums[j]| <= target`, update `dp[i] = max(dp[i], dp[j] + 1)`. Finally, return `-1` if `dp[-1]` is still `-inf`, otherwise return `dp[-1]`.

```python
class Solution:
    def maximumJumps(self, nums: List[int], target: int) -> int:
        dp = [-inf] * len(nums)
        dp[0] = 0
        
        for i in range(1, len(nums)):
            for j in range(i):
                if -target <= nums[j] - nums[i] <= target:
                    dp[i] = max(dp[i], dp[j] + 1)

        return -1 if dp[-1] == -inf else dp[-1]
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n)`
