For this question we can simulate each possible combination by removing the left most character and appending it to the right of the text `n` times, where `n` represents the length of the input string `s`. If any of the combinations equal to `goal` we will return true, otherwise we will return false.

```python
class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        if len(s) == 1:
            return s == goal
            
        for i in range(len(s)):
            if s == goal:
                return True
            s = s[1:len(s)] + s[0]
        return False
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
