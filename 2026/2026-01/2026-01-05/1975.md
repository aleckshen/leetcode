If the number of negative values in the matrix are even then we can continue to flip adjacent pairs until all are positive. If this is the case then we can return the absolute value of every value in the matrix summed up. If the number of negative values including 0 are odd then we will return the absolute value of every value in the matrix summed up minus 2 times the smallest negative value when flipped.

```python
class Solution(object):
    def maxMatrixSum(self, matrix):
        absSum = 0
        numOfNegs = 0
        smallest = float('inf')

        for i in range(len(matrix)):
            for j in range(len(matrix)):
                absSum += abs(matrix[i][j])
                if matrix[i][j] <= 0:
                    numOfNegs += 1
                smallest = min(smallest, abs(matrix[i][j]))

        if numOfNegs % 2 == 0:
            return absSum
        return absSum - (smallest * 2)
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(1)`
