This is a bfs problem where we need to calculate the maximum sum et each level. Levels increase starting from level 1 being the root node. We will start by initializing two variables `maxLevel` and `maxSum`. While we iterate level by level we will have two local variables `currLevel` and `currSum`. At each level we will compare the current sum with the max sum, if the current sum is greater then the max sum then we will update the max sum to be the current sum and the max level to be the current level.

```python
class Solution(object):
    def maxLevelSum(self, root):
        q = collections.deque()
        q.append(root)
        maxLevel = 1
        maxSum = float('-inf')

        currLevel = 0
        while q:
            currLevel += 1
            currSum = 0
            for i in range(len(q)):
                node = q.popleft()
                if node:
                    if node.left:
                        q.append(node.left)
                    if node.right:
                        q.append(node.right)
                    currSum += node.val
            if currSum > maxSum:
                maxSum = currSum
                maxLevel = currLevel
            currSum = 0
            currSum = 0

        return maxLevel
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(m)`
