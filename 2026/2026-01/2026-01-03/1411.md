We know that every row we have 3 columns, there are two different types of row patterns where colors do not touch each other. `ABA` represents the row pattern `A-B-A` and `ABC` represents the row pattern `A-B-C`. We will start by initializing two dp arrays `dpA` and `dpB`, `dpA[i]` will represent the number of ways in which row `i` can create the pattern `ABA`, `dpB[i]` will represent the number of ways in which row `i` can create the pattern `ABC`. We will initialize both `dpA[1]` and `dpB[1]` to 6 as for both patterns there are initially 6 possible ways to create each pattern with the 3 different colors.

Now we iterate from each row `i` to `n`, at each step we can calculate the number of ways to create the pattern for `ABA` and `ABC`. For `dpA[i] if the previous row was `ABA` then the new `ABA` row can be placed in 3 possible ways for each `ABA`. If the previous row was `ABC` then the new `ABA` row can be placed in 2 possible ways for each `ABA`. For `dpB[i]` if the previous row was `ABA` then the new `ABC` can be placed in two possible ways and the same goes for if the previous row was `ABA`.

For each row we will make the following calculations for the number of possible patterns and at the end we will return `dpA[n] + dpB[n]` which gives us the total number of combinations for `n` rows of size 3.

```python
class Solution(object):
    def numOfWays(self, n):
        MOD = 10**9 + 7
        
        dpA = [0] * (n + 1) # dpA[i] = ways where row i is ABA
        dpB = [0] * (n + 1) # dpB[i] = ways where row i is ABC
        
        # Base case
        dpA[1] = 6
        dpB[1] = 6
        
        for i in range(2, n + 1):
            dpA[i] = (dpA[i-1] * 3 + dpB[i-1] * 2) % MOD
            dpB[i] = (dpA[i-1] * 2 + dpB[i-1] * 2) % MOD
        
        return (dpA[n] + dpB[n]) % MOD
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
