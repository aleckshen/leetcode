This is a 2D-DP problem. We will start by initializing a 2D dp array that is length of input array `(nums1 + 1) *
(nums2 + 1)`. At each step we will have 3 possible choices:
1. We can take both `nums1[i]` and `nums2[j]` increased with the previous largest sub sequence.
2. We can skip `nums1[i]`.
3. We can skip `nums2[j]`.

After calculating the three possible choices we will set `dp[i][j]` to be the maximum of these three choices. 
This means that at each step we will be taking the maximum possible choice at all times, if the previous choice
results in a negative sub sequence we can start from 0 which is what `max(0, dp[i + 1][j + 1]` will do.

```python
class Solution(object):
    def maxDotProduct(self, nums1, nums2):
        dp = [[float('-inf')] * (len(nums2) + 1) for _ in range(len(nums1) + 1)]

        for i in range(len(nums1) - 1, -1, -1):
            for j in range(len(nums2) -1, -1, -1):
                takeBoth = nums1[i] * nums2[j] + max(0, dp[i + 1][j + 1])
                skip1 = dp[i + 1][j]
                skip2 = dp[i][j + 1]
                dp[i][j] = max(takeBoth, skip1, skip2)

        return dp[0][0]
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
