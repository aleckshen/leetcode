Using hints from leetcode we are told to find the maximum common value in `hFences` and `vFences` with
fences `1` and `m` extended into `hFences` and fences `1` and `n` extended into `vFences`. First we will sort both
arrays then we will loop through `hFences` and add all the differences into a set `hDiffs`, we will then iterate through 
`vFences` and find the max common value.

If the max common value is zero then we have not found a valid common pair and we will return `-1`, otherwise we
will return the max common value squared.

```python
class Solution(object):
    def maximizeSquareArea(self, m, n, hFences, vFences):
        MOD = 10**9 + 7

        hFences.append(1)
        hFences.append(m)
        hFences.sort()

        hDiffs = set()
        for i in range(len(hFences)):
            for j in range(i):
                hDiffs.add(hFences[i] - hFences[j])

        vFences.append(1)
        vFences.append(n)
        vFences.sort()

        maxCommon = 0
        for i in range(len(vFences)):
            for j in range(i):
                diff = vFences[i] - vFences[j]
                if diff in hDiffs:
                    maxCommon = max(maxCommon, diff)

        if maxCommon == 0:
            return -1

        return (maxCommon * maxCommon) % MOD
```

> Time Complexity : `O(m * n + h^2 + v^2)`
> 
> Space Complexity : `O(h^2 + v^2)`
