Since the input list is already sorted in increasing order lexicographically when can just iterate through the input list and check if the current letters ascii value is greater than the target value. If this is ever true then we have found the minimum letter that is greater then the target, otherwise we will return the first letter in the input array.

```python
class Solution:
    def nextGreatestLetter(self, letters: List[str], target: str) -> str:
        for letter in letters:
            if ord(letter) > ord(target):
                return letter
        return letters[0]
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
