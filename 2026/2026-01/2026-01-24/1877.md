For this question we can minimize all the pairs by first sorting the list, once the list is sorted we can iterate through the list and take the first and last elements as minimal pairs. We will compare the pair sum with a global variable `maxSum` and return this at the end.

```python
class Solution(object):
    def minPairSum(self, nums):
        nums.sort()
        maxSum = float('-inf')
        for i in range(len(nums) // 2):
            maxSum = max(maxSum, (nums[i] + nums[len(nums) - 1 - i]))

        return maxSum
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(1)`
