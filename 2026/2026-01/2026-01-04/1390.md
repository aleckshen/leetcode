For this question we will iterate through all numbers in the input array `nums`, for each number we encounter we will check for how many divisors the number contains. If the number contains exactly 4 divisors then we will add the sum of the divisors to a result variable `res`. I first started by iterating from `1, (num // 2) + 1` for each number in `nums`, this way we would skip calculating redundant numbers pass `(num // 2) + 1` that would not be able to divide the number itself. 

```python
class Solution(object):
    def sumFourDivisors(self, nums):
        res = 0
        for num in nums:
            numDivisors = 0
            totalSum = 0
            for i in range(1, (num // 2) + 1):
                if num % i == 0:
                    numDivisors += 1
                    totalSum += i
            numDivisors += 1
            totalSum += num
            if numDivisors == 4:
                res += totalSum
            numDivisors = 0
            totalSUm = 0

        return res
```

However this solution still exceeded the time limit, to further optimize my solution I used the hint that divisors come in pairs. For example given the number 28, if 2 divides 28 then 28 // 2 also divides 28. If we check for divisors this way then we can iterate from `1, sqrt(num) + 1`, this will reduce the time complexity from O(n * m/2) to O(n * sqrt(m)). One other case we need to take into account is if two divisor pairs end up being the same. For example `i` and `num // i` end up being the same pair, if this is the case then we will only append one of the pairs.

```python
class Solution(object):
    def sumFourDivisors(self, nums):
        res = 0

        for num in nums:
            divisors = []

            for i in range(1, int(num**0.5) + 1):
                if num % i == 0:
                    divisors.append(i)
                    if i != (num // i):
                        divisors.append(num // i)

            if len(divisors) == 4:
                res += sum(divisors)

        return res
```

> Time Complexity : `O(n * sqrt(m))`
> 
> Space Complexity : `O(sqrt(m))`
