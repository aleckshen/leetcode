For this question we will initialize a result array `ans`, we will then iterate through every number in the input array. FOr each number we iterate through we will check for all numbers from `0` to `nums[i]` and check whether the questions condition is true. If the condition ever evaluates to true then we will append the number to `ans` and break out of the loop, otheriwse we will append `-1` to `ans`.

```python
class Solution(object):
    def minBitwiseArray(self, nums):
        ans = []
        for i in range(len(nums)):
            found = False
            for j in range(nums[i]):
                if j | (j + 1) == nums[i]:
                    ans.append(j)
                    found = True
                    break
            if not found:
                ans.append(-1)

        return ans
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(n)`
