We can sort the input list and iterate through it in windows of size `k`. We can take the last value of each window and minus it from the first value in each window to find each windows minimum difference. With each minimum difference we calculate we will compare it to a global variable `minDiff` and return this after iterating through the entire input array.

```python
class Solution(object):
    def minimumDifference(self, nums, k):
        if k == 1:
            return 0

        nums.sort()
        minDiff = float('inf')

        for i in range(len(nums) - k + 1):
            minDiff = min(minDiff, nums[i + k - 1] - nums[i])

        return minDiff
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(1)`
