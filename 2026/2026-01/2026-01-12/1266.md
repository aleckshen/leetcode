For this question we want to return the minimum time it takes to visit all coordinates in order on a 2D plane
given a input list `points` of coordinates. In one second we can either move horizontally once, vertically
once or vertically and horizontally once at the same time. Since we want the minimum time we should
first consider all movements that combine horizontal and vertical movements together.

The way I did this question was to take the difference between the `x` coordinates of the point we are 
traveling to and the difference between the `y` coordinates of the point we are traveling to. We can sum
these two values together to get the total difference. This represents the time it takes to travel from
the two points without diagonal movements. We can then take the minimum difference of these two values and
subtract it from the total difference, this will take into account diagonal movements and give us the 
minimum time it takes to travel from two points. We can then append this value to a global `time` variable
and return it in the end.

```python
class Solution(object):
    def minTimeToVisitAllPoints(self, points):
        time = 0

        for i in range(len(points) - 1):
            currX, currY = points[i]
            nextX, nextY = points[i + 1]

            xDiff = max(currX, nextX) - min(currX, nextX) 
            yDiff = max(currY, nextY) - min(currY, nextY)
            totalDiff = xDiff + yDiff
            
            time += totalDiff - min(xDiff, yDiff) 

        return time
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
