We are given a array of size `2 * n`, we know that `nums` contains `n + 1` elements and exactly one element in `nums` is repeated `n` times. If the element we are looking for is repeated `n` then the other elements of `nums` appear only once. Therefore we can iterate through `nums` and return the number that is repeated.

```python
class Solution(object):
    def repeatedNTimes(self, nums):
        seen = set()
        for num in nums:
            if num in seen:
                return num
            seen.add(num)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
