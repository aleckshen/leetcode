For this question we want to iterate through all possible sizes of squares in the input grid. Once the largest sqaure size has been estiablished we can iterate from a square size of two to the largest square size. This first for loop will represent the square size and the second for loop will represent the row index, the third and final for loop will represent the column index.

Each cell we iterate over will represent the top left corner of a square, we will then have a function named `isMagic` thatwill check whether or not the current square is a magic square. If it is then we will compare the current square size with the largest square size initially defined as 1. We can then return the largest square size once we have iterated through all cells in the grid for all possible square sizes.

```python
class Solution(object):
    def largestMagicSquare(self, grid):
        largest = 1
        ROWS = len(grid)
        COLS = len(grid[0])

        for size in range(2, min(ROWS, COLS) + 1):
            for r in range(ROWS - size + 1):
                for c in range(COLS - size + 1):
                    if self.isMagic(grid, r, c, size):
                        largest = max(largest, size)

        return largest

    def isMagic(self, grid, r, c, size):
        # Sum of the first row is the target
        target = sum(grid[r][c:c + size])
    
        # Check all rows
        for i in range(size):
            if sum(grid[r + i][c:c + size]) != target:
                return False
    
        # Check all columns
        for j in range(size):
            col_sum = 0
            for i in range(size):
                col_sum += grid[r + i][c + j]
            if col_sum != target:
                return False
    
        # Check main diagonal
        diag1 = 0
        for i in range(size):
            diag1 += grid[r + i][c + i]
        if diag1 != target:
            return False
    
        # Check anti-diagonal
        diag2 = 0
        for i in range(size):
            diag2 += grid[r + i][c + size - 1 - i]
        if diag2 != target:
            return False
    
        return True
```

> Time Complexity : `O(n^5)`
> 
> Space Complexity : `O(1)`
