For this question we need to find the minimum `y` coordinate value such that the area below this
`y` coordinate value is equal to the area above the `y` coordinate value. We can solve this problem using
binary search where we will first find the minimum `y` coordinate and the maximum `y` coordinate. We will 
iterate through the input list to find these two bounds whilst also calculating the total area of all the
squares in the input list.

We want to our loop to keep running as long as the difference between the two bounds are greater than 0.000001,
this will ensure that our answer is precise. While this loop runs we will calculate the mid point
by adding the lower and upper bounds together and dividing by 2. If the area below this mid point value is lesser
then the total area halved, then we need to increase our `y` coordinate upwards and we will set our minimum bound
to be the current mid point value. If the area below is greater then or equal to the total value halved then we 
need to decrease our `y` coordinate downwards and we will set our maximum bound to be the current mid point value.

At the end we can return the the lower bound `minY` which will represent the minimum `y` coordinate that splits
the total area of all squares in two.

```python
class Solution(object):
    def separateSquares(self, squares):
        minY = float('inf')
        maxY = float('-inf')
        totalArea = 0

        for x, y, l in squares:
            minY = min(minY, y)
            maxY = max(maxY, y + l)
            totalArea += (l * l)

        while (maxY - minY) > 1e-6:
            mid = (minY + maxY) / 2.0

            if self.areaBelow(squares, mid) < totalArea / 2.0:
                minY = mid
            else:
                maxY = mid

        return minY

    def areaBelow(self, squares, mid):
        area = 0

        for x, y, l in squares:
            if mid <= y:
                continue
            elif mid >= (y + l):
                area += (l * l)
            else:
                area += (mid - y) * l

        return area
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(1)`
