Using hint 1 we know that, if we know the sum of a subtree, the answer is `max( (total_sum - subtree_sum) * subtree_sum)` in each node. To find the sum for every subtree of our input tree we need to traverse through it depth first in post order. First we will create a global variable `self.maxProduct` and then create a local function `totalSum` to retrieve the total sum of the input tree. 

We will then traverse through the input tree depth first, at each point we will calculate the current sum of the subtree. We can find the max product of the current sub tree using the formula `max( (total_sum - subtree_sum) * subtree_sum)`, we will compare this with the global variable `maxProduct` for every sub tree in the input tree.

At the end we will return `maxProduct % MOD`.

```python
class Solution(object):
    def maxProduct(self, root):
        MOD = 10**9 + 7
        self.maxProduct = 0

        def totalSum(node):
            if not node:
                return 0
            return node.val + totalSum(node.left) + totalSum(node.right)

        total = totalSum(root)

        def dfs(node):
            if not node:
                return 0

            left = dfs(node.left)
            right = dfs(node.right)

            subSum = node.val + left + right
            self.maxProduct = max(self.maxProduct, (total - subSum) * subSum)

            return subSum

        dfs(root)
        return self.maxProduct % MOD
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(h)`
