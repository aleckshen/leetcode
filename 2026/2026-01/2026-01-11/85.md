This solution uses 2D-dp by treating each cell `(i, j)` containing `1` as the bottom-right 
corner of a possible rectangle. First it builds a width table where `width[i][j]` stores the number of 
consecutive 1's ending at column `j` in row `i`, computed by extending the width from the left. Then, for 
each such cell, it tries to extend the rectangle upward row by row `i` to `0`, keeping track of the 
minimum width seen so far because a rectangle spanning multiple rows can only be as wide as 
its narrowest row. For each possible height `(i - k + 1)` it computes the area `minWidth * height` and 
updates the global maximum, if the width ever becomes zero, it stops early since no further rectangle is 
possible. After processing all cells, the maximum area found is returned as the answer.

```python
class Solution(object):
    def maximalRectangle(self, matrix):
        ROWS, COLS = len(matrix), len(matrix[0])
        width = [[0] * COLS for _ in range(ROWS)]
        maxArea = 0

        for i in range(ROWS):
            for j in range(COLS):
                if matrix[i][j] == "1":
                    if j > 0:
                        width[i][j] = width[i][j - 1] + 1
                    else:
                        width[i][j] = 1

                    minWidth = width[i][j]
                    for k in range(i, -1, -1):
                        minWidth = min(minWidth, width[k][j])
                        if minWidth == 0:
                            break
                        area = minWidth * (i - k + 1)
                        maxArea = max(maxArea, area)

        return maxArea
```

> Time Complexity : `O(n^2 * m)`
> 
> Space Complexity : `O(n * m)`
