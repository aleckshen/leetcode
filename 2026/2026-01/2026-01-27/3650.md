For this question we have the option to reverse the direction of edges if we increase the weight by 2 times the current weight. We want to find the shortest path from node `0` to node `n - 1`, this is a pretty good indicator to use dijkstras algorithm. To be able to find all valid edges we need to create a adjacency list where we append all the possible edges from the input list and all edges reversed with the weights increase by two times.

After creating the adjacency list we can run dijkstras algorithm to find the minimum cost path to reach node `n - 1`.

```python
class Solution(object):
    def minCost(self, n, edges):
        g = [[] for _ in range(n)]
        for x, y, w in edges:
            g[x].append((y, w))
            g[y].append((x, 2 * w))

        dist = [float('inf')] * n
        visited = [False] * n
        dist[0] = 0
        heap = [(0, 0)]  

        while heap:
            cur_dist, x = heapq.heappop(heap)

            if x == n - 1:
                return cur_dist

            if visited[x]:
                continue
            visited[x] = True

            for y, w in g[x]:
                new_dist = cur_dist + w
                if new_dist < dist[y]:
                    dist[y] = new_dist
                    heapq.heappush(heap, (new_dist, y))

        return -1
```

> Time Complexity : `O(E * log V)`
> 
> Space Complexity : `O(V)`
