This is a dfs problem where we need to find the lowest common ancestor of all deepest nodes in the input
tree. We will recursively traverse through the input tree depth first, once we reach the bottom we will 
return from our base case:
- If the current node is null, then return `None` and depth of 0.

If the base case doesn't return false then we will check the following:
1. If the current nodes left depth is greater than the right depth, return left node with left depth + 1.
2. If the current nodes right depth is greater than the left depth, return the right node with right depth + 1.
3. If the current nodes left and right depth are equal then return the current node with left depth + 1.

We will call dfs on the root node and return the smallest subtree with the deepest node.

```python
class Solution(object):
    def subtreeWithAllDeepest(self, root):
        
        def dfs(node):
            if not node:
                return None, 0

            left, leftDepth = dfs(node.left)
            right, rightDepth = dfs(node.right)

            if leftDepth > rightDepth:
                return left, leftDepth + 1
            elif rightDepth > leftDepth:
                return right, rightDepth + 1
            else:
                return node, leftDepth + 1

        return dfs(root)[0]
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
