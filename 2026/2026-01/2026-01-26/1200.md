For this question we want to return the list of pairs containing the minimum absolute difference in ascending order. First we can sort the list, this will allow us to iterate through the list in pairs and find the minimum absolute differences. We will also initialize a list `pairs` which will be returned in the end and a global variable `minDiff` that will represent the minimum absolute difference. As we iterate through the list we will check two important conditions:
1. If the current difference of the pairs is eqaul to the current `minDiff` then we will append the pair to `pairs`.
2. If the current difference of the pairs is lesser than the current `minDiff` then we will reset the list `pairs` to be empty, and then append the new pair. We will also update our global variable `minDiff` to the new minimum difference.

Once we iterate through the sorted input list we can return the array `pairs`.

```python
class Solution(object):
    def minimumAbsDifference(self, arr):
        pairs = []
        minDiff = float('inf')

        arr.sort()
        for i in range(len(arr) - 1):
            diff = arr[i + 1] - arr[i]

            if diff == minDiff:
                pairs.append((arr[i], arr[i + 1]))
            elif diff < minDiff:
                pairs = [(arr[i], arr[i + 1])]
                minDiff = diff

        return pairs
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(n)`
