We can solve this problem using dynamic programming where at each step we store the minimum cost 
to make `s1[i:]` equal to `s2[j:]` at position `(i, j)`. We will first start by initializing a dp array
of size `len(s1) + 1` by size `len(s2) + 1`. We will then fill the base cases where if `s1` or `s2` were
to be empty then we would need to delete all characters to make the two strings equal.

For the logic of the problem we will loop through the dp table bottom up, we will encounter two cases:
1. If the string at `s1[i]` is equal to the string at `s2[j]` then we don't need to delete any characters,
we will then set `dp[i][j]` to be `dp[i + 1][j + 1]` which is the minimum cost in the previous state.
2. If the strings are not equal then we choose the deletion that results in the minimum total cost, this is
taken by setting `dp[i][j] = min(ord(s1[i]) + dp[i + 1][j], ord(s2[j]) + dp[i][j + 1])`.

Once we finishing looping through the dp array bottom up the value at `dp[0][0]` will represent the minimum
ascii delete sum for two strings.

```python
class Solution(object):
    def minimumDeleteSum(self, s1, s2):
        dp = [[0] * (len(s2) + 1) for _ in range(len(s1) + 1)]

        for i in range(len(s1) - 1, -1, -1):
            dp[i][len(s2)] = dp[i + 1][len(s2)] + ord(s1[i])
        
        for j in range(len(s2) - 1, -1, -1):
            dp[len(s1)][j] = dp[len(s1)][j + 1] + ord(s2[j])

        for i in range(len(s1) - 1, -1, -1):
            for j in range(len(s2) - 1, -1, -1):
                if s1[i] == s2[j]:
                    dp[i][j] = dp[i + 1][j + 1]
                else:
                    dp[i][j] = min(
                        ord(s1[i]) + dp[i + 1][j],
                        ord(s2[j]) + dp[i][j + 1]
                    )

        return dp[0][0]
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(n * m)`
