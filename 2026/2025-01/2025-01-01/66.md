For this question we iterate through each digit in the input array `digits`. We will concatenate to a empty string `num` the digit we are currently iterating over as a string. We can then revert the string to a integer and increment it by one. Then we can revert it back to a string and iterate over each digit as a string and append it to a array `res` as a integer. 


```python
class Solution(object):
    def plusOne(self, digits):
        num = ''
        for digit in digits:
            num += str(digit)

        res = []
        num = int(num) + 1
        for ch in str(num):
            res.append(int(ch))

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
