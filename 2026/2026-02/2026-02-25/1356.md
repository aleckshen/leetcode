For this question we iterate through each number in the input array in binary, for each number we will count the number of `1` bits it contains and store each number in a frequency hashmap where the key is the count of `1` bits and the value is the number in base 10. We can then sort the by the number of `1` bits to get a list of sorted keys to iterate through the hashmap. We can then iterate through the hashmap by the sorted keys and sort each array we iterate through. We will then append each number of each sorted array to a results array and return it.

```python
class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        freq = {} 

        for num in arr:
            count = bin(num)[2:].count('1')
            if count in freq:
                freq[count].append(num)
            else:
                freq[count] = [num]

        keys = sorted(list(freq))

        res = []
        for key in keys:
            for num in sorted(freq[key]):
                res.append(num)

        return res
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(n)`
