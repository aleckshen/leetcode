Run dfs on the input tree and return the depth/height of each node. At each node we can compare the left and right subtrees height to check whether the tree is balanced or not. If it isn't we will return false otherwise we will return true.

```python
class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        self.isBalanced = True

        def dfs(node):
            if not node:
                return 0

            left = dfs(node.left)
            right = dfs(node.right)

            if abs(left - right) > 1:
                self.isBalanced = False

            return 1 + max(left, right)

        dfs(root)
        return self.isBalanced
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(h)`
