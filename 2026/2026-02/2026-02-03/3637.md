For this question we need to find two indicies `p` and `q` where `0 < p < q < n − 1` that satisfy the requirements of a trionic array. We will first start by handling the edge case of arrays of size 3, arrays of size 3 cannot fulfill this requirement and we will instantly return false. We will then set two variables `p` and `q` to `None`. We will iterate through the input array and attempt to find indices `p` and `q` that will satisfy the condition for a trionic array.

This can we done with three for loops, one for each condition. If any of the conditions are not met we can instantly return false. If we have successfully iterated through all three for loops then we have satisfied all the conditions for a trionic array and we can return true.

```python
class Solution:
    def isTrionic(self, nums: List[int]) -> bool:
        if len(nums) == 3:
            return False

        p = None
        q = None

        for i in range(1, len(nums) - 2):
            if nums[i] > nums[i - 1]:
                p = i
            else:
                if not p:
                    return False
                break

        for i in range(p + 1, len(nums) - 1):
            if nums[i] < nums[i - 1]:
                q = i
            else:
                if not q:
                    return False
                break

        for i in range(q + 1, len(nums)):
            if nums[i] <= nums[i - 1]:
                return False

        return True
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
