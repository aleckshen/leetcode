For this question we can take a sliding window approach. We will iterate through the input array and set the index as the right pointer. We will also initialize a left pointer to zero that will increase if the condition `nums[rightPointer] > (k * nums[leftPointer])` is true. This will ensure that our window is always valid and when it becomes invalid then we will shift the necessary pointers. At each iteration of the right pointer shifting we will calculate the maximum length of the current window, once the loop terminates we will return the length of the array minus this maximum length window value to find the minimum removals to balance a array.

```python
class Solution:
    def minRemoval(self, nums: List[int], k: int) -> int:
        nums.sort()
        left = 0
        maxLen = 0

        for right in range(len(nums)):
            while nums[right] > k * nums[left]:
                left += 1
            maxLen = max(maxLen, right - left + 1)

        return len(nums) - maxLen
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(1)`
