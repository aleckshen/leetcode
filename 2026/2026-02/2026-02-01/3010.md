For this question we need to split our input array into three subarrays where the sum of the starting values will give us the minimum cost. We have to take the first value in the input array so we can focus on how we are going to split and find the next two minimum values. We can iterate through the input list from the third value to the end leaving the second value as a possible subarray. Once we find the minimum value we can store the index in a variable aswell.

The minimum number will represent the start of a subarray, to find our last subarray we will find the minimum number from the left of the current value and to the right of the current value. Once we find this last value we can sum the starting number of the input array with the two minimum values we have found to return the minimum cost.

```python
class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        minEndNum = float('inf')
        minEndNumIdx = 0

        for i in range(2, len(nums)):
            if nums[i] < minEndNum:
                minEndNum = nums[i]
                minEndNumIdx = i

        if minEndNumIdx == len(nums) - 1:
            minMidNum = min(nums[1:minEndNumIdx])
        else:
            minMidNum = min(min(nums[1:minEndNumIdx]), min(nums[minEndNumIdx + 1:]))

        return nums[0] + minMidNum + minEndNum
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
