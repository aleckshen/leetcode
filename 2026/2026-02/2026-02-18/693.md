For this question we can convert the input integer to binary, then we can iterate through the binary string bit by bit. We will check if the current but is equal to the next bit, if this is true then the number does not have alternating bits and we return false. If we iterate through the entire string then we have found a binary number with alternating bits and we can return true.

```python
class Solution:
    def hasAlternatingBits(self, n: int) -> bool:
        binary = bin(n)[2:]
        
        for i in range(len(binary) - 1):
            if binary[i] == binary[i + 1]:
                return False
        return True
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
