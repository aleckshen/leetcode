For this question we will convert the input integer to binary then reverse the bits. We will then append `0`'s to the end of the string while the length of the string is lesser than 32. Once we have appended all the zeros we can convert the binary string back to integer and return it.

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        n = bin(n)[2:][::-1]

        while len(n) < 32:
            n += '0'

        return int(n, 2)
```

> Time Complexity : `O(1)`
> 
> Space Complexity : `O(1)`
