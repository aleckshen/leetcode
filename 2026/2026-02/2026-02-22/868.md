For this question we want to look for the longest distance between any two adjacent `1`'s. We will first set the value `prev` to `None`, then iterate through the input integer in binary. When we encounter a `1` bit we will check if the value `prev` is `None`, if it is then we will set `prev` to the current index `i`. If `prev` is not `None` then we have found an adjacent pair of `1`'s and we can take the different between the current index and prev and compare that with a global longest distance value `res`. Once we iterate through the entire input string we can return the variable `res`.

```python
class Solution:
    def binaryGap(self, n: int) -> int:
        res = 0
        prev = None
        binary = bin(n)[2:]

        for i in range(len(binary)):
            if binary[i] == '1':
                if prev != None:
                    res = max(res, i - prev)
                prev = i

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
