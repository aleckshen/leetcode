For this question we have to look at the constraints of the problem. We know that `1 <= left <= right <= 10^6`, this question asks us to find the number of set bits in the range of `left` and `right` inclusive. Note that given these constraints `11111...` 19 times is lesser than `10^6`, the next prime number exceeds this number. Since this is the case we only need to check for prime numbers that are in the range of `0 - 19` inclusive, we can use a set for this. Then we can create a function that takes the number of `1`'s in a binary string and check ifs the number if prime. If this is true then we will append one to our result, at the end we will return the result which contains the number of set bits in binary representation.

```python
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        res = 0

        for i in range(left, right + 1):
            if self.isPrime(bin(i).count('1')):
                res += 1

        return res

    def isPrime(self, n: int) -> bool:
        prime = {2, 3, 5, 7, 11, 13, 17, 19}

        if n in prime:
            return True
        return False
```

> Time Complexity : `O(r - l)`
> 
> Space Complexity : `O(1)`
