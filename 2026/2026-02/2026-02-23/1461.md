First we can find all substrings of size `k` in the input string `s` and put them in a set. The number of all possible binary codes of size `k` is `2^k`, therefore we will return true if the length of the set is equal to `2^k`, otherwise we will return false.

```python
class Solution:
    def hasAllCodes(self, s: str, k: int) -> bool:
        substrings = set()

        for i in range(len(s) - k + 1):
            substrings.add(s[i:i + k])

        if len(substrings) == 2 ** k:
            return True
        return False
```

> Time Complexity : `O(n * k)`
> 
> Space Complexity : `O(n)`
