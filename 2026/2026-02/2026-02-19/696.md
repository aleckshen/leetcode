My initial approach was to check every even substring and check if the left half of the substring is consecutive and if the right half of the substring is consecutive. If this is true and the numbers are different, then it would coutn as a valid substring.

```python
class Solution:
    def countBinarySubstrings(self, s: str) -> int:
        res = 0 
        
        for size in range(2, len(s) + 1, 2):
            for i in range(len(s) - size + 1):
                substring = s[i:i + size]

                left = substring[:size // 2]
                right = substring[size // 2:]
                
                if (
                    len(set(left)) == 1 and
                    len(set(right)) == 1 and
                    left[0] != right[0]
                ):
                    res += 1

        return res
```

However this solution did TLE. To optimize our solution we can create a list that represents the groups of consecutive bits. For example `0001110` would give us `[3, 3, 1]`.After doing this we can iterate through every neighboring group, and take the minimum consecutive sequence and add the sum to our result value. This is because given the neighboring groups `[3, 3]` we can form 3 substrings `'01', '0011', '000111'`, this is true given any sized neighboring group. At the end we can return the result that stored each sum of minimum neighboring group sizes.

```python
class Solution:
    def countBinarySubstrings(self, s: str) -> int:
        groups = [1]
        for i in range(1, len(s)):
            if s[i-1] != s[i]:
                groups.append(1)
            else:
                groups[-1] += 1

        print(groups)

        ans = 0
        for i in range(1, len(groups)):
            ans += min(groups[i-1], groups[i])

        return ans
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
