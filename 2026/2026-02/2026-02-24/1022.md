For this question we will traverse all posible paths in the input tree, at each point we will keep track of a `curr` variable which represents the binary string summed on the current path. Once we reach a leaf node, we will convert our binary path sum to base 10 and appendd it to a global `res` variable.

```python
class Solution:
    def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
        res = 0 

        def dfs(curr, node):
            nonlocal res

            if not node.left and not node.right:
                res += int(curr, 2)
                return

            if node.left: 
                dfs(curr + str(node.left.val), node.left)
            if node.right:
                dfs(curr + str(node.right.val), node.right)
        
        dfs(str(root.val), root)
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
