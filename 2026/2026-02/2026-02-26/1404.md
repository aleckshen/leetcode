Convert input binary string to integer, then we can simulate the number of operations required. We know that it is guarenteed that you can always reach `1` for all test cases, so we can have a while loop that runs while the number is not eqaul to `1`. If the number is even we will divide by `2` and if the number is odd then we will increment by one. Each loop we will increment the number of steps by one and return the number of steps after the loop terminates.

```python
class Solution:
    def numSteps(self, s: str) -> int:
        steps = 0
        num = int(s, 2)
        
        while num != 1:
            steps += 1

            if num % 2  == 0:
                num = num // 2
            else:
                num += 1

        return steps
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
