For this question we will add the two binary numbers bit by bit from the least signifcant bit and append the result to a result string. We will have a variable `carry` that will take into account the carry over for addition of bits that overflow. At the end of adding every bit if we still have carry over then we will return the string with a `1` appended onto the most significant bit, otherwise we will return the current string.

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        res = ""
        if len(a) >= len(b):
            larger = a
            smaller = b
        else:
            larger = b
            smaller = a

        carry = 0
        for i in range(len(larger)):
            if i < len(smaller):
                total = int(larger[-1 - i]) + int(smaller[-1 - i]) + carry
            else: total = int(larger[-1 - i]) + carry

            if total == 3:
                res = "1" + res
                carry = 1
            elif total == 2:
                res = "0" + res
                carry = 1
            elif total == 1:
                res = "1" + res
                carry = 0
            else:
                res = "0" + res
                carry = 0

        if carry > 0:
            return "1" + res
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
