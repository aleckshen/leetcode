We can turn the current BST into a sorted array by performing a inorder traversal on the input BST. Once we have the sorted array we can recursively build the balanced BST. At each step we will take the middle point of the array and set that as the root, then we will attach the left and right tree nodes to be the midpoints of each respective subarray. Once the recursive call finishes we can return the root node.

```python
class Solution:
    def balanceBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        inorder = []

        def dfs(node):
            if not node:
                return None
            
            dfs(node.left)
            if node:
                inorder.append(node.val)
            dfs(node.right)

        def build(arr):
            if not arr:
                return None
                
            mid = len(arr) // 2
            root = TreeNode(arr[mid])
            root.left = build(arr[:mid])
            root.right = build(arr[mid+1:])
            return root

        dfs(root)
        return build(inorder)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
