This question is the same as the previous daily where we need to find the longest balanced sub string in a input string `s`. However in this case we only have to deal with the letters `a`, `b` and `c`, however the constraints are much tighter and if we were to implement yesterdays solution we would TLE. To solve this problem we can break it down into three sub problems and create functions to handle these sub problems. The first sub problem is to finds the longest running string of singular letters, for example `aaa`. This counts as a balanced substring and we will create a function `mono` to handle this. The next sub problem is to find the longest running string of two distinct letters, for example `ababab`. This counts as a balanced substring and we will create a function `duo` to handle this, also note that we will need to test for different combinations for this function. The last sub problem is find the longest running string of three distinct letters, for example `abcabc`. 

After defining these three functions we can return the maximum longest running substring between these three functions and return it.

```python
class Solution:
    def mono(self, s: str) -> int:
        if not s:
            return 0
        cnt = 1
        ans = 1
        for i in range(1, len(s)):
            if s[i] == s[i - 1]:
                cnt += 1
            else:
                cnt = 1
            ans = max(ans, cnt)
        return ans

    def duo(self, s: str, c1: str, c2: str) -> int:
        pos: Dict[int, int] = {0: -1}
        ans = 0
        delta = 0
        for i, ch in enumerate(s):
            if ch != c1 and ch != c2:
                pos.clear()
                pos[0] = i
                delta = 0
                continue

            if ch == c1:
                delta += 1
            else:
                delta -= 1

            if delta in pos:
                ans = max(ans, i - pos[delta])
            else:
                pos[delta] = i

        return ans

    def trio(self, s: str) -> int:
        cnt0 = cnt1 = cnt2 = 0  
        pos: Dict[Tuple[int, int], int] = {(0, 0): -1}
        ans = 0
        for i, ch in enumerate(s):
            if ch == 'a':
                cnt0 += 1
            elif ch == 'b':
                cnt1 += 1
            else:  
                cnt2 += 1

            key = (cnt1 - cnt0, cnt2 - cnt0)

            if key in pos:
                ans = max(ans, i - pos[key])
            else:
                pos[key] = i

        return ans

    def longestBalanced(self, s: str) -> int:
        return max(
            self.mono(s),
            self.duo(s, 'a', 'b'),
            self.duo(s, 'a', 'c'),
            self.duo(s, 'b', 'c'),
            self.trio(s),
        )
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
