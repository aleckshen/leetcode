A string is balanced if the all the `a`'s comes before any `b`, the problematic pattern is when we encounter `ba`'s. We can iterate through the input list and keep track of how many `b`'s we have seen, once we encounter a `a` then we have a conflict. When we encounter a `a` after a `b` we have two options, we can either delete all previous `b`'s before or we can delete the current `a` we are on. We want the cheaper current option. We can initialize two arrays, one will represent all the number `b`'s to the left and the other will represent the number of `a`'s to the right. At each step we will add together the number of `a`'s to the right and the number of `b`'s to the left, this will ensure the string is balanced. We will compute the cost at each step and take the minimum cost and return it.

```python
class Solution:
    def minimumDeletions(self, s: str) -> int:
        n = len(s)

        rightA = [0] * (n + 1)   
        for i in range(n - 1, -1, -1):
            rightA[i] = rightA[i + 1]
            if s[i] == 'a':
                rightA[i] += 1

        leftB = [0] * (n + 1)
        for i in range(n):
            leftB[i + 1] = leftB[i]
            if s[i] == 'b':
                leftB[i + 1] += 1

        res = inf
        for i in range(n + 1):
            res = min(res, leftB[i] + rightA[i])
        
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
