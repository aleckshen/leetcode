For this problem we can brute force it and calculate the number of distinct odd and evens for every sub array possible. We will use a hash map to ensure the number of evens and odds we calculate are distinct, at each possible subarray we will check if the number of distinct odds are equal to the number of distinct evens. If this is true then we can update our max length if the current size is greater then the global max length size.

```python
class Solution:
    def longestBalanced(self, nums: List[int]) -> int:
        length = 0

        for i in range(len(nums)):
            even = {}
            odd = {}

            for j in range(i, len(nums)):
                if nums[j] % 2 == 0:
                    even[nums[j]] = even.get(nums[j], 0) + 1
                else:
                    odd[nums[j]] = odd.get(nums[j], 0) + 1

                if len(odd) == len(even):
                    length = max(length, j - i + 1)
        
        return length
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n)`
