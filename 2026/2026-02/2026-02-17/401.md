For this question we will check all possible values of hours and minutes. For each possible two values we will count the number of `1`'s in each binary conversion. If the number of `1`'s in the two values added together is equal to `turnedOn` then we have found a valid time and we can append it to our results list.

```python
class Solution:
    def readBinaryWatch(self, turnedOn: int) -> List[str]:
        res = []
        for h in range(12):
            for m in range(60):
                ones = bin(h).count('1') + bin(m).count('1')
                if ones == turnedOn:
                    if m < 10:
                        res.append(f"{h}:0{m}")
                    else:
                        res.append(f"{h}:{m}")

        return res
```

> Time Complexity : `O(1)`
> 
> Space Complexity : `O(1)`
