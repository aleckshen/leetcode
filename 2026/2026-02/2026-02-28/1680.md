For this question we can concatenate all binary strings from `1 - n`. After we can convert the number to base 10 and modulo by `10^9 + 7` and return the result.

```python
class Solution:
    def concatenatedBinary(self, n: int) -> int:
        binary = "0b"
        MOD = 10 ** 9 + 7

        for i in range(1, n + 1):
            binary += bin(i)[2:]

        return int(binary, 2) % MOD
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(n * log n)`
