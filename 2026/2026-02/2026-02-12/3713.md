We can brute force this question and check for every possible substring if the number of distinct characters appear the same number of times. 

```python
class Solution:
    def longestBalanced(self, s: str) -> int:
        longest = 0

        for i in range(len(s)):
            distinct = {}
            for j in range(i, len(s)):
                distinct[s[j]] = distinct.get(s[j], 0) + 1
                num = distinct[s[j]]
                valid = True

                for value in distinct.values():
                    if num != value:
                        valid = False
                        break
                if valid:
                    longest = max(longest, sum(distinct.values()))

        return longest
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n)`
