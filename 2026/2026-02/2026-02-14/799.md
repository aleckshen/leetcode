For this problem we can keep track of the total amount of champagne that flows through a glass. For example if `poured = 10`, then the first glass will have a total flow-through of 10, then the two cups in the second row will each have a total flow-through of 4.5, and so on. In general, if a glass has flow-through `x`, then the the current cup at row `r` and cup `c` has `(x - 1.0) / 2.0` quantity of champagne. We can simulate the entire pour for 100 rows of glasses. A glass at `[r][c]` will have excess champagne flow towards `[r + 1][c]` and `[r + 1][c + 1]`.

```python
class Solution:
    def champagneTower(self, poured: int, query_row: int, query_glass: int) -> float:
        A = [[0] * k for k in range(1, 102)]
        A[0][0] = poured
        
        for r in range(query_row + 1):
            for c in range(r + 1):
                q = (A[r][c] - 1.0) / 2.0
                if q > 0:
                    A[r+1][c] += q
                    A[r+1][c+1] += q

        return min(1, A[query_row][query_glass])
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n^2)`
