For this question we can take a sliding window approach. Initially we set both pointers to `0` and increment the right pointer at each iteration. At each iteration we will also keep track of the frequencies of each letter the right pointer lands on, if the frequnecy of this letter exceeds `2` then we will shift our left pointer and decrement the frequency of the character the left pointer is on until the we have a valid window. At each point we will take the length of the window as the maximum length substring with at most two occurences. After our right pointer reaches the last letter in the input string we can return the max length substring value.

```python
class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        res = 1
        l = 0
        freq = {}

        for r in range(len(s)):
            freq[s[r]] = freq.get(s[r], 0) + 1

            while freq[s[r]] > 2:
                freq[s[l]] -= 1
                l += 1

            res = max(res, r - l + 1)

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
