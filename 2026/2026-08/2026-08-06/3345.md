Iterate from `n` to `n * 10 + 1` as we know that `n * 10` will contain at least one zero which will zero out the product. For each number in the loop we will check the product of each digit in the number and check if it's divisible by `t`, since this will return true at some point, we can return `i` as soon as the condition returns true indicating the smallest number.

```python
class Solution:
    def smallestNumber(self, n: int, t: int) -> int:
        for i in range(n, n * 10 + 1):
            temp = 1
            for digit in str(i):
                temp *= int(digit)
            if temp % t == 0:
                return i
```

> Time Complexity : `O(n * log n)`
>
> Space Complexity : `O(log n)`
