```python
class Solution:
    def minimumDeletions(self, nums: List[int]) -> int:
        max_num = max(nums)
        min_num = min(nums)
        max_index = 0
        min_index = 0
        n = len(nums)

        for i in range(n):
            if nums[i] == max_num:
                max_index = i
            if nums[i] == min_num:
                min_index = i

        min_index, max_index = min(min_index, max_index), max(min_index, max_index)

        # minus from left and right
        left_right = min_index + 1 + n - 1 - max_index + 1

        # minus left and left
        left_left = max_index + 1

        # minus right and right
        right_right = n - 1 - min_index + 1

        return min(left_right, left_left, right_right)
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
