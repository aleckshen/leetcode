For this question we can take a sliding window approach. We will start with both pointers at zero, at every point we will count the frequency of the character the right pointer is currently on and shift it to the right. If the frequency count of the current character the right pointer is on exceeds `k` we will shift our left pointer until it decrements the frequency below `k`. At every point we can record the max sub array length as the difference between the left and right pointers and compare that to a global variable `res` representing the length of the longest sub array.

```python
class Solution:
    def maxSubarrayLength(self, nums: List[int], k: int) -> int:
        res = 0
        freq = {}
        l = 0

        for r in range(len(nums)):
            freq[nums[r]] = freq.get(nums[r], 0) + 1

            while freq[nums[r]] > k:
                freq[nums[l]] -= 1
                l += 1

            res = max(res, r - l + 1)

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
