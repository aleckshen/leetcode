```python
class Solution:
    def shortestBeautifulSubstring(self, s: str, k: int) -> str:
        res = ""
        l = 0
        beautiful = 0

        for r in range(len(s)):
            if s[r] == "1":
                beautiful += 1

            while beautiful > k:
                if s[l] == "1":
                    beautiful -= 1
                l += 1

            while s[l] == "0" and l < len(s) - 1:
                l += 1

            if beautiful == k:
                if not res:
                    res = s[l:r + 1]
                elif len(s[l:r + 1]) < len(res):
                    res = s[l:r + 1]
                elif len(s[l:r + 1]) == len(res):
                    if s[l:r + 1] < res:
                        res = s[l:r + 1]

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
