We first find the longest sequential prefix sum in nums starting from index `0`. Given the prefix sum, we will check if it's in the input array `nums`, if it isn't we will return the sum, otherwise we will keep incrementing by 1 until we find a missing number and return.

```python
class Solution:
    def missingInteger(self, nums: List[int]) -> int:
        pre = nums[0]
        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1] + 1:
                pre += nums[i]
            else:
                break

        while pre in nums:
            pre += 1

        return pre
```

> Time Complexity : `O(n * k)`
>
> Space Complexity : `O(1)`
