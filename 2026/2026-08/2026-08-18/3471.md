For each window of size `k` we can iterate through all unique elements and record the frequency. After, we can return the maximum value that has a frequency of only `1`.

```python
class Solution:
    def largestInteger(self, nums: List[int], k: int) -> int:
        frequencies = {}
        for i in range(len(nums) - k + 1):
            unique = set(nums[i:i + k])
            for num in unique:
                frequencies[num] = frequencies.get(num, 0) + 1

        res = -1
        for num, freq in frequencies.items():
            if freq == 1:
                res = max(res, num)

        return res
```

> Time Complexity : `O(n * k)`
>
> Space Complexity : `O(n)`
