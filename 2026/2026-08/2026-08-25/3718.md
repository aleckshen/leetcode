```python
class Solution:
    def missingMultiple(self, nums: List[int], k: int) -> int:
        hs = set(nums)
        curr = k

        while True:
            if curr not in hs:
                return curr
            curr += k
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
