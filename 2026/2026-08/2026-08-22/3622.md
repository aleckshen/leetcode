```python
class Solution:
    def checkDivisibility(self, n: int) -> bool:
        dig_sum = 0
        dig_product = 1

        for digit in str(n):
            dig_sum += int(digit)
            dig_product *= int(digit)

        return n % (dig_sum + dig_product) == 0
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
