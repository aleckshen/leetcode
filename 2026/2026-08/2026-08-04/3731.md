We iterate from the minimum value in `nums` to the maximum value in `nums`, for each number we check if it exists within the input list, if it doesn't we append it to a result variable and return it after looping through all values.

```python
class Solution:
    def findMissingElements(self, nums: List[int]) -> List[int]:
        res = []

        for i in range(min(nums), max(nums)):
            if i not in nums:
                res.append(i)

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
