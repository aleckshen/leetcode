```python
class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        for i in range(len(nums)):
            nums[i] = abs(nums[i])
        nums.sort()

        res = 0
        l = 0
        r = len(nums) - 1
        while l <= r:
            if l == r:
                res += nums[r] ** 2
                r -= 1
            else:
                res += nums[r] ** 2
                res -= nums[l] ** 2
                l += 1
                r -= 1

        return res
```

> Time Complexity : `O(n * log n)`
>
> Space Complexity : `O(1)`
