```python
class Solution:
    def countIslands(self, grid: List[List[int]], k: int) -> int:
        # key ideas:
        # we run dfs on each cell in the grid which recurses
        # through all 4 directions up, down, left, right.
        # It will sum for all values in that islands and once
        # every cell has been visited we can check if the total
        # sum in that island is divisible by `k`

        def dfs(r, c):
            if (r < 0 or r >= ROWS or
                c < 0 or c >= COLS):
                return 0

            if not grid[r][c]:
                return 0

            total = grid[r][c]
            grid[r][c] = 0

            for x, y in dirs:
                total += dfs(r + x, c + y)

            return total

        ROWS = len(grid)
        COLS = len(grid[0])
        dirs = [(0, 1), (1, 0), (-1, 0), (0, -1)]
        res = 0

        for r in range(ROWS):
            for c in range(COLS):
                if grid[r][c] and dfs(r, c) % k == 0:
                    res += 1

        return res
```

> Time Complexity : `O(n * m)`
>
> Space Complexity : `O(n * m)`
