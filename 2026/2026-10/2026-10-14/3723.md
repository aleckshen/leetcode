```python
class Solution:
    def maxSumOfSquares(self, num: int, sum: int) -> str:
        res = []

        for i in range(num):
            if sum >= 9:
                res.append("9")
                sum -= 9
            else:
                if sum:
                    res.append(str(sum))
                    sum -= sum
                else:
                    res.append("0")

        return "" if sum else "".join(res)
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
