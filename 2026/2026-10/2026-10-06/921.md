```python
class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        left = 0
        right = 0

        for brac in s:
            if brac == "(":
                left += 1
            elif brac == ")":
                if left:
                    left -= 1
                else:
                    right += 1

        return left + right
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
