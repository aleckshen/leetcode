```python
class Solution:
    def removeOuterParentheses(self, s: str) -> str:
        res = []
        curr = []
        left = 0
        right = 0

        for brac in s:
            if brac == "(":
                left += 1
                curr.append("(")
            else:
                right += 1
                curr.append(")")

            if left == right:
                decomp = "".join(curr)
                res.append(decomp[1: len(decomp) - 1])

                left = 0
                right = 0
                curr = []

        return "".join(res)
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
