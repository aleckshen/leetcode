```python
class Solution:
    def targetIndices(self, nums: list[int], target: int) -> list[int]:
        res = []
        nums.sort()
        for i in range(len(nums)):
            if nums[i] == target:
                res.append(i)

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
