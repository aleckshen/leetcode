```python
class Solution:
    def createGrid(self, m: int, n: int) -> list[str]:
        grid = []
        for i in range(m):
            if i == 0:
                grid.append("." * n)
            else:
                row = "#" * (n - 1)
                grid.append(row + ".")

        return grid
```

> Time Complexity : `O(n * m)`
>
> Space Complexity : `O(n)`
