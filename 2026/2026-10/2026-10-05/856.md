```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        stack = [0]

        for brac in s:
            if brac == "(":
                score = 0
                stack.append(score)
            else:
                top = stack.pop()
                if top:
                    top *= 2
                else:
                    top += 1
                stack[-1] += top

        return stack[0]
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
