```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        res = []

        def dfs(brac, left, right):
            if left > n or right > n:
                return

            if left == n and right == n:
                res.append(brac)

            if left > right:
                dfs(brac + ")", left, right + 1)
            dfs(brac + "(", left + 1, right)

        dfs("", 0, 0)
        return res
```

> Time Complexity : `O(4^n / sqrt(n))`
>
> Space Complexity : `O(n)`
