```python
class Solution:
    def reverseDegree(self, s: str) -> int:
        res = 0
        for i in range(len(s)):
            res += (i + 1) * (ord('z') - ord(s[i]) + 1)

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
