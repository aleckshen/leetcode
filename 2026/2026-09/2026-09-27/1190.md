```python
class Solution:
    def reverseParentheses(self, s: str) -> str:
        stack = []
        res = []

        for ch in s:
            if ch == "(":
                stack.append(len(res))
            elif ch == ")":
                start = stack.pop()
                res[start:] = res[start:][::-1]
            else:
                res.append(ch)

        return "".join(res)
```

> Time Complexity : `O(n^2)`
>
> Space Complexity : `O(n)`
