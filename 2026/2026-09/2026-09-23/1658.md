```python
class Solution:
    def minOperations(self, nums: list[int], x: int) -> int:
        target = sum(nums) - x
        if target < 0:
            return -1
        left = cur = 0
        longest = -1
        for right, v in enumerate(nums):
            cur += v
            while cur > target:
                cur -= nums[left]
                left += 1
            if cur == target:
                longest = max(longest, right - left + 1)
        return len(nums) - longest if longest != -1 else -1
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
