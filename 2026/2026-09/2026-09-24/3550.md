```python
class Solution:
    def smallestIndex(self, nums: List[int]) -> int:
        for i in range(len(nums)):
            total = 0
            for digit in str(nums[i]):
                total += int(digit)
            if i == total:
                return i

        return -1
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
