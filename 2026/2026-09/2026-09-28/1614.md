```python
class Solution:
    def maxDepth(self, s: str) -> int:
        res = -inf
        count = 0

        for ch in s:
            if ch == "(":
                count += 1
            elif ch == ")":
                count -= 1
            res = max(res, count)

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
