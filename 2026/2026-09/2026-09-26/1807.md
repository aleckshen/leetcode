```python
class Solution:
    def evaluate(self, s: str, knowledge: list[list[str]]) -> str:
        res = []
        hm = dict(knowledge)

        i = 0
        while i < len(s):
            if s[i] == '(':
                key = ""
                i += 1
                while s[i] != ')':
                    key += s[i]
                    i += 1
                if key in hm:
                    res.append(hm[key])
                else:
                    res.append('?')
                i += 1
            else:
                res.append(s[i])
                i += 1

        return "".join(res)
```

> Time Complexity : `O(n + m)`
>
> Space Complexity : `O(n + m)`
