```python
class Solution:
    def countCommas(self, n: int) -> int:
        res = 0

        step = 1000
        commas = 1
        while step <= n:
            possible_nums = (step * 1000) - 1
            if n - possible_nums > 0:
                res += (possible_nums - step + 1) * commas

            prev = step
            step *= 1000
            commas += 1

        commas -= 1
        step //= 1000
        res += (n - step + 1) * commas

        return res
```

> Time Complexity : `O(log n)`
>
> Space Complexity : `O(1)`
