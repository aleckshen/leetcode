```python
class Solution:
    def uniformArray(self, nums1: list[int]) -> bool:
        odd_count = 0
        even_count = 0
        min_odd = inf
        min_even = inf
        n = len(nums1)

        for i in range(n):
            if nums1[i] % 2 == 0:
                even_count += 1
                min_even = min(min_even, nums1[i])
            else:
                odd_count += 1
                min_odd = min(min_odd, nums1[i])

        if odd_count == n or even_count == n:
            return True
        return min_odd < min_even
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
