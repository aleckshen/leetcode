```python
class Solution:
    def maximumLength(self, nums: List[int]) -> int:  
        freq = Counter(nums)
        res = 1

        if 1 in freq and freq[1] % 2 == 0:
            res = max(res, freq[1] - 1)
        else:
            res = max(res, freq[1])

        for x in freq:
            if x == 1:
                continue

            count = 1
            curr = x
            while curr * curr in freq and freq[curr] > 1:
                count += 2
                curr = curr ** 2
            res = max(res, count)
                
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
