```python
class Solution:
    def leftRightDifference(self, nums: List[int]) -> List[int]:
        left = [0] * len(nums) 
        right = [0] * len(nums)

        curr = 0
        for i in range(1, len(nums)):
            curr += nums[i - 1]
            left[i] = curr

        curr = 0
        for i in range(len(nums) - 2, -1, -1):
            curr += nums[i + 1]
            right[i] = curr

        for i in range(len(nums)):
            left[i] = abs(left[i] - right[i])

        return left
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
