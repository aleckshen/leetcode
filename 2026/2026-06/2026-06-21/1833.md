```python
class Solution:
    def maxIceCream(self, costs: List[int], coins: int) -> int:
        costs.sort() 
        res = 0

        for ice_cream in costs:
            coins -= ice_cream 
            if coins >= 0:
                res += 1
            else:
                return res

        return res
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(1)`
