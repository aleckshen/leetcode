We can sort the input list in decreasing order. For every two max cost candies we will skip the next max cost candy in the list. In other words we will take the sum of all candies in the input list sorted in decreasing order skipping every third candy cost.

```python
class Solution:
    def minimumCost(self, cost: List[int]) -> int:
        res = 0
        cost = sorted(cost, reverse=True)
        count = 0

        for cdy in cost:
            if count != 2:
                res += cdy
                count += 1
            else:
                count = 0
        return res
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(1)`
