```python
class Solution:
    def maximumElementAfterDecrementingAndRearranging(self, arr: List[int]) -> int:
        arr.sort()
        threshold = 0

        for num in arr:
            if num > threshold:
                threshold += 1

        return threshold
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
