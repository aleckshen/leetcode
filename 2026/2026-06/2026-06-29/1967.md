```python
class Solution:
    def numOfStrings(self, patterns: List[str], word: str) -> int:
        res = 0 

        for substring in patterns:
            if substring in word:
                res += 1

        return res
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(1)`
