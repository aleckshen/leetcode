```python
class Solution:
    def mapWordWeights(self, words: List[str], weights: List[int]) -> str:
        alphabet = 'abcdefghijklmnopqrstuvwxyz'
        weightMap = {}
        for i in range(26):
            weightMap[alphabet[i]] = weights[i]

        reverseAlpha = "".join(sorted(alphabet, reverse=True))
        reverseMap = {}
        for i in range(26):
            reverseMap[i] = reverseAlpha[i]

        res = ""
        for word in words:
            total = 0
            for letter in word:
                total += weightMap[letter]
            res += reverseMap[total % 26] 
        return res
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(1)`
