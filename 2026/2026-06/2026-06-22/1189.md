```python
class Solution:
    def maxNumberOfBalloons(self, text: str) -> int:
        freq = Counter(text)
        
        if 'o' in freq and 'l' in freq:
            freq['o'] = freq['o'] // 2
            freq['l'] = freq['l'] // 2

        if 'b' in freq and 'a' in freq and 'l' in freq and 'o' in freq and 'l' in freq:
            return min(freq['b'], freq['a'], freq['l'], freq['o'], freq['n'])
        else:
            return 0
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
