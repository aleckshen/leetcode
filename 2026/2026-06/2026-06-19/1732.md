```python
class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        res = -inf
        total = 0

        for ng in gain:
            total += ng
            res = max(res, total)

        if res < 0:
            return 0
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
