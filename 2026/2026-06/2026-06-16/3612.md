```python
class Solution:
    def processStr(self, s: str) -> str:
        res = "" 
        for token in s:
            if token == '*':
                if res:
                    res = res[:len(res) - 1]
            elif token == '#':
                if res:
                    res += res
            elif token == '%':
                if res:
                    res = res[::-1]
            else:
                res += token
        return res
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(1)`
