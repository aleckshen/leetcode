```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        res = 0

        last_a = -1
        last_b = -1
        last_c = -1
        for i in range(len(s)):
            if s[i] == 'a':
                last_a = i
            elif s[i] == 'b':
                last_b = i
            else:
                last_c = i
            if last_a >= 0 and last_b >= 0 and last_c >= 0:
                res += min(last_a, last_b, last_c) + 1

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
