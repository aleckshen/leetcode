```python
class Solution:
    def countServers(self, grid: list[list[int]]) -> int:
        r = len(grid)
        c = len(grid[0])
        rows = [0 for _ in range(r)]
        cols = [0 for _ in range(c)]

        for row in range(r):
            for col in range(c):
                if grid[row][col] == 1:
                    rows[row] += 1
                    cols[col] += 1

        res = 0
        for row in range(r):
            for col in range(c):
                if grid[row][col] == 1 and (rows[row] > 1 or cols[col] > 1):
                    res += 1

        return res
```

> Time Complexity : `O(m * n)`
>
> Space Complexity : `O(m + n)`
