```python
class Solution:
    def minimumCost(self, cost1: int, cost2: int, costBoth: int, need1: int, need2: int) -> int:
        res = 0
        if costBoth < cost1 + cost2:
            smallest = min(need1, need2)
            res += costBoth * smallest
            need1 -= smallest
            need2 -= smallest

        if need1:
            if cost1 < costBoth:
                res += cost1 * need1
            else:
                res += costBoth * need1

        if need2:
            if cost2 < costBoth:
                res += cost2 * need2
            else:
                res += costBoth * need2

        return res
```

> Time Complexity : `O(1)`
>
> Space Complexity : `O(1)`
