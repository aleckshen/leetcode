```python
class Solution:
    def checkString(self, s: str) -> bool:
        seen_b = False
        for ch in s:
            if ch == 'b':
                seen_b = True

            if seen_b and ch == 'a':
                return False

        return True
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
