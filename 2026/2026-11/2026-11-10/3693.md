```python
class Solution:
    def climbStairs(self, n: int, costs: List[int]) -> int:
        dp = [inf for _ in range(n + 1)]
        dp[0] = 0

        for i in range(n):
            for k in range(1, 4):
                j = i + k
                if j <= n:
                    dp[j] = min(dp[j], dp[i] + costs[j - 1] + k ** 2)

        return dp[-1]
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
