```python
class Solution:
    def numOfSubarrays(self, arr: list[int]) -> int:
        # key idea:
        # keep track of cumalative sum, and the number of odd and even
        # cumalative sums. For each cumalative sum we encounter we have
        # two cases:
        # case 1: if the current sum is odd we check the number even sums
        # previously as odd - even = odd and add that to the total number of
        # sub arays with odd sum, including the current odd sum itself aswell
        # case 2: if the current sum is even we check the number of odd sums
        # previoulsy as even - odd = odd and add that to the total number of
        # sub arrays with odd sum

        MOD = 10 ** 9 + 7
        res = 0

        total = 0
        prev_odd = 0
        prev_even = 0

        for num in arr:
            total += num

            if total % 2 == 0: # even case
                res += prev_odd
                prev_even += 1
            else: # odd case
                res += (prev_even + 1)
                prev_odd += 1

        return res % MOD
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
