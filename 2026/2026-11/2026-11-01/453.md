```python
class Solution:
    def minMoves(self, nums: list[int]) -> int:
        moves = 0
        mn = min(nums)

        for num in nums:
            moves += num - mn

        return moves
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
