```python
class Solution:
    def findTheDistanceValue(self, arr1: list[int], arr2: list[int], d: int) -> int:
        res = 0

        for i in range(len(arr1)):
            valid = True
            for j in range(len(arr2)):
                if abs(arr1[i] - arr2[j]) <= d:
                    valid = False
                    break
            if valid:
                res += 1

        return res
```

> Time Complexity : `O(n^2)`
>
> Space Complexity : `O(1)`
