```python
class Solution:
    def canAliceWin(self, n: int) -> bool:
        remove = 10
        for i in range(8):
            n -= remove
            if i % 2 == 1:
                if n < 0:
                    return True
            else:
                if n < 0:
                    return False
            remove -= 1
```

> Time Complexity : `O(1)`
>
> Space Complexity : `O(1)`
