```python
class Solution:
    def digitSum(self, s: str, k: int) -> str:
        # while length of s is greater than k we divide into k sections
        # and run the divide, replace and merge for the current round

        while len(s) > k:
            new = ""
            for i in range(0, len(s), k):
                total = 0
                for digit in str(s[i:i + k]):
                    total += int(digit)
                new += str(total)
            s = new

        return s
```

> Time Complexity : `O(n * r)`
>
> Space Complexity : `O(n)`
