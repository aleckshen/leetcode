For this question we start at `(0,0)` and do a DFS traversal, where at each cell you look at what directions that street type opens to, and for each of those directions you check if the neighboring cell has an opening facing back toward you (e.g. if you move right, the neighbor must open left). If it does, you move there and recurse, marking cells visited so you don't loop. If you ever reach `(m - 1, n - 1)` return true, otherwise if you run out of valid moves return false and backtrack.

```python
class Solution:
    def hasValidPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        visited = set()
        
        connections = {
            1: ['left', 'right'],
            2: ['up', 'down'],
            3: ['left', 'down'],
            4: ['right', 'down'],
            5: ['left', 'up'],
            6: ['right', 'up'],
        }
        moves = {'left': (0, -1), 'right': (0, 1), 'up': (-1, 0), 'down': (1, 0)}
        opposite = {'left': 'right', 'right': 'left', 'up': 'down', 'down': 'up'}
        
        def dfs(r, c):
            if (r, c) == (m - 1, n - 1):
                return True
            visited.add((r, c))
            
            for direction in connections[grid[r][c]]:
                dr, dc = moves[direction]
                nr, nc = r + dr, c + dc
                
                if (0 <= nr < m and 0 <= nc < n 
                    and (nr, nc) not in visited
                    and opposite[direction] in connections[grid[nr][nc]]):
                    if dfs(nr, nc):
                        return True
            return False
        
        return dfs(0, 0)
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
