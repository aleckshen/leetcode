I originally had the idea of iterating through the entire input list for all possible combinations of linear and circular distances for each unique value of `nums[query]`. this solution ended up exceeding the time limit so i opted for a binary search approach, storing all the possible values in a hashmap as keys with the value being a list of their corresponding indicies to binary search through that instead.

```python
class Solution:
    def solveQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        res = []
        n = len(nums)

        indices = defaultdict(list)
        for i, v in enumerate(nums):
            indices[v].append(i)

        for query in queries:
            val = nums[query]
            indexList = indices[val]

            if len(indexList) == 1:
                res.append(-1)
                continue

            distance = inf
            l, r = 0, len(indexList) - 1
            while l < r:
                mid = (l + r) // 2
                if indexList[mid] < query:
                    l = mid + 1
                else:
                    r = mid

            pos = l
            if pos - 1 >= 0:
                linear = abs(indexList[pos - 1] - query)
                circular = n - linear
                distance = min(distance, linear, circular)

            if pos + 1 < len(indexList):
                linear = abs(indexList[pos + 1] - query)
                circular = n - linear
                distance = min(distance, linear, circular)

            linear = abs(indexList[0] - query)
            distance = min(distance, n - linear)

            linear = abs(indexList[-1] - query)
            distance = min(distance, n - linear)

            res.append(distance)

        return res
```

> Time Complexity : `O(q * log n)`
> 
> Space Complexity : `O(n)`
