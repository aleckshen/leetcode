We can represent vertical moves (U and D) with `vertical` and horizontal moves (L and R) with `horizontal`. We will iterate through moves and increment `vertical` if we move up and decrement `vertical` if we move down. For horizontal movements we will increment `horizontal` when we move left and decrement `horizontal` when we move right. After iterating through `moves` if both `horizontal` and `vertical` are equal to zero then we are at the origin `(0, 0)`.

```python
class Solution:
    def judgeCircle(self, moves: str) -> bool:
        horizontal = 0
        vertical = 0 

        for move in moves:
            if move == 'U':
                vertical += 1
            if move == 'D':
                vertical -= 1
            if move == 'L':
                horizontal += 1
            if move == 'R':
                horizontal -= 1

        return horizontal == 0 and vertical == 0
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
