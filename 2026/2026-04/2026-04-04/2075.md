Lowkey didn't do this question very efficiently but oh well. We first create the matrix for this question represented by the examples. After this we can iterate through the matrix diagonally from top left to bottom right starting from the first cell in the matrix. At each cell we will append the character on the current cell to a variable `originalText`. After iterating through the entire matrix we can return the result `originalText` (minus any additional spaces if any).

```python
class Solution:
    def decodeCiphertext(self, encodedText: str, rows: int) -> str:
        if encodedText == "":
            return ""

        rowLength = len(encodedText) // rows
        matrix = [[0] * rowLength for _ in range(rows)]
        count = 0
        valid = True

        for r in range(len(matrix)):
            if not valid:
                break
            for c in range(len(matrix[0])):
                if count > len(encodedText):
                    valid = False
                    break
                matrix[r][c] = encodedText[count]
                count += 1

        originalText = ""
        for i in range(rowLength):
            originalText += matrix[0][i]
            j = i + 1
            tempRow = 1
            while tempRow < rows and j < rowLength:
                originalText += matrix[tempRow][j]
                tempRow += 1
                j += 1
        
        for i in range(len(originalText) - 1, -1, -1):
            if originalText[i] == " ":
                continue
            return originalText[:i + 1]
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
