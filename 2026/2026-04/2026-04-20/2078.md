Brute force solution

```python
class Solution:
    def maxDistance(self, colors: List[int]) -> int:
        n = len(colors)
        res = -inf
        for i in range(n):
            for j in range(i + 1, n):
                if colors[i] != colors[j]:
                    res = max(res, j - i)
        return res
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(1)`
