We can solve this problem with one pass using a hashmap that stores the reversed integer as its key and the index as the value. We start by initializing an empty hashmap and a variable `distance` that will represent the minimum distance between mirror pairs. We can iterate through the input array and at each point check if the current number is in the hashmap containing reversed integers, if it is then we can take the minimum distance by substacting the index values and comparing with `distance`. At each point we will also add the current number we are on but reversed into the hashmap, this will ensure that the reversed values in the hashmap will always have a index lesser than the current number we are on.

After iterating through the input array we can return `distance` if a mirror pair exists otherwise we will return `-1`.

```python
class Solution:
    def minMirrorPairDistance(self, nums: List[int]) -> int:
        dic = {}
        distance = inf

        for i, num in enumerate(nums):
            if num in dic:
                distance = min(distance, i - dic[num])
            dic[int(str(num)[::-1])] = i

        if distance == inf:
            return -1
        return distance
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
