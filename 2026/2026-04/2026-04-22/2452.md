We can solve this problem with a brute force approach. For each word in `queries` we will check every word in `dictionary`, for each word in `dicionary` if any letters differ by less than 3 then we have found a matching word and can move onto the next word in `queries`.

```python
    def twoEditWords(self, queries: List[str], dictionary: List[str]) -> List[str]:
        wordLen = len(queries[0])
        res = []  

        for i in range(len(queries)):
            for j in range(len(dictionary)):
                swaps = 0
                for k in range(wordLen):
                    if queries[i][k] != dictionary[j][k]:
                        swaps += 1
                if swaps < 3:
                    res.append(queries[i])
                    break

        return res
```

> Time Complexity : `O(q * d * n)`
> 
> Space Complexity : `O(1)`
