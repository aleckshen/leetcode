We can first flatten the `m * n` grid into a 2D array. If each number in the flattened array returns the same remainder modulo `x` then we have a valid problem solution, if not we return `-1`. If there is a valid solution then we start by sorting the flattended array, the most optimal target value to reach for each number in the array will be the mid point of the flattened array. We will delcare this value as `target`. We can then iterate through the flattened array and calculate the number of operations required to reach `target` given `x` operations for each number.

```python
class Solution:
    def minOperations(self, grid: List[List[int]], x: int) -> int:
        flatten = [] 
        for row in grid:
            for cell in row:
                flatten.append(cell)

        remainder = flatten[0] % x
        for num in flatten:
            if num % x != remainder:
                return -1

        flatten.sort()
        target = flatten[len(flatten) // 2]
        ops = 0
        for num in flatten:
            ops += abs(num - target) // x
        return ops
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(n)`
