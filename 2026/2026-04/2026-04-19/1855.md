We can solve this problem using a two pointer approach, first we set `i` and `j` to both be `0`, `i` will represent the pointer for `num1` and `j` will represent the pointer for `num2`. We want to maximize the distance between `i` and `j`, since both arrays are sorted in decreasing order we can increment `i` when `nums1[i] > nums2[j]` and increment `j` at every step.This loop will run while `i < len(nums1)` and `j < len(nums2)`, once this condition breaks `i` and `j` will represent the max distance between a pair of values. If this value is lesser than `0` we will return `0`, otherwise we will return `j - i - 1`.

```python
class Solution:
    def maxDistance(self, nums1: List[int], nums2: List[int]) -> int:
        i, j = 0, 0
        while i < len(nums1) and j < len(nums2):
            if nums1[i] > nums2[j]:
                i += 1
            j += 1
        if (j - i - 1) < 0:
            return 0
        return j - i - 1
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
