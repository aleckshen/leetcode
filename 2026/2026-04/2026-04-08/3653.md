For each query in `queries` we can apply the following operations stated in the description of the problem. After aplying the operations we can set a result variable `res` initially to the first element in the array. We will then iterate through each element in the array (not including the first element) and apply the XOR operation of the current element on the result variable. After iterating through the entire array and applying the XOR operation we can return the result.

```python
class Solution:
    def xorAfterQueries(self, nums: List[int], queries: List[List[int]]) -> int:
        for l, r, k, v in queries:
            idx = l
            while idx <= r:
                nums[idx] = (nums[idx] * v) % (10 ** 9 + 7)
                idx += k

        res = nums[0]
        for i in range(1, len(nums)):
            res = res ^ nums[i]
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
