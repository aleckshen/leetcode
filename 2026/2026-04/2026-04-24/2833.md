For this question we can find the absolute value of the number of left moves minus the number of right moves. Then we can add the number of underlined counts on top of this for the furthest point from the origin.

```python
class Solution:
    def furthestDistanceFromOrigin(self, moves: str) -> int:
        freq = Counter(moves)
        return abs(freq['L'] - freq['R']) + freq['_']
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
