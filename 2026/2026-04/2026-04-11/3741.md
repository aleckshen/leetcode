Same problem as previous problem except we need to optimize based on harsher constraints. We can first create a hashmap that stores the number as the key and the indicies that exist for that number in a list. We can then iterate through each list of indicies that are of size 3 or greater to obtain the minimum distance between three equal elements.

This reduces the time complexity from the original brute force solution of O(n^3) to O(n).

```python
class Solution:
    def minimumDistance(self, nums: List[int]) -> int:
        dic = {}
        for i, num in enumerate(nums):
            if num in dic:
                dic[num].append(i)
            else:
                dic[num] = [i]

        res = inf
        for indicies in dic.values():
            if len(indicies) >= 3:
                for size in range(len(indicies) - 2):
                    res = min(
                        res,
                        abs(indicies[size] - indicies[size + 1]) +
                        abs(indicies[size + 1] - indicies[size + 2]) +
                        abs(indicies[size + 2] - indicies[size])
                    )

        if res == inf:
            return -1
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
