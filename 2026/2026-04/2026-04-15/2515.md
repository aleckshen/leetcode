For this question we can enumerate through the input list and check for the target value at each iteration. If the current value is equal to the target value then we have two ways to reach the current variables from the start index:
1. We can take the absolute value of the current index minus start index, this gives us the distance it takes to reach the target value without wrapping the circular array.
2. We can take the length of the input list and minus it from the absolute value of the current index minus start index, this gives us the distance it takes to reach the target value wrapping the circular array.

We will take the minimum of these two distances and store it in `res`. After iterating through the entire array we can return `-1` if no target was found, otherwise we can return `res`.

```python
class Solution:
    def closestTarget(self, words: List[str], target: str, startIndex: int) -> int:
        res = inf
        for i, word in enumerate(words):
            if word == target:
                res = min(res, abs(i - startIndex), len(words) - abs((i - startIndex)))
        if res == inf:
            return -1
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
