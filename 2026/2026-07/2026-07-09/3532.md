```python
class Solution:
    def pathExistenceQueries(self, n: int, nums: List[int], maxDiff: int, queries: List[List[int]]) -> List[bool]:
        component = [0] * n
        val = 0

        for i in range(1, n):
            if nums[i] - nums[i - 1] > maxDiff:
                val += 1
            component[i] = val

        ans = []
        for u, v in queries:
            ans.append(component[u] == component[v])

        return ans
```

> Time Complexity : `O(n + q)`
>
> Space Complexity : `O(n)`
