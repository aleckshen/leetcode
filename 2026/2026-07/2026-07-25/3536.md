Find the two max digits with two passes. In the first pass we keep track of the global max and the index of the global max, in the second pass we keep track of the global max if the index of the max variable is not equal to the index of the previous global max. After both passes we can return the product of the two global maxes.

```python
class Solution:
    def maxProduct(self, n: int) -> int:
        mx = (-inf, -inf)
        s = str(n)

        for i in range(len(s)):
            mx = max(mx, (int(s[i]), i))

        res = -inf
        for i in range(len(s)):
            if i != mx[1]:
                res = max(res, int(s[i]))

        return mx[0] * res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
