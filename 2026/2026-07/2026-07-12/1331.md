```python
class Solution:
    def arrayRankTransform(self, arr: List[int]) -> List[int]:
        if not arr:
            return []

        increase = sorted(arr)
        hm = {increase[0]: 1}

        counter = 1
        prev = increase[0]
        for i in range(1, len(arr)):
            if increase[i] != prev:
                counter += 1
            hm[increase[i]] = counter
            prev = increase[i]

        for i in range(len(arr)):
            arr[i] = hm[arr[i]]

        return arr
```

> Time Complexity : `O(n * log n)`
>
> Space Complexity : `O(n)`
