For this question we start by counting the frequency of each letter occuring in the input string `s`, we can store the values in a hashmap then convert it to a list where each element represents a list containing the letter then the frequency of the letter. We can then sort the list lexicographically.

For this question we need to realise that palindromes can either be odd or even, if its even then every character will have an even frequency, if its odd then every character will have an even frequency except for one odd frequency character. After this we can initialize a list of size `s`, we will set two pointers `l` and `r` representing the start of the array and the end of the array respectively.

We will iterate through the sorted list and run a while loop while the frequency of the current character is greater than 0. Before we run the while loop we need to check one condition: if the current character has odd frequency we need to append the character to the middle of the array. After this we can continue to append the current character to the `l` pointer and `r` pointer and decrement the frequency by 2 whilst also shifting the `l` pointer up 1 and the `r` pointer down 1.

After iterating through all characters in the array we can use the `.join()` method to return the resulting string.

```python
class Solution:
    def smallestPalindrome(self, s: str) -> str:
        freq = Counter(s)
        lst = []
        res = [""] * len(s)

        for letter, freq in freq.items():
            lst.append([letter, freq])
        lst.sort()

        l = 0
        r = len(res) - 1
        for i in range(len(lst)):
            letter, freq = lst[i]
            if freq % 2 == 1:
                res[(l + r) // 2] = letter
                freq -= 1

            while freq > 0:
                res[l] = letter
                res[r] = letter
                l += 1
                r -= 1
                freq -= 2

        return "".join(res)
```

> Time Complexity : `O(n * log n)`
>
> Space Complexity : `O(n)`
