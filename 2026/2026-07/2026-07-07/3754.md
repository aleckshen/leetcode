```python
class Solution:
    def sumAndMultiply(self, n: int) -> int:
        if n == 0:
            return 0

        res = [] 
        for num in str(n):
            if num != '0':
                res.append(num)

        total = 0
        for num in res:
            total += int(num)

        return int("".join(res)) * total
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
