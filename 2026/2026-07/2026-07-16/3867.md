```python
class Solution:
    def gcdSum(self, nums: list[int]) -> int:

        def gcd(a, b):
            while b:
                a, b = b, a % b
            return a

        prefix = [0] * len(nums)
        mx = -inf
        for i in range(len(nums)):
            mx = max(mx, nums[i])
            prefix[i] = gcd(nums[i], mx)

        res = 0
        prefix.sort()
        for i in range(len(prefix) // 2):
            res += gcd(prefix[i], prefix[-1 - i])

        return res
```

> Time Complexity : `O(n * log n + n * log (max(nums)))`
>
> Space Complexity : `O(n)`
