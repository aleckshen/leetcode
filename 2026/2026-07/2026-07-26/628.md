For this question we notice that the largest product of three numbers can only be created the two possible combinations, the product of the three largest numbers or the product of the two smallest numbers and the largest number. After notcing this we can iterate through input array keeping track of the largest 3 numbers and smallest 2 numbers.

We can then return the max between the product of the three largest numbers and the product of the two smallest numbers times largest number.

```python
class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        max1 = max2 = max3 = float('-inf') # three largest
        min1 = min2 = float('inf') # two smallest

        for x in nums:
            # three largest
            if x > max1:
                max1, max2, max3 = x, max1, max2
            elif x > max2:
                max2, max3 = x, max2
            elif x > max3:
                max3 = x

            # two smallest
            if x < min1:
                min1, min2 = x, min1
            elif x < min2:
                min2 = x

        return max(max1 * max2 * max3, min1 * min2 * max1)
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
