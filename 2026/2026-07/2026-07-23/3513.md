```python
class Solution:
    def uniqueXorTriplets(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 2:
            return n

        ans = 1
        while ans <= n:
            ans <<= 1

        return ans
```

> Time Complexity : `O(1)`
>
> Space Complexity : `O(1)`
