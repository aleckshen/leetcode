```python
class Solution:
    def gcdOfOddEvenSums(self, n: int) -> int:
        odd_sum = 0
        even_sum = 0

        for i in range(1, (n * 2) + 1):
            if i % 2 == 0:
                odd_sum += i
            else:
                even_sum += i

        res = 1
        for i in range(1, min(odd_sum, even_sum)):
            if odd_sum % i == 0 and even_sum % i == 0:
                res = i

        return res
```

> Time Complexity : `O(n^2)`
>
> Space Complexity : `O(1)`
