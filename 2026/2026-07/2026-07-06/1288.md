```python
class Solution:
    def removeCoveredIntervals(self, intervals: List[List[int]]) -> int:
        intervals.sort() 
        res = len(intervals)

        prev_interval = intervals[0]
        for i in range(1, len(intervals)):
            if intervals[i][0] <= prev_interval[0] and intervals[i][1] >= prev_interval[1]:
                res -= 1
                prev_interval = intervals[i]
            elif prev_interval[0] <= intervals[i][0] and prev_interval[1] >= intervals[i][1]:
                res -= 1
            else:
                prev_interval = intervals[i]

        return res
```

> Time Complexity : `O(n * log n)`
> 
> Space Complexity : `O(1)`
