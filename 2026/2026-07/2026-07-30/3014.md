Since each character is unique we can iterate through `word` letter by letter and assign each letter by its minimum cost. We do this by keeping track of the amount of letters iterated through and appending to result based on this count.

```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        count = 0
        res = 0

        for w in word:
            count += 1
            if count < 9:
                res += 1
            elif count < 17:
                res += 2
            elif count < 25:
                res += 3
            else:
                res += 4

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(1)`
