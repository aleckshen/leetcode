```python
class Solution:
    def sequentialDigits(self, low: int, high: int) -> List[int]:
        res = []

        for i in range(len(str(low)), len(str(high)) + 1):
            for j in range(1, 9):
                leading = str(j)
                while len(leading) < i:
                    if leading[-1] == '9':
                        leading = -1
                        break
                    leading += str(int(leading[-1]) + 1)
                if int(leading) >= low and int(leading) <= high:
                    res.append(int(leading))

        return res
```

> Time Complexity : `O(1)`
>
> Space Complexity : `O(1)`
