This question is the same as the previous daily except for the fact that characters can repeat in the input string. This means that we need to assign lower costs for characters with higher frequency, we can start by initializing a hashmap representing the frequencies of each character. We sort the values in decreasing order order then iterate through each value and increment a result variable based on the current count of characters we are on.

```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        hm = Counter(word)
        frequencies = sorted(hm.values(), reverse=True)
        count = 0
        res = 0

        for freq in frequencies:
            count += 1
            if count < 9:
                res += freq
            elif count < 17:
                res += freq * 2
            elif count < 25:
                res += freq * 3
            else:
                res += freq * 4

        return res
```

> Time Complexity : `O(n)`
>
> Space Complexity : `O(n)`
