```python
class Solution:
    def shiftGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:

        def shift(arr):
            m = len(arr)
            n = len(arr[0])
            prev = arr[m - 1][n - 1]
            for r in range(m):
                for c in range(n):
                    temp = arr[r][c]
                    arr[r][c] = prev
                    prev = temp

        for i in range(k):
            shift(grid)

        return grid
```

> Time Complexity : `O(k * n * m)`
>
> Space Complexity : `O(1)`
