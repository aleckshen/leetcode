For this question the brute force approach is to calculate all possible sub arrays and compare the max sum for every sub array we calculate. This would run in O(n^2) time complexity, we can optimize it to run in O(n) time complexity. First we will have a global variable that represents the maximum sum, we will also have a running sum that represents the current sum as we iterate through the input list. At each step we have the following options:
1. Add the number we are currently on to the current sum.
2. Restart the current sum to the number we are on.

At each step we will always increment current sum with the number we are on, but we will also check if the number we are on is greater then the current sum we just added to. This will be true when the current sum previously was a negative value, whenever this is the case we want to reset the current sum to the current number. At each step we will also compare the maximum sum with the current sum, after iterate through all numbers in the input array we can return the maximum sum.

```python
class Solution(object):
    def maxSubArray(self, nums):
        maxSum = float('-inf')

        currSum = 0
        for num in nums:
            currSum += num
            if num > currSum:
                currSum = num
            maxSum = max(maxSum, currSum)

        return maxSum
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
