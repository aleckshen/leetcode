For this question we will first initialize a variable `goal` which will represent the destination we are trying to jump to. We will iterate through the input array backwards and at each point we will check if the current number plus the index we are on is able to jump to the goal index. If this is true then we can set `goal` to the current index we are on. This will essentially check if at every position in the array we can find a consecutive jump that will reach the end index of the array. Once we iterate all the way to the first value of the array we will do one final check. Since we need to be able to jump from the first index of the array, `goal` will have to equal to 0 for us to return true. After iterate through the input array we will return true if goal is equal to 0 otherwise we will return false.

```python
class Solution(object):
    def canJump(self, nums):
        goal = len(nums) - 1

        for i in range(len(nums) - 2, -1, -1):
            if i + nums[i] >= goal:
                goal = i

        return goal == 0
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
