For this question we want to detect a cycle within a the graph and remove the edge that forms the cycle. Note that there can be multiple edges that form the cycle within the graph, but the question specifies to remove the last edge in the input list that forms the cycle.

We can first create a 1-indexed adjacency list which will store the neighbors of each node as we iterate through the input list. Next we will create a dfs function which will check for cycles through the use of a visited set. The dfs function will take in two parameters, the current node `u` and the parent node `parent`. Initially the parent node will be passed in as `-1` as it doesn't exist, but as we traverse the neighbors of the current node the parent node will change. 

We will iterate through the current nodes neighbors and check three conditions:
1. If the neighboring nodes we are iterating over is equal to the parent node than we continue to avoid falsely identifying cycles as the graph is bidirectional.
2. If the current nodes neighbors belong in the visited set then a cycle is detected and we return true.
3. Recursively call dfs on the current nodes neighbors as well to check whether a cycle exists, if this is also true then we return true.

We will iterate through each input edge as `u, v`, we will construct the adjacency list that we earlier declared as we iterate through each edge and run dfs on node `u`. The way we construct our adjacency list while running dfs on the current nodes will allow us to return the cycle that is last in the input edge list. Once a cycle has been constructed and the dfs function on the current node `u` returns true then we can return the edge `[u, v]` as the edge forming the cycle.

```python
class Solution(object):
    def findRedundantConnection(self, edges):
        adj = [[] for i in range(len(edges) + 1)]

        def dfs(u, parent):
            visited.add(u)
            for v in adj[u]:
                if v == parent:
                    continue
                if v in visited:
                    return True   
                if dfs(v, u):
                    return True
            return False

        visited = set()

        for u, v in edges:
            visited.clear()
            adj[u].append(v)
            adj[v].append(u)

            if dfs(u, -1):
                return [u, v]
```

> Time Complexity : `O(E * (V + E))`
> 
> Space Complexity : `O(V + E)`
