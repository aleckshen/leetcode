For this question we want to calculate the minimum number of minutes it takes for for all oranges in a `m * n` grid to be rotten. Upon each minute of time all rotten oranges that are adjacent to it will also grow rotten. Since we want to increment the number of minutes level by level we will use a bfs traversal. 

Initially we will traverse through the grid and count the number of fresh oranges. This is to handle two cases:
1. If the number of fresh oranges is equal to 0 we will return `0`.
2. When we run the bfs algorithm we will decrement the number of fresh oranges each time we encounter one, if there so happens to be a fresh orange that is not reachable then the number of fresh oranges will never equal to 0. We will check for this at the end of the algorithm and if this is true then we will return `-1`.

Upon the same traversal we will also append the row and column indexes of rotten oranges as a `(r, c)` tuples. 

For the logic of our bfs algorithm we will start by running the traversal while the queue is non-empty and the number of fresh oranges is greater than 0. We will iterate through all oranges that are currently within the queue (all rotten oranges for this stage in time), upon each iteration we will pop the orange from the queue and retrieve the index values of the rotten orange. We will check for 4 cases:
1. If the cell above the current cell is in bound and has a rotten orange.
2. If the cell to the left of the current cell is in bound and has a rotten orange.
3. If the cell to the bottom of the current cell is in bound and has a rotten orange.
4. If the cell to the right of the current cell is in bound and has a rotten orange.

If any of these cases are true we will first change the value of this orange in the input grid to `2` which marks it as a rotten orange. This is to ensure that we don't accidentally decrement oranges that have already been marked as rotten. Secondly we will decrement the number of fresh oranges by 1. And lastly we will append the row and column index of the current rotten orange to the queue for the next iteration.

After iterating through all oranges at the current stage in time, we will increment the number of minutes by one. Once the queue is empty, we can check if the number of fresh oranges is equal to 0. If this is true we will return the number of minutes, otherwise we will return `-1`.

```python
class Solution(object):
    def orangesRotting(self, grid):
        minutes = 0
        fresh = 0

        rows = len(grid)
        cols = len(grid[0])
        queue = collections.deque()
        
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1:
                    fresh += 1
                elif grid[r][c] == 2:
                    queue.append((r, c))

        while queue and fresh > 0:
            for i in range(len(queue)):
                r, c = queue.popleft()
                if r - 1 >= 0 and grid[r - 1][c] == 1: #top
                    grid[r - 1][c] = 2
                    queue.append((r - 1, c))
                    fresh -= 1
                if c - 1 >= 0 and grid[r][c - 1] == 1: #left
                    grid[r][c - 1] = 2
                    queue.append((r, c - 1))
                    fresh -= 1
                if r + 1 < rows and grid[r + 1][c] == 1: #bottom
                    grid[r + 1][c] = 2
                    queue.append((r + 1, c))
                    fresh -= 1
                if c + 1 < cols and grid[r][c + 1] == 1: #right
                    grid[r][c + 1] = 2
                    queue.append((r, c + 1))
                    fresh -= 1

            minutes += 1

        if fresh == 0:
            return minutes
        return -1
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
