For this question we want to create a deep clone of a given input graph. First we will initialize a hashmap that stores current to copy node pairs. We will recursively run dfs to create a copy of each node and its neighbors. On each recursive call we will also append the copy of its neighbors onto the current copy node. We will have a base case to check whether or not a copy of a node is already created in the hashmap, if this is true we can just return the current copy of the node. If the node is not in the hashmap we will continue to create a copy as explained above and return the copied node at the end.

We can call dfs on the input node given and also return the node that the dfs function returns which is a copy of the current input node. 

```python
class Solution(object):
    def cloneGraph(self, node):
        if not node:
            return 

        oldToNew = {}
        
        def dfs(node):
            if node in oldToNew:
                return oldToNew[node]

            copy = Node(node.val)
            oldToNew[node] = copy
            for neighbor in node.neighbors:
                copy.neighbors.append(dfs(neighbor))

            return copy

        return dfs(node)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
