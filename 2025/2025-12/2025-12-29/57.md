For this question we have a input array of sorted intervals `intervals`, we also have another interval `newInterval` that we want to insert into the current input array `intervals`. This is easy if `newInterval` does not overlap with any intervals in `intervals`, to merge intervals together we can take the minimum of the starting intervals for both the current interval we are on and `newInterval`, and also take the maximum of the ending intervals for both the current interval we are on and `newInterval`.

We will start by initializing a results array `res`. We will iterate through all intervals in `intervals`, we will have three main cases to take into account:
1. If the end interval value of `newInterval` is lesser then the starting interval value of the current interval then we have found a position to insert `newInterval` into. We will append `newInterval` into `res` and return `res` appended with the intervals left remaining in `intervals`.
2. If the starting interval value of `newInterval` is greater than the ending interval value of the current interval then we want to append the current interval to `res` and continue with the next iteration.
3. If both conditions above result to false that means `newInterval` overlaps with the current interval. In this case we take the minimum starting intervals of the current interval and `newInterval` and take the maximum ending intervals of the current interval and `newInterval` to create the merged `newInterval`.

After iterating through all intervals if we have not returned from the first `if` statement in our for loop then it means that `newInterval` belongs at the end of the list, in this case we can just append `newInterval` to `res` and return it.

```python
class Solution(object):
    def insert(self, intervals, newInterval):
        res = []

        for i in range(len(intervals)):
            if newInterval[1] < intervals[i][0]:
                res.append(newInterval)
                return res + intervals[i:]
            elif newInterval[0] > intervals[i][1]:
                res.append(intervals[i])
            else:
                newInterval = [min(intervals[i][0], newInterval[0]),
                               max(intervals[i][1], newInterval[1])]

        res.append(newInterval)
        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
