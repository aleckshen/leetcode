For this question we can take a similar approach to the [Pacific-Atlantic-Water-Flow](/2025/2025-12/2025-12-05/417.md) question. We know that any `'O'` cells surrounding the edges cannot be captured. We can run a dfs algorithm that starts from every single edge cell, if the edge cell is in bounds of the board and the edge cell is `'O'` then we will change that value to `'T'` temporarily and run dfs on all adjacent cells of that. This will ensure that all regions connected to the edges that are marked as `'O'` will not be captured.

We can then run a nested for loop on the entire board, if the cell we land on is equal to `'O'` then we can capture it and change its value to `'X'`, if the cell we land on is equal to `'T'` representing the temporary variable then we will switch its value back to `'O'` and if the value we land on is equal to `'X'` then we will skip to the next iteration. After traversing through the entire `m * n` board all regions surrounded with `'X'` cells would have been captured.

```python
class Solution(object):
    def solve(self, board):
        rows = len(board)
        cols = len(board[0])

        def capture(r, c):
            if r < 0 or c < 0 or r >= rows or c >= cols or board[r][c] != 'O':
                return 
            
            board[r][c] = 'T'
            capture(r - 1, c) #top
            capture(r, c - 1) #left
            capture(r + 1, c) #bottom
            capture(r, c + 1) #right

        for c in range(cols):
            capture(0, c)
            capture(rows - 1, c)

        for r in range(rows):
            capture(r, 0)
            capture(r, cols - 1)

        for r in range(rows):
            for c in range(cols):
                if board[r][c] == 'O':
                    board[r][c] = 'X'
                elif board[r][c] == 'T':
                    board[r][c] = 'O'
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
