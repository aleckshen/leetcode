This question was pretty similar to the previous question insert interval in the sense that if we have a overlapping interval we need to merge the two intervals together. First we will sort the intervals by the starting intervals. We will then set `prevInterval` to the first interval in the input array `intervals`. Now we can iterate through the intervals starting from the second interval, if the previous intervals end interval is greater then or equal to the current intervals starting interval we need to merge the two intervals together. Once we merge them together we can set `prevInterval` to the merged interval. If the current interval doesn't overlap with the previous interval then we can append the previous interval to the result array and carry on iterating through the input array.

After iterating through the entire list we will have one more interval to append to the result list. If it overlaps with the previous interval then we will merge it together with the previous interval and append it to the results list, otherwise we just append the last interval left.

```python
class Solution(object):
    def merge(self, intervals):
        intervals.sort()
        res = []

        prevInterval = intervals[0]
        for i in range(1, len(intervals)):
            if prevInterval[1] >= intervals[i][0]:
                prevInterval = [min(prevInterval[0], intervals[i][0]),
                                max(prevInterval[1], intervals[i][1])]
            else:
                res.append(prevInterval)
                prevInterval = intervals[i]

        if res and res[-1][1] > prevInterval[0]:
            res[-1] = [min(prevInterval[0], res[-1][0]),
                       max(prevInterval[1], res[-1][1])]
        else:
            res.append(prevInterval)

        return res
```

> Time Complexity : `O(n log n)`
> 
> Space Complexity : `O(n)`
