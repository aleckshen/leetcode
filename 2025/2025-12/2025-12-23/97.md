This problem requires us to create a string `s3` by interleaving strings `s1` and `s2`. We know that these strings can interleave and form `s3` only if the sum of the characters in `s1` plus the sum of the characters in `s2` is equal to the sum of the characters in `s3`. We will solve this problem recursively, we will start by taking in three parameters `(i, j, k)` which represents the pointers of string `s1`, `s2` and `s3` respectively. At each step of our recursive call we will have two choices:
1. If the string at at index `i` for `s1` matches the string at index `k` for `s3` then we will proceed with the next character in `s1`.
2. If the string at index `j` for `s2` matches the string at index `k` for `s3` then we will proceed with the next character in `s2`.

We will also memoize each recursive step to avoid redundant recursive calls. Once we reach the base case where the `k` pointer is the same length of the string `s3`, then we can return true if the the `i` pointer is the same length of the string `s1` and the `j` pointer is the same length of the string `s2`.

```python
class Solution(object):
    def isInterleave(self, s1, s2, s3):
        memo = {}
        
        def dfs(i, j, k):
            if (i, j, k) in memo:
                return memo[(i, j, k)]
            if k == len(s3):
                return (i == len(s1)) and (j == len(s2))

            if i < len(s1) and s1[i] == s3[k]:
                memo[(i, j, k)] = dfs(i + 1, j, k + 1)
                if memo[(i, j, k)]:
                    return True
                
            if j < len(s2) and s2[j] == s3[k]:
                memo[(i, j, k)] = dfs(i, j + 1, k + 1)
                if memo[(i, j, k)]:
                    return True

            return False

        return dfs(0, 0, 0)
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
