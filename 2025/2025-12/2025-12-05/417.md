For this problem I started off the with naive solution of checking if every single cell would be able to reach the pacific and atlantic ocean. This required each cell to traverse through every other cell in the graph, this resulted in a time complexity of O((n * m)^2) and I ended up exceeding the time limit.

To optimize this I decided to run dfs from every single edge cell in the `m * n` grid. We will also initialize a pacific and atlantic ocean set that will represent all the coordinates that are can reach the respective oceans. As we know that every single edge cell from the `m * n` grid can flow into the ocean, we can just run dfs on the adjacent cells of the edge cells and compare the current cell we are on to the previous value that we will also pass into the dfs function. The base case for the dfs function will include the following conditions:
1. If the row and column index is out of bounds, return.
2. If the coordinate is already within the visited set, return.
3. If the current value is lesser than the previous value, return.

If all the base case conditions return false then we know that we have encountered a coordinate that can flow into the ocean of the desired set we passed in. We can then add the coordinate to the desired set and run dfs on its adjacent cells.

After running dfs on every single edge cell in the `m * n` grid then we can append all coordinates that belong in both the atlantic and pacific ocean set to a results array and return it.

```python
class Solution(object):
    def pacificAtlantic(self, heights):
        rows = len(heights)
        cols = len(heights[0])
        pacific = set()
        atlantic = set()

        def dfs(r, c, visited, prevHeight):
            if ((r, c) in visited or r < 0 or r >= rows 
            or c < 0 or c >= cols or heights[r][c] < prevHeight):
                return 

            visited.add((r, c))
            dfs(r - 1, c, visited, heights[r][c]) #top
            dfs(r, c - 1, visited, heights[r][c]) #left
            dfs(r + 1, c, visited, heights[r][c]) # bottom
            dfs(r, c + 1, visited, heights[r][c]) # right

        for c in range(cols):
            dfs(0, c, pacific, heights[0][c]) 
            dfs(rows - 1, c, atlantic, heights[rows - 1][c])

        for r in range(rows):
            dfs(r, 0, pacific, heights[r][0])
            dfs(r, cols - 1, atlantic, heights[r][cols - 1])

        res = []
        for coord in pacific:
            if coord in atlantic:
                x, y = coord
                res.append([x, y])

        return res
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
