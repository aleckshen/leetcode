For this question we will create a recursive function where at each step we have the option to subtract or add the current number at index `i` to our total count. Initially the total count will be set to 0. Once we reach the end of the input array we can check the two conditions:
1. If the total is equal to the target then we can return 1.
2. If the total is not equal to the target then we can return 0.

After the conditions of the base case we will have the two recursive calls added together and returned. We can also store the result of the recursive calls added together in a cache to avoid redundant calls. This will reduce the time complexity from O(2^n) to O(n * m).

```python
class Solution(object):
    def findTargetSumWays(self, nums, target):
        memo = {}

        def dfs(i, total):
            if i == len(nums):
                if total == target:
                    return 1
                else:
                    return 0
            if (i, total) in memo:
                return memo[(i, total)]

            memo[(i, total)] = dfs(i + 1, total + nums[i]) + dfs(i + 1, total - nums[i])
            return memo[(i, total)]

        return dfs(0, 0)
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(n * m)`
