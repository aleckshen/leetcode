My first thought to this question was to draw out a decision tree. At each step we have the following options:
1. We can either do nothing and proceed onto the next stock in `prices[i + 1]`.
2. We can choose to buy stock, if we buy stock for the next decision we can either stay on cool down or we can immediately sell the stock.
3. We can choose to sell stock and we are forced to go on cool down for one day.

Given these possible choices we can write a recursive solution where at each index we can do the following choices above. The base case will be if the index `i` goes out of bounds then we return 0. Otherwise we have the following choice of staying on cool down, buying or selling. We will have a boolean variable `buying` that will allow us to buy its set to true. We will return the maximum value at each step between choosing to cool down and between the choice of either buying or selling.

```python
class Solution(object):
    def maxProfit(self, prices):
        
        def dfs(i, buying):
            if i >= len(prices):
                return 0

            cooldown = dfs(i + 1, buying)    
            if buying:
                buy = dfs(i + 1, False) - prices[i]
                return max(buy, cooldown)
            else:
                sell = dfs(i + 2, True) + prices[i]
                return max(sell, cooldown)

        return dfs(0, True)
```

The following code above works but runs in exponential time complexity, in order to reduce the time complexity we can memoize sub problems in a cache as `(index, buying)` keys where the value represents the maximum profit. This will reduce the time complexity from O(2^n) to O(n).

```python
class Solution(object):
    def maxProfit(self, prices):
        memo = {} #(index, buying) pairs

        def dfs(i, buying):
            if i >= len(prices):
                return 0
            if (i, buying) in memo:
                return memo[(i, buying)]

            cooldown = dfs(i + 1, buying)    
            if buying:
                buy = dfs(i + 1, False) - prices[i]
                memo[(i, buying)] = max(buy, cooldown)
                return memo[(i, buying)]
            else:
                sell = dfs(i + 2, True) + prices[i]
                memo[(i, buying)] = max(sell, cooldown)
                return memo[(i, buying)]

        return dfs(0, True)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
