For this problem I first drew out a decision tree, for each house we encounter in the input list `nums` we can either rob the house or skip the house. The decision tree shows all possible choices from choosing each decision at each house. I ended up with the following solution:

```python
class Solution(object):
    def rob(self, nums):
        def dfs(i):
            if i >= len(nums):
                return 0

            return max(dfs(i + 1), nums[i] + dfs(i + 2))

        return dfs(0)
```

However this solution exceeded time limit as it has a time complexity of O(2^n). To optimize this solution we can use dynamic programming, there are multiple ways to approach this question but I found the bottom up method more intuitive. First I constructed a array where at each index `i`, `dp[i] will represent the maximum amount of money that can be robbed up to that point. This is calculated by identifying the fact that the current max amount of money that can be robbed up until house `i` is split between two choices:
1. If we take the previous max value from `dp[i - 1]` then it means we robbed the previous house so `dp[i - 1]` itself will be a choice.
2. If we take the current house at `nums[i]` then it means `dp[i - 1]` wasn't robbed and we can add `nums[i]` with `dp[i - 2]`.

If we take the maximum of these two choices we will be able to calculate the max amount of money that can be robbed iteratively by updating out dp array. Note that the first two elements of the dp array will be set manually, the max amount of money that can be robbed at index `0` will always be the cost of the house at index `0`. However the max amount of money that can be robbed at index `1` will depend on the max between the amount of money in house `0` and house `1`. Once we set these two initial values in our dp array we can iteratively calculate the maximum amount of money we can rob up until the last house.

At the end we will have calculated the maximum amount of money we can rob which will be the last element in our dp array and we can return `dp[-1]`.

```python
class Solution(object):
    def rob(self, nums):
        if len(nums) == 1:
            return nums[0]

        dp = [0] * len(nums) 
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        for i in range(2, len(nums)):
            dp[i] = max(nums[i] + dp[i - 2], dp[i - 1])

        return dp[-1]
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
