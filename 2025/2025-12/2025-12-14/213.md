This question is the same as the first house robber question except the houses are arranged in a circular format. This means that if we choose to rob from the first house in the input array then we are not allowed to rob from the last house in the array as it would be adjacent in a circular arrangement. If this is the case then we have two options:
1. Find the maximum amount of money we can rob starting from house `0` to house `n - 1`.
2. Find the maximum amount of money we can rob starting from house `1` to house `n`.

Note that we will also have two edge cases, if there is only one house to rob then we will return the amount of money in that house. If there are only two houses, then technically they will both be adjacent if arranged in a circle so we can return the max amount of money between the two houses. After handling the base cases we can initialize two arrays. `dp` will represent the max amount of money we can rob from house `0` to house `n - 1` and `dp1` will represent the max amount of money we can rob from house `1` to house `n`.

Finding the maximum amount of money to rob up until each house `i` will be the same as the way we solved it in the first house robber question. We will have two for loops to calculate for each and at the end of both we can return the maximum between `dp[-2]` as the last house is skipped and `dp1[-1]`.

```python
class Solution(object):
    def rob(self, nums):
        if len(nums) == 1:
            return nums[0]

        if len(nums) == 2:
            return max(nums)

        dp = [0] * len(nums)
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])

        dp1 = [0] * len(nums)
        dp1[1] = nums[1]

        for i in range(2, len(nums) - 1):
            dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])

        for i in range(2, len(nums)):
            dp1[i] = max(dp1[i - 1], nums[i] + dp1[i - 2])
        
        return max(dp[-2], dp1[-1])
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
