This question involves validating parentheses with a slight twist where stars can equal to either a opening bracket, closing bracket or a empty string. My first intuition is to implement a solution using stacks, where at each point if we encounter a opening bracket we append to a stack `left` the current index representing the open brace. If we encounter a star we will append to another stack called `star` the index of the current star. If we encounter a closing brace we will check the following:
1. if both stacks are empty this means that there is no corresponding closing brace and we return false.
2. If `left` is non empty then we will pop from the left stack. 
3. If `left` is empty then we will pop from `star` using the star as a closing brace.

After enumerating through the input string `s` we can still have remaining open braces and stars left. The reason why we append the index to the respective stacks is for this final step. We will run a while loop while both `left` is non empty and `star` is non empty. While both are non empty we will check if the stars index at the top of the stack `star` is greater then the index of the bracket at the top of the stack `left`. If this is true then star can be used as a closing brace and we will pop from both stacks. Otherwise we will only pop from `star`. 

After the while loop terminates we can return true if `left` is empty otherwise we return false.

```python
class Solution(object):
    def checkValidString(self, s):
        left = []
        star = []

        for i, char in enumerate(s):
            if char == '(':
                left.append(i)
            elif char == '*':
                star.append(i)
            else:
                if not left and not star:
                    return False
                if left:
                    left.pop()
                else:
                    star.pop() 

        while left and star:
            if star[-1] > left[-1]:
                left.pop()
            star.pop()

        return not left
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
