This is a cycle detection question where you can visualize each course as a node. If a node contains a cycle then it means that the course can never be completed given a infinite loop prerequisite condition. To start this question we will initialize a hashmap that will contain each node and a adjacency list of its prerequisites. We will also use a visited hash set that will help us detect cycles.

We will start by creating a recursive dfs function that checks if a course and its prerequisite courses are valid. The base cases will check:
1. If the course is in the visited set, that means a cycle has been detected and we can return false.
2. If the courses has no prerequisite course, then we can return true.

For the body of our recursive dfs function we will first add the current course to our visited set, then we will iterate through all prerequisite courses in the current courses adjacency list. If any of the prerequisite courses in the current courses adjacency list return false then we will also return false. Otherwise if all prerequisite of the current course return true then we can remove the current course from the visited set and initialize the adjacency to be empty which will mean that the current course is a valid course that can be taken without duplicate cycles. Then we can return True.

We will iterate through all courses and run dfs on every single course number, if any return false then we will return false, otherwise we will return true.

```python
class Solution(object):
    def canFinish(self, numCourses, prerequisites):
        prereqMap = {i:[] for i in range(numCourses)}
        for course, prereq in prerequisites:
            prereqMap[course].append(prereq)

        visited = set()

        def dfs(course):
            if course in visited:
                return False

            if prereqMap[course] == []:
                return True

            visited.add(course)
            for prereq in prereqMap[course]:
                if not dfs(prereq):
                    return False
            visited.remove(course)
            prereqMap[course] = []
            return True
                
        for i in range(numCourses):
            if not dfs(i):
                return False
        return True
```

> Time Complexity : `O(V + E)`
> 
> Space Complexity : `O(V + E)`
