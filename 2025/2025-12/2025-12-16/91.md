For this question we can use recursion and memoization where at each index `i` in the input string `s` we calculate the number of ways we can decode the string from `i` to the end of the string. If the subproblem at index `i` has already been calculated we can return the desired number from our cache otherwise we will compute the value ourself and store it in the cache.

First we will initialize our cache with the following key value pair `len(s): 1`, this ensures that once we reach the end of the input string it will return 1. We will the check if the current value at index `i` is equal to 0, if this is true then we return 0 as 0 is not a part of our mappings.

For the logic of the recursive function we will first explore the case where the current digit is encoded by itself, we will store that in a result variable. Next we will check if the next digit in `s[i + 1]` can form a digit between 1-26 with `s[i]`, if this is possible then we will also add the result of this possible case onto the current result variable. After exploring both these cases we can cache out result at `dp[i]`. 

We can return and call the recursive function we have created which will represent the number of ways input string `s` can be encoded.

```python
class Solution(object):
    def numDecodings(self, s):
        dp = {len(s) : 1}

        def dfs(i):
            if i in dp:
                return dp[i]
            if s[i] == "0":
                return 0

            res = dfs(i + 1)
            if i + 1 < len(s) and (
                s[i] == "1" or s[i] == "2" and
                s[i + 1] in "0123456"
            ):
                res += dfs(i + 2)
            dp[i] = res
            return res

        return dfs(0)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
