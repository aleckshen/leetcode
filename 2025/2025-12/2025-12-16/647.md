This question is solved the same way from the previous question [Longest-Palindromic-Substring](/2025/2025-12/2025-12-15/5.md). We will calculate all substrings of input string `s` and check whether they are palindromes by shifting left and right pointers outwards, whilst iterating through every character in the input string. If the left and right pointers are equal we will increment our result count by 1. We need to handle two cases:
1. If the input string is of odd length then every left and right pointer we create at every character will be initialized as both `i`.
2. If the input string is of even length then every left and right pointer we create at every character will be initialized as `i` and `i + 1` respectively.

Once we iterate through all characters of the input string, we can return the result count.

```python
class Solution(object):
    def countSubstrings(self, s):
        res = 0

        for i in range(len(s)):
            #even length case 
            l, r = i, i
            while l >= 0 and r < len(s) and s[l] == s[r]:
                res += 1
                l -= 1
                r += 1

            #odd length case
            l, r = i, i + 1
            while l >= 0 and r < len(s) and s[l] == s[r]:
                res += 1
                l -= 1
                r += 1

        return res
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(1)`
