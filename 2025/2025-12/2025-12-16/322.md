For this problem we want the minimum amount off coins in `coins` that will sum up to `amount`. If this result doesn't exist return `-1`. We can think of the problem like this, at each decision we have the option of picking every single coin in `coins`. Each coin we take will account for 1 coin picked, if `amount` minus the coin we picked is greater than equal to zero then we need to pick more coins to ensure that the `amount - coin` will reach 0 at some point.

To solve this solution we will use recursion with memoization, our base cases will be:
1. If total is equal to 0 then we have found a possible combination of coins to sum to amount and we can return 0 to stop.
2. If the total amount is in the cache, then we have already solved this subproblem and we can return the combination.

For the body of our function we will first set a result variable to infinity, this will represent the minimum amount of coins to sum to `total`. Given the current total, we will iterate through every possible coin choice in array `coins`, if the `total` minus the coin we are on is greater than or equal to zero, then we will set the result to the minimum of the current result and 1 coin choice plus `dfs(total - coin)`. At each point we will also cache the minimum number of coins required to sum to amount, this will stop any redundant combinations being solved.

We will call our function and store the returned variable in `minCoins`. If `minCoins` is equal to infinity then no solutions were found and we can return `-1`, otherwise we will return `minCoins`.

```python
class Solution(object):
    def coinChange(self, coins, amount):
        memo = {}

        def dfs(total):
            if total == 0:
                return 0
            if total in memo:
                return memo[total]

            res = float('inf')
            for coin in coins:
                if total - coin >= 0:
                    res = min(res, 1 + dfs(total - coin))

            memo[total] = res
            return res

        minCoins = dfs(amount)
        if minCoins == float('inf'):
            return -1
        return minCoins
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(m)`
