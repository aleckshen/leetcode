The brute force solution of this problem would be to iterate over each index in the array and check whether it can travel around the circuit, but this results in a time complexity of O(n^2) worst case. To solve this solution in O(n) we can use a greedy approach. First note that if the sum of the gas is lesser then the sum of the cost then it will be impossible to travel around the circuit. We will first check if this is true, if it is then we will return `-1`, otherwise we will need to identify which index allows us to travel around the circuit.

We will then initialize two variables `res` and `total` which will both be set to zero. `res` will represent the resulting index and `total` will represent the gas and cost difference. We will iterate through all possible indexes and at each and point increment our total to the current difference of gas and cost at the current index. If the total ever reaches below 0 we know that it is impossible to proceed further, we can then set `res` to the current index plus one and reset our total to zero.

After iterating through all possible indexes we can return the result index.

```python
class Solution(object):
    def canCompleteCircuit(self, gas, cost):
        if sum(gas) < sum(cost):
            return -1

        res = 0
        total = 0

        for i in range(len(gas)):
            total += gas[i] - cost[i]
            if total < 0:
                res = i + 1
                total = 0

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
