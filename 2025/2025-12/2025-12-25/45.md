We can approach this problem using a bfs approach where each level will represent the current jump we are one and all the possible jumps within the current level will be represented by the values between a left and a right pointer. We will first initialize a variable `jumps` which will record the minimum number of jumps available, next we wil initialize two pointers `l, r` which will represent the window of available jumps for the current level we are on. Both pointers are initially both set to zero as the only possible option of the first jump is at index 0. We will run this algorithm while the right pointer has not landed on the last index of the array, we will set a variable named `farthest` at each level we iterate through.

We will iterate through all possible jumps at the current level and record the maximum jump possible from the range of values within the current window. We will then set our left pointer to be the right pointer plus one and the set the right pointer to be the farthest jump possible. The left and right pointers will contain the values of the next range of possible jumps available. After updating the pointers we will increment the variable `jumps` by 1.

After the algorithm terminates we can return the variable `jumps` which will represent the minimum number of jumps required to reach the last index of the input array.

```python
class Solution(object):
    def jump(self, nums):
        jumps = 0
        l, r = 0, 0

        while r < len(nums) - 1:
            farthest = 0
            for i in range(l, r + 1):
                farthest = max(farthest, i + nums[i])
            l = r + 1
            r = farthest 
            jumps += 1

        return jumps
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
