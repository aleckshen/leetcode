For this question we want to first create a hash map where each character in the input string `s` will be stored in the hashmap, the corresponding value of each key in the hashmap will be the last index of the character in the input string. We will then initialize two variables `size` and `end`, `size` will represent the size of the partition and `end` will represent the last index for all characters in the current partition. These two variables will both be set to zero initially.

We will then iterate through the input string `s`, at each point we will first increment the size of the partition by one. Next we will set `end` to the max of the current value `end` and the last index of the current character we are iterating over. If the value `end` is equal to the current index that means that there are no more repetitions for all characters in the current partition, we can then append `size` to a results list and set `end` and `size` back to 0. After iterating through the entire input string we can return the results list.

```python
class Solution(object):
    def partitionLabels(self, s):
        res = []

        lastIndex = {}
        for i in range(len(s) - 1, -1, -1):
            if s[i] not in lastIndex:
                lastIndex[s[i]] = i

        size = 0
        end = 0
        for i in range(len(s)):
            size += 1
            end = max(end, lastIndex[s[i]])

            if i == end:
                res.append(size)
                end = 0
                size = 0

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(m)`
