For this question I initially thought to use dijkstra's algorithm but I ended up having some issues due to the fact that the question specified a minimum cost with only `k` number of stops between the source and destination node.

After looking at neetcodes solution we can use bellman fords algorithm. The algorithm starts by creating a array `prices` where each index `i` in the array represents the minimum cost it takes to get to node `i`. We want to iterate layer by layer `k + 1` times since we are allowed `k` stops between the source and destination node. On each iteration we will first create a temporary prices array, then we will iterate through each edge which is given to us by the `flights` input array. Upon each edge we encounter we first check if the node is reachable, if it is not then we will continue otherwise we will check if the price to reach the current node plus the price to reach the destination node is lesser than the price at the destination node. If this is true we will replace the cost at the destination node with the new minimum value, otherwise we will continue.

Once we finish iterate through `k + 1` levels we will check the minimum cost it took with at most `k` stops to get to the destination node. If the value is infinity, it means it wasn't able to be reached within `k` stops and we return `-1`, otherwise we will return the minimum cost given by `prices[dst]`.

```python
class Solution(object):
    def findCheapestPrice(self, n, flights, src, dst, k):
        prices = [float('inf')] * n
        prices[src] = 0

        for i in range(k + 1):
            tempPrices = list(prices)

            for node, dest, price in flights:
                if prices[node] == float('inf'):
                    continue
                if prices[node] + price < tempPrices[dest]:
                    tempPrices[dest] = prices[node] + price

            prices = tempPrices

        if prices[dst] == float('inf'):
            return -1
        return prices[dst]
```

> Time Complexity : `O(E * K)`
> 
> Space Complexity : `O(n)`
