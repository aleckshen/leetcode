For this problem we want the minimum cost to connect all points on a 2D plane. We can use prims algorithm which finds a minimum spanning tree with minimal edge costs. First we will start by visualizing each coordinate as a node from `0 - n-1`, we will create a adjacency list containing `(weight, node)` pairs where each node will have a `(weight, node)` pair to every other node/coordinate.

We will have a variable `res` that will be incremented each time we find a minimum weight edge to connect onto our spanning tree, a hash set `visited` that will keep track of visited nodes and a min heap that will be initialized with a weight of 0 at node 0.

While the length of the visited set is lesser then the number of coordinates we will pop the minimum edge weight node in the min heap. First we will check if its in the visited set, if it is we will skip this iteration, otherwise we will continue with the rest of the code. If its not in the visited set, we will add the current node to the visited set, increment out result variable by the weight of the node and push every adjacent node/coordinate as `(weight, node)` pairs into the min heap.

Once we have visited all nodes and connected each node to our spanning tree the while loop will stop and we can return the result variable representing the minimum cost to connect all coordinates.

```python
class Solution(object):
    def minCostConnectPoints(self, points):
        adj = { i:[] for i in range(len(points))} #(weight, node) pairs
        for i in range(len(points)):
            x, y = points[i]
            for j in range(i + 1, len(points)):
                x1, y1 = points[j]
                dist = abs(x - x1) + abs(y - y1)
                adj[i].append((dist, j))
                adj[j].append((dist, i))

        res = 0
        visited = set()
        minHeap = [(0, 0)]

        while len(visited) < len(points):
            weight, node = heapq.heappop(minHeap)
            if node in visited:
                continue
            visited.add(node)
            res += weight
            for neiWeight, neiNode in adj[node]:
                heapq.heappush(minHeap, (neiWeight, neiNode))

        return res
```

> Time Complexity : `O(n^2 * log n)`
> 
> Space Complexity : `O(n^2)`
