For this problem we can iterate through every cell in the `m * n` grid. Once we reach a `"1"` representing land we can increment the number of islands by one and run dfs recursively on the current cells adjacent neighbours (horizontal and vertical neighbours). If we reach a `"0"` representing water we will skip the current cell.

Our dfs algorithm will take two parameters `i` and `j` representing the column index and row index respectively. Firstly we will mark the current cell we are on as `"0"`, this will ensure that no cells of land that we have already visited will be repeated. The base case of out dfs algorithm will check if the column or row index is out of bounds or if the current cell we are on is `"0"` representing water, if this is true then we will return. 

The main logic of our dfs algorithm is quite simple, we will just run dfs on the current cells adjacent neighbours which are `i +1, j`, `i, j + 1`, `i - 1, j` and `i, j - 1`. 

After running dfs on every cell in the `m * n` input grid we can return the number of islands.

```python
class Solution(object):
    def numIslands(self, grid):
        rows = len(grid)
        cols = len(grid[0])
        islands = 0

        def dfs(i, j):
            if i < 0 or i >= rows or j < 0 or j >= cols or grid[i][j] == "0":
                return

            grid[i][j] = "0"
            dfs(i + 1, j) #bottom
            dfs(i, j + 1) #right
            dfs(i - 1, j) #top
            dfs(i, j - 1) #left

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == "1":
                    islands += 1
                    dfs(r, c)
                else:
                    continue

        return islands
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
