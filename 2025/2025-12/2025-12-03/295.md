This question is pretty similar to the number of islands leetcode question, I feel like this question comes pretty naturally once you understand it. To see the thought process behind discovering the number of islands in a `m * n` grid you can refer to [Number-Of-Islands](200.md). 

This question will use the same idea as the number of islands leetcode question except this time for each block of land we encounter within a island we will increment a global variale representing the number of cells within the current island. Once we recursively count every cell within the current island, we will compare the number of cells with the max area. This will happen upon each discovery of a `1` cell in the `m * n` grid representing a block of land. After running dfs to count the number of land within a island we will reset the global variable representing the number of land within a island and continue iterating through the input grid.

After iterating through the entire input grid we can return the max area.

```python
class Solution(object):
    def maxAreaOfIsland(self, grid):
        rows = len(grid)
        cols = len(grid[0])
        maxArea = 0
        self.islands = 0

        def dfs(i, j):
            if i < 0 or i >= rows or j < 0 or j >= cols or grid[i][j] == 0:
                return 

            grid[i][j] = 0
            self.islands += 1
            dfs(i + 1, j) #bottom
            dfs(i, j + 1) #right
            dfs(i - 1, j) #top
            dfs(i, j - 1) #left

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1:
                    dfs(r, c)
                    maxArea = max(maxArea, self.islands)
                    self.islands = 0
                else:
                    continue

        return maxArea
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
