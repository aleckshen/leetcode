My original thought to solve this problem was by using recursion, through each step we will have to choices, either we increment our step by one or by two. Each recursive call we will call itself with the current step + 1 and the current step + 2, we will have two base cases. If the current step is equal to n return 1 and if the current step is greater than n then return 0.

```python
class Solution(object):
    def climbStairs(self, n):
        def dfs(i):
            if i == n:
                return 1
            if i > n:
                return 0
            
            return dfs(i + 1) + dfs(i + 2)

        return dfs(0)
```

This solution worked but ended up exceeding the time limit. To solve this problem we can use a bottom up dynamic programming approach. We will start from solving the two smallest sub problems, given `n` steps there is one possible way to reach `n` steps and given `n - 1` steps there is also one possible way to reach `n` steps. To calculate for `n - 2` steps we wall take the number of ways to reach `n - 1` steps plus the number of ways to reach `n` steps. We can notice a pattern, given a integer `x` where `0 <= x <= n - 2`, the number of ways to reach `n` steps from `x` will always be the number of ways `x + 1` can reach `n` steps plus the number of ways `x + 2` can reach `n` steps. Therefore we do not need to actually create a dp array and we can reserver space by storing the two variables within the for loop itself. We will iterate from `0 to n - 1` and and store a temporary variable one, the variable one will then equal to the current value plus by the value two, then we will set the value two to the temporary variable one. We will do this `n - 1` times then return the value one.

```python
class Solution(object):
    def climbStairs(self, n):
        one = 1
        two = 1

        for i in range(n - 1):
            temp = one
            one = one + two
            two = temp

        return one
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
