The recursive solution to this question is to have two options at each index of the input array `coins`, we can either add the current amount of coins at index `i` to the total, or we can add the current amount of coins at index `i + 1` to the total. We will have 3 base cases:
1. If the index goes out of bounds return 0.
2. If the total exceeds the target amount of coins, return 0.
3. If the total is equal to the target amount, return 1.

For the body of the function we will recursively call both of the options said above. 

```python
class Solution(object):
    def change(self, amount, coins):

        def dfs(i, total):
            if i >= len(coins):
                return 0
            if total > amount:
                return 0
            if total == amount:
                return 1

            return dfs(i, total + coins[i]) + dfs(i + 1, total)  

        return dfs(0, 0)
```

This solution works but runs in O(2^n) time complexity. To reduce the time complexity of this solution to O(n * m) we can memoize our sub problems and store them in a cache as `(index, total)` tuples, where the value will represent the number of ways to make change for the remaining amount starting from coin `i` and with the current accumulated total.

```python
class Solution(object):
    def change(self, amount, coins):
        memo = {}

        def dfs(i, total):
            if (i, total) in memo:
                return memo[(i, total)]
            if i >= len(coins):
                return 0
            if total > amount:
                return 0
            if total == amount:
                return 1

            memo[(i, total)] = dfs(i, total + coins[i]) + dfs(i + 1, total)   
            return memo[(i, total)] 

        return dfs(0, 0)
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(n * m)`
