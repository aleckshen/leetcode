To solve this question efficiently we need to recognize that if any value in a triplet at index `i` is greater than the value in the target triplet at index `i` then we need to skip this triplet. This is due to the following reason:
- Given a triplet `(a, b, c)` and a target triplet of `(2, 5, 7)`, if the value `a` is greater than 2 that means given any operation our first value of the triplet will never end up at the specified value of 2. 

To achieve the desired result of the target triplet we must only look for triplets with values `(a, b, c)` where `a`, `b` and `c` are lesser than or equal to the values of the target triplet `(d, c, e)`. We will initially start by setting a dummy triplet value with all three values set to negative infinity. We will iterate through each triplet in the input array `triplets`, if any of the values in the triplet are greater than the corresponding value in the target triplet we will skip this iteration. If all the values are valid we will first check if the triplet itself is equal to the target value, if this is true we return true. Otherwise we will run the given operation on current triplet we are on with the triplet previously.

We will also check if this modified triplet is equal to the target triplet, if it is we will return true. If we iterate through all triplets and have not found a triplet that equals to the target triplet then we will return false.

```python
class Solution(object):
    def mergeTriplets(self, triplets, target):
        res = [float('-inf'), float('-inf'), float('-inf')]    

        for t in triplets:
            if (t[0] > target[0] or
                t[1] > target[1] or
                t[2] > target[2]):
                continue

            if t == target:
                return True

            res = [max(res[0], t[0]),
                   max(res[1], t[1]),
                   max(res[2], t[2])]

            if res == target:
                return True

        return False
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
