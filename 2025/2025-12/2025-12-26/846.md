For this question given a integer array `hand` we need to arrange our hand to form `groupSize` groups of consecutive numbers. First notice that if the number of cards in our hand divided by `groupSize` is not equal to zero then we cant even a valid group of cards. If this is true we can instantly return false, otherwise we will search for a possible arrangement.

We can first create a frequency hashmap of each number in the array `hand`, we will then sort the input list `hand` then iterate through each number in groups of `groupSize` and decrement each numbers frequency in the hashmap we just created. This works because by sorting the list we will always start at the minimum possible element. For each number in the current group we are on we will check if we can decrement the frequency of the number, if this is not possible then it means we cannot create a consecutive group with the current number and we can return false. Otherwise will continue to decrement the frequency of each number until all numbers frequencies will end up at 0. Once this is done the for loop will terminate and we can return true.

```python
class Solution(object):
    def isNStraightHand(self, hand, groupSize):
        if len(hand) % groupSize != 0:
            return False

        freq = Counter(hand)
        hand.sort()
        
        for num in hand:
            if freq[num]:
                for i in range(num, num + groupSize):
                    if not freq[i]:
                        return False
                    freq[i] -= 1

        return True
```

> Time Complexity : `O(n log n)`
> 
> Space Complexity : `O(n)`
