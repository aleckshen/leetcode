The naive way to solve this problem is to find every single sub array within the input array and compare the product of that sub array with a global variable representing the maximum product.

```python
class Solution(object):
    def maxProduct(self, nums):
        maxProduct = nums[0]

        for i in range(len(nums)):
            product = 1
            for j in range(i, len(nums)):
                product *= nums[j]
                maxProduct = max(maxProduct, product)

        return maxProduct
```

This solution however will run in O(n^2) time complexity and exceeds the time limit for larger input sized arrays.

To optimize this we can use dynamic programming, my initial idea was to initialize a dp array where at each index `i` in the dp array we will have a tuple representing the maximum product up to index `i` and a minimum product up to index `i`. This would take into account negative values which was the hard part about the problem. This also handles any 0 values as any value multiplied by zero will equal to zero, so when we encounter a zero in the input array the min and max product tuple will reset to 0.

At the end we can set our maxProduct to negative infinity and iterate through each max product in the dp array to find our resulting max product then return it.

```python
class Solution(object):
    def maxProduct(self, nums):
        dp = [0] * len(nums)
        dp[0] = (nums[0], nums[0]) #(maxProduct, minProduct) pairs

        for i in range(1, len(nums)):
            curr = nums[i]
            prev_max, prev_min = dp[i - 1]

            max_i = max(curr, curr * prev_max, curr * prev_min)
            min_i = min(curr, curr * prev_max, curr * prev_min)

            dp[i] = (max_i, min_i)

        maxProduct = float('-inf')

        for max_i, min_i in dp:
            maxProduct = max(maxProduct, max_i)

        return maxProduct
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
