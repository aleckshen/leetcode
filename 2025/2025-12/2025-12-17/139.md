For this question we want to first construct a dp array that is set to the length of input word `s` plus one. We will initially set the last element to the dp array to true. We will iterate character by character backwards on our input string `s`, for each character we iterate over we will check for all words in `wordDict`. If the sequence of characters at index `i` all the way to end of the string `w (word in the dict we are currently on)`, matches one of the words in `wordDict` then we will set the value at `dp[i]` to be equal to `dp[i + len(w)]`. This checks that the value we are on connects to a valid sequence of words, if it does then `dp[i]` will be set to true, else `dp[i]` will be set to false.

After iterating through each character in the input string `s` and checking for all words in `wordDict`, we can return the value at `dp[0]` which will be true if there's a valid sequence of characters in `wordDict` that make up the input string `s. Otherwise if there isn't a valid sequence of characters then the value at `dp[0]` will be false.

```python
class Solution(object):
    def wordBreak(self, s, wordDict):
        dp = [False] * (len(s) + 1)
        dp[len(s)] = True

        for i in range(len(s) - 1, -1, -1):
            for w in wordDict:
                if (i + len(w)) <= len(s) and s[i:i + len(w)] == w:
                    dp[i] = dp[i + len(w)]
                if dp[i]:
                    break

        return dp[0]
```

> Time Complexity : `O(n^2 * m)`
> 
> Space Complexity : `O(n)`
