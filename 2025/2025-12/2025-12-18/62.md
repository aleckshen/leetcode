My first intuition was to create a recursive dfs approach, where at each step we are given two options, traverse downwards or traverse to the right of the grid. If we reach out of bounds we will return 0 and if we reach the bottom right corner we return 1.

```python
class Solution(object):
    def uniquePaths(self, m, n):

        def dfs(i, j):
            if i >= m or j >= n:
                return 0

            if (i == m - 1) and (j == n - 1):
                return 1

            return dfs(i, j + 1) + dfs(i + 1, j)

        return dfs(0, 0)
```

This solution works but runs in O(2^n), this exceeds the time limit for larger grids. To optimize this we can use dynamic programming, after looking at some hints I noticed that the number of unique paths from any square in the grid is dependant on the number of unique paths from the right square and the bottom square.

We can create a two dimensional dp array where the array is of size `(m + 1) * (n + 1)`, everything is initialized with zeros. The reason the grid has one extra row and column is due to the fact that when we calculate the unique paths from the edges of the grid we can just add by zero instead of handling out of bounds exceptions. We will start by initializing the bottom right corner of the `m * n` grid to 1, this is because the number of unique ways to reach the end point from the left and top of the bottom right corner of the grid is 1.

We can iterate backwards from the dp array  and calculate the current value of `dp[i][j]` to be equal to the value of the right square and bottom square. Of course we first iterate through the dp array we will encounter the bottom right value, we want to skip this so we don't reset this value to 0. After iterate through the whole `m * n` grid the value at `dp[0][0]` will represent the number of unique paths to reach the bottom right corner.

```python
class Solution(object):
    def uniquePaths(self, m, n):
        dp = [[0] * (n + 1) for i in range(m + 1)]
        dp[m - 1][n - 1] = 1
        
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if i == m - 1 and j == n - 1:
                    continue
                dp[i][j] = dp[i + 1][j] + dp[i][j + 1]

        return dp[0][0]
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
