For this question the intuition is to find the longest increasing sub sequence of integers for every number in the input array. At each number we have the option including any number to the right of it to its current position if its greater than the current number. Given any option we choose to include to the current sub sequence, the number we choose will also have a possibility for any other subsequence to the right of its position to be added onto it as long as its greater then the current number. This means that the increasing sub sequence of a number is dependant on the longest increasing sub sequence of all numbers to its right, this continues onto the last number of the input array where the longest increasing sub sequence of it will equal to 1.

We can initialize a dp array which is the size of input array. We will initialize all values to 1 as any number by itself has a sequence of 1. We will iterate through the input array backwards, at each integer `i` we will check for all integers to the right of the current integer `i`. If the integer at index `i` in our input array is lesser than any number to its right, then we will set `dp[i]` to be the maximum between the current integer sequence at `dp[i]` and the integer sequence at `dp[j]` plus by one top include the added on sequence currently.

At the end we can return the maximum value in the dp array which will represent the longest increasing sub sequence.

```python
class Solution(object):
    def lengthOfLIS(self, nums):
        dp = [1] * len(nums)

        for i in range(len(nums) - 1, -1, -1):
            for j in range(i, len(nums)):
                if nums[i] < nums[j]:
                    dp[i] = max(dp[i], 1 + dp[j])

        return max(dp)  
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n)`
