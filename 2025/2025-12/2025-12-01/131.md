To solve this problem we will use backtracking to explore all possible ways to break the string into substrings where each substring is a palindrome. We maintain two lists: `res`, which stores all valid partitions, and `partition`, which holds the current path of palindromic substrings during exploration. Our recursive function `dfs(i)` represents the idea of making partitions starting from index `i` in the string. If `i` reaches the end of the string, it means the current partitioning is complete and valid, so we append a copy of partition to `res`. Otherwise, we iterate `j` from `i` to the end of the string, and for each position we check whether the substring `s[i:j+1]` is a palindrome. If it is, we choose that substring by appending it to partition, then recursively call `dfs(j+1)` to continue partitioning the remainder of the string. After the recursive call returns, we backtrack by removing the substring we just added, ensuring we explore all other possibilities. The helper function isPali checks whether a substring is a palindrome by comparing characters from both ends inward.

```python
class Solution(object):
    def partition(self, s):
        res = []
        partition = []

        def dfs(i):
            if i >= len(s):
                res.append(list(partition))
                return
            for j in range(i, len(s)):
                if self.isPali(s, i, j):
                    partition.append(s[i:j + 1])
                    dfs(j + 1)
                    partition.pop()
        
        dfs(0)
        return res

    def isPali(self, s, l, r):
        while l < r:
            if s[l] != s[r]:
                return False
            l, r = l + 1, r - 1
        return True
```

> Time Complexity : `O(n * 2^n)`
> 
> Space Complexity : `O(n)`
