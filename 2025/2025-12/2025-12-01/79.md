This question requires you to search for a word in a `m * n` grid of characters `board`. If the word can be constructed by using characters that are vertical or horizontal to each other, whilst not reusing the same cells then we can return `True`, otherwise `False`. We need to check for every single cell in the `m * n` grid and recursively check for every single path possible. We will start by creating a nested for loop that checks for every cell within the `board`. On each cell we will run a recursive dfs algorithm that traverses every path possible for the given cell. We will also use a set that is used so repeated paths will not be possible.

When we first create the algorithm we need to think of the parameters we pass in. Firstly we are checking each cell in the `m * n` grid which has a row and column index, so we will pass in a row parameter and a column parameter. We also need to check whether the word we are currently on matches the letter at index `i` in the target word, so we also need a parameter `i` that represents the index we are on. 

For the base case of the recursive algorithm we will have if index `i` reaches the length of the word then we can return `True` as it found a sequence of characters in the grid that matches the target word. The following cases are required to check whether or not our cell is still valid or not:
1. If the column index or row index is out of bounds we return `False`.
2. If the cell we are in is within hash set we return `False`.
3. If the cell we are on is not equal to the character at index `i` in the target word we return `False`.

Now for the recursive logic of the algorithm we will run dfs on 4 possible paths, the cell above the current, the cell to the left of the current, the cell to the bottom of the current and the cell to the right of the current. When we run dfs on these 4 possible paths we will also increment `i` by one which shows that a character in the sequence has been found. We will return the `True` if any of these 4 paths return `True`.

We will recursively run dfs on each cell from the nested for loop we created at the start and return `True` if the current cell returns a path that is valid. Otherwise if we traverse through the whole grid and no valid paths are found then we will return `False`.

```python
class Solution(object):
    def exist(self, board, word):
        rows = len(board)
        cols = len(board[0])
        seen = set()

        def dfs(r, c , i):
            if i == len(word):
                return True
            
            if (r < 0 or c < 0 or 
                r >= rows or c >= cols or
                board[r][c] != word[i] or
                (r, c) in seen):
                return False

            seen.add((r, c))
            res = (dfs(r + 1, c, i + 1) or
                dfs(r, c + 1, i + 1) or 
                dfs(r - 1, c, i + 1) or
                dfs(r, c - 1, i + 1))

            seen.remove((r, c))
            return res

        for r in range(rows):
            for c in range(cols):
                if dfs(r, c, 0):
                    return True

        return False
```

> Time Complexity : `O(m * 4^n)`
> 
> Space Complexity : `O(n)`
