For this solution I originally thought to create a adjacency list and run dfs on the node `k` to search for the minimum time on the current nodes adjacent nodes. Once it reached a leaf node it would return the minimum time. However I was assuming that the graph was acyclic and my solution first ran into a infinite recursion loop. I then implemented a visited set that would take care of any loops, however it still didn't solve the problem of the minimum time it would take for a the signal to reach all nodes as it traverses by depth.

            if len(visited) == n:
                self.minTime = max(self.minTime, totalTime)

        if len(visited) == n:

To improve this solution with some hints, I create d a distant adjacency list. The list represents the time it takes for for a signal to reach that node from node `k`. Initially all nodes distances are set to positive infinity, we will traverse through every node and its adjacent neighbors recursively. Upon each traversal of a node we can set the distance of the node in the distance adjacency list to the current time, we will also have a base case that takes into account of cycles.

we will call dfs on node `k` with the current time initially set to 0. After the algorithm is run we can take the maximum distance from the distance adjacency list. If the value is infinity that means one of the nodes are unreachable and we can return -1, otherwise we will return the minimum distance.

```python
class Solution(object):
    def networkDelayTime(self, times, n, k):
        adj = { i:[] for i in range(n + 1)}

        for node, target, time in times:
            adj[node].append((target, time)) #target, time tuples

        dist = {node: float("inf") for node in range(1, n + 1)}

        def dfs(node, currTime):
            if currTime >= dist[node]:
                return 

            dist[node] = currTime
            for target, time in adj[node]:
                dfs(target, currTime + time)

        dfs(k, 0)
        minTime = max(dist.values())

        if minTime == float('inf'):
            return -1
        return minTime
```

Decided to learn a more efficient way of solving the problem from using dijkstra's algorithm by running a bfs algorithm using a priority queue/min heap. It resulted in a much more efficient time complexity of O(E * log(V)) instead of my original solutions time complexity of O(V * E).

```python
class Solution(object):
    def networkDelayTime(self, times, n, k):
        edges = { i:[] for i in range(1, n + 1)}
        for node, neighbour, weight in times:
            edges[node].append((neighbour, weight))

        minHeap = [(0, k)]
        visited = set()
        time = 0
        
        while minHeap:
            currWeight, currNode = heapq.heappop(minHeap)
            if currNode in visited:
                continue

            visited.add(currNode)
            time = max(time, currWeight)

            for node, weight in edges[currNode]:
                if node not in visited:
                    heapq.heappush(minHeap, (weight + currWeight, node))

        if len(visited) == n:
            return time
        return -1
```

> Time Complexity : `O(E * log(V))`
> 
> Space Complexity : `O(V + E)`
