This question is a continuation of the previous course schedule question. Instead this time we want to append nodes to a output list in topological order, the ordering in our output list should ensure a student can take every single course in the order of the list starting from index 0. 

We will first create a adjacency list for every single course, this time we will use two hash sets, one for cycles and one for courses that are already visited. Our dfs function will be similar to the previous course schedule question, we will have two base cases:
1. If the course we are currently on is already in the cycle set we return false as we have encountered a cycle.
2. The course we are on has already been visited before so we can instantly return true to avoid redundant code.

For the body of our dfs function we will first add the current course to the cycle set, next we will traverse through each course in the current courses prerequisites and run dfs on all the following courses too. If any of those courses contain a cycle then we will instantly return false. Otherwise if all of the courses prerequisites are valid, then we can remove the current course from the cycle set and add the current course to the visited set. Since this shows that the current course is valid and does not contain cycles, we can append it to the output list and return true.

We will run this dfs function on every single course and if any course returns false then we will return a empty list, otherwise we will return the output list at the end of the for loop.

```python
class Solution(object):
    def findOrder(self, numCourses, prerequisites):
        prereq = {i: [] for i in range(numCourses)}
        for crs, pre in prerequisites:
            prereq[crs].append(pre)

        visited = set()
        cycle = set()
        res = []

        def dfs(course):
            if course in cycle:
                return False
            if course in visited:
                return True

            cycle.add(course)
            for pre in prereq[course]:
                if not dfs(pre):
                    return False

            cycle.remove(course)
            visited.add(course)
            res.append(course)
            return True

        for i in range(numCourses):
            if not dfs(i):
                return []

        return res
```

> Time Complexity : `O(V + E)`
> 
> Space Complexity : `O(V + E)`
