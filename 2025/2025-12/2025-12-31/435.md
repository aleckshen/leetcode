For this question we can initially sort the input array `intervals` by their starting interval value. We will set a variable `prevEnd` which represents the previous end interval value of the interval we iterating over, this will initially be set to the end interval value of the first interval in `intervals`. When we iterate over `intervals` we will start from the second interval. We will also have a variable `count` will check keep track of the minimum number of intervals we need to erase to achieve non-overlapping intervals.

For each interval we iterate over we will check if the previous intervals end value is greater then the current intervals start value. If this is true then we need to erase a interval so we can increment count by 1, but we also need to take into account that both of these intervals could be erased. The question requires us to achieve the minimum number of erasures possible, so in this case we will set the previous end interval value to be the minimum of the two end intervals. 

If the intervals do not overlap then we can just set `prevEnd` to the current intervals end value. Once we iterate through all intervals in `intervals` then we can return `count`.

```python
class Solution(object):
    def eraseOverlapIntervals(self, intervals):
        intervals.sort()
        count = 0

        prevEnd = intervals[0][1]
        for i in range(1, len(intervals)):
            if prevEnd > intervals[i][0]:
                count += 1
                prevEnd = min(prevEnd, intervals[i][1])
                continue
            prevEnd = intervals[i][1]

        return count
```

> Time Complexity : `O(n log n)`
> 
> Space Complexity : `O(n)`
