This problem is pretty similar to the previous question climbing stairs. To solve this problem I first noticed that given the choice of taking one step or two steps we always want to take the step that is the minimum cost between the two steps. This means that the minimum cost of step `i` will always depend on the minimum of `i + 1` and `i + 2`. If we iterate through the list backwards and take the cost at index `i` and add it with the minimum cost between `i + 1` and `i + 2`, then the cost at index `i` will now represent the minimum cost it takes to reach the top of the staircase from that point.

We will first append `0` to the input list as we want the second to last value being able to calculate the minimum cost of adding 2 steps too. Then we will iterate through the list backwards and updates `cost[i]` to be `cost[i]` plus the minimum of `cost[i + 1]` and `cost[i + 2]`. Once we iterate through the entire list we can return the minimum of the cost at index `0` and the cost at index `1` as those are the two possible positions we are allowed to start at.

```python
class Solution(object):
    def minCostClimbingStairs(self, cost):
        cost.append(0)
        for i in range(len(cost) - 3, -1, -1):
            cost[i] += min(cost[i + 1], cost[i + 2])

        return min(cost[0], cost[1])
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
