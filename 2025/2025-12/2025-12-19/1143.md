My first though to solve this problem is to iterate through each character in `text1`, for each string in `text1` we will iterate through each character in `text2`. If the strings match we will increment our sequence count by 1 and continue running dfs on both index pointers shifted by one. If they are not equal twe have two possible options, either we shift our pointer for `text1` by one and leave the current pointer of `text2` at its current position or leave the pointer at `text1` on its current position and shift the pointer for `text2` by one. We will return the maximum value between these two decisions.

At the end we will run dfs from both characters at their starting character and return the longest common sub sequence.

```python
class Solution(object):
    def longestCommonSubsequence(self, text1, text2):

        def dfs(i, j):
            if i == len(text1) or j == len(text2):
                return 0

            if text1[i] == text2[j]:
                return 1 + dfs(i + 1, j + 1)
            
            return max(dfs(i, j + 1), dfs(i + 1, j))

        return dfs(0, 0)
```

We end up repeating a lot of sub problems when the length of each input texts are large. To optimize this we can memoize our sub problems by storing them in a hashmap as `(i, j)` keys. This will reduce the time complexity from O(2^n) to O(m * n).

```python
class Solution(object):
    def longestCommonSubsequence(self, text1, text2):
        memo = {}

        def dfs(i, j):
            if i == len(text1) or j == len(text2):
                return 0
            if (i, j) in memo:
                return memo[(i, j)]

            if text1[i] == text2[j]:
                memo[(i, j)] = 1 + dfs(i + 1, j + 1)
            else:
                memo[(i, j)] = max(dfs(i, j + 1), dfs(i + 1, j))

            return memo[(i, j)] 

        return dfs(0, 0)
```

> Time Complexity : `O(m * n)`
> 
> Space Complexity : `O(m * n)`
