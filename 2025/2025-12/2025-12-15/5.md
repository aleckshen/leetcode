The naive solution to this question is to find all possible substrings of input string `s` and check if each one is a palindrome or not. If it is we can append it to a list of valid palindromes and return the longest length palindrome within that list

```python
class Solution(object):
    def longestPalindrome(self, s):
        palindromes = []
        for i in range (len(s)):
            for j in range(len(s)):
                if self.isPalindrome(s, i, j):
                    palindromes.append(s[i:j + 1])

        longest = ""
        for palin in palindromes:
            if len(palin) > len(longest):
                longest = palin
        
        return longest
        
    def isPalindrome(self, string, i, j):
        while i < j:
            if string[i] == string[j]:
                i += 1
                j -= 1
            else:
                return False
        return True 
```

This is pretty inefficient as the solution uses a nested for loop along side a helper function which calculates if the current substring is a palindrome. This results in a time complexity of O(n^3), this solution exceeds the time limit for longer string input test cases. To optimize this solution we can start our pointer from the middle and expand outwards to check if it's a palindrome or not. 

For each letter in the input string `s` we need to expand left and right pointers outwards to check if its a palindrome or not, solving the problem this way will reduce the time complexity to O(n^2). 

There are two cases that we have to take into account when solving this problem:
1. The input string is of odd length, we will set our left and right pointers to the same index `i` and shift outwards.
2. The input string is of even length, we will set our left and right pointers to index `i` and `i + 1` respectively and shift outwards.

During each computation we just need to check whether the the current letter the two pointers are pointing at is equal. If they are we can check if the length of the current substring is longer than the result substring to update it or not, then we can shift our pointers. 

After we run both while loops for even and odd cases we can return the resulting substring.

```python
class Solution(object):
    def longestPalindrome(self, s):
        res = ""

        for i in range(len(s)):
            #odd length case
            l, r = i, i
            while l >= 0 and r < len(s) and s[l] == s[r]:
                if (r - l + 1) > len(res):
                    res = s[l:r + 1]
                l -= 1
                r += 1

            #even length case
            l, r = i, i + 1
            while l >= 0 and r < len(s) and s[l] == s[r]:
                if (r - l + 1) > len(res):
                    res = s[l:r + 1]
                l -= 1
                r += 1

        return res
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O()`
