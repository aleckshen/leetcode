For this question my initial thought was to recursively traverse through the left and right subtree from the root node and check if the left child node of each node is lesser than the current node, and if the right child node of each node is greater than the current node. However I encountered a error along the way, we need to ensure that ALL subtrees within the tree are valid binary search trees.

Then we need to keep track of a maximum and minimum value when traversing through each subtree. While we traverse through a left node we must ensure the range is between the current minimum and the parent node. While traversing through a right node we must ensure the range is between the current maximum value and the parent node. While these conditions are true we can continue to traverse the tree using dfs. We want to return a boolean value for both left and right subtree where if either conditions are false for each subtree, we return `False`. If both subtrees traverse through the whole subtree we will reach the base that handles `None` type nodes and return `True`.

```python
class Solution(object):
    def isValidBST(self, root):

        def dfs(node, currMin, currMax):
            if not node:
                return True

            if currMin >= node.val or node.val >= currMax:
                return False

            return dfs(node.left, currMin, node.val) and dfs(node.right,    node.val, currMax)

        return dfs(root, float('-inf'), float('inf'))
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
