Intuitively we can look at this question and find the target sum using a nested for loop to check for all pairs of
elements that sum up to the target value, then return the indices of each loop. However this is not optimal as it
results in a time complexity of O(n^2).

To optimize the run time we can use a hashmap that stores the key as the value of a num if the target - num is not in the 
hashmap and the value as the index of the num. If the target value - num is in the hashmap then we have the two values that sum to the target and we can return the current index of the value in the for loop and the index of the value in the hashmap.
This results in a time complexity of O(n) as only one iteration of a for loop is required.

```python
class Solution(object):
    def twoSum(self, nums, target):
        dic = {}

        for i in range(len(nums)):
            if target - nums[i] in dic:
                return [i, dic[target - nums[i]]]
            else:
                dic[nums[i]] = i
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
