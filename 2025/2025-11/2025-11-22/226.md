For this question we need to invert each node in the left subtree, with each node in the right subtree. We can do this with a recursive DFS approach. We will have a stopping condition the checks if the root node is none, if its not then we will recursively call the invert tree function for the left subtree and the right sub tree. Once both subtrees are inverted we can return the root node.

```python
class Solution(object):
    def invertTree(self, root):
        if not root:
            return None

        temp = root.left
        root.left = root.right
        root.right = temp

        self.invertTree(root.left)
        self.invertTree(root.right)

        return root
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
