This question is pretty simple after doing the finding minimum in rotated sorted array question. To start off we have to achieve this in a time complexity of O(log n), so we need to find a solution using binary search. Since the input array is rotated we know that there are two sorted portions of the array. We need to be able to identify if either the left portion of the array is sorted or if the right portion of the array is sorted. 

We will first initialize two pointers `l, r` that represents the left most value and the right most value respectively. While the left pointers is lesser than or equal to the right pointer we will run the search algorithm. First we compute the middle index `(l + r) // 2`. We will always check if this value is equal to the target value, if it is we will return the index, otherwise we will either search the left portion of the array or the right portion of the array.

We can check if the left portion of the array is sorted with `nums[l] <= nums[mid]`. If this is true then the values between the left pointer and the middle index are sorted. We can check if the target value lies within this range, if it is we continue binary search in the left sorted portion of the array, otherwise we continue binary search in the right portion of the array.

If `nums[l] <= nums[mid]` evaluates to false, we know that the right portion of the array is sorted. This means that the values between the middle index and the right pointer are sorted. We can check if the target values within this range if it is we continue binary search in the right sorted portion of the array, otherwise we continue binary search in the left portion of the array.

This covers all cases and if the target value isn't within the input array the left and right pointers will converge past each other and we will return `-1`.

```python
class Solution(object):
    def search(self, nums, target):
        l, r = 0, len(nums) - 1

        while l <= r:
            mid = (l + r) // 2

            if nums[mid] == target:
                return mid

            # Left half is sorted
            if nums[l] <= nums[mid]:
                if nums[l] <= target < nums[mid]:
                    r = mid - 1
                else:
                    l = mid + 1

            # Right half is sorted
            else:
                if nums[mid] < target <= nums[r]:
                    l = mid + 1
                else:
                    r = mid - 1

        return -1
```

> Time Complexity : `O(log n)`
> 
> Space Complexity : `O(1)`
