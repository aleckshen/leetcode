Looking at this problem I first thought to append all nodes in the right subtree to a results list, also while we traverse the right sub tree we also want to keep track of the depth of the right subtree. While we traverse the left subtree we can append nodes to the results list if the depth of the left subtree exceeds the depth of the right subtree. I tried implementing this with a dfs approach and had issues with depth calculations. 

I ended up opting for a bfs approach, I found that this problem can be handled easier looking at nodes level by level and returning the right most node in each level. We can start by initializing a queue with the root node, while the queue is not empty we can run the following operations:
1. Initialize a variable `rightNode` that will represent the right most node in the level.
2. Pop each node in the current level from left to right and append its children to the queue.

Once we pop all nodes from a level in the tree we can append the `rightNode` variable to the results list while its not `None`. Once the queue is empty the results list will contain all the right most nodes in each level.

```python
class Solution(object):
    def rightSideView(self, root):
        res = []
        queue = collections.deque([root])

        while queue:
            rightNode = None

            for i in range(len(queue)):
                node = queue.popleft()
                if node:
                    rightNode = node
                    queue.append(node.left)
                    queue.append(node.right)

            if rightNode:
                res.append(rightNode.val)

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
