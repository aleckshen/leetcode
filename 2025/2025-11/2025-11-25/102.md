I feel like the solution to this question was pretty intuitive, we just need to store each levels nodes from left to right in a temporary list and append that to a results list. The obvious approach to this is to use a bfs traversal as it checks from level to level. We will start by using a queue and appending the root value to it. While the queue is non empty we will create a empty list `level` that represents the nodes from each level. We will iterate through each node in the current queue and pop each node, upon pop of each node we will check if the node is not `None`. If this is true we will append the node to the `level` array and also append the left and right values of the node to the queue. The last check we will do is if the `level` array is non empty, this is to ensure that we don't append any empty lists to the results list.

After popping all nodes from the queue the while loop will stop and we can return the results variable that represents each levels nodes from left to right.

```python
class Solution(object):
    def levelOrder(self, root):
        res = []
        queue = collections.deque()
        queue.append(root)

        while queue:
            level = []

            for i in range(len(queue)):
                node = queue.popleft()
                if node:
                    level.append(node.val)
                    queue.append(node.left)
                    queue.append(node.right)

            if level:
                res.append(level)

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
