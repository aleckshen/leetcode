For this problem we need to think about all the possible cases for identifying a lowest common ancestor. Note that given the current `root` node, if node `q` is lesser then the `root` node then it must be in the left subtree and if node `q` is greater then then `root` node then it must be in the right subtree. This property of the binary search tree helps us simply the solution. There will be three distinct cases:
1. `p` is in the left subtree and `q` is in the left subtree. We will set the current node to the left node and continue traversing the left subtree.
2. `p` is in the right subtree and `q` is in the right subtree. We will set the current node to the right node and continue traversing the right sub tree.
3. One node lies on each side of the current node or if one of them matches the current node—then the current node is the point where their paths diverge and we can return the current node.

```python
class Solution(object):
    def lowestCommonAncestor(self, root, p, q):
        current = root

        while current:
            if p.val < current.val and q.val < current.val:
                current = current.left
            elif p.val > current.val and q.val > current.val:
                current = current.right
            else:
                return current
```

> Time Complexity : `O(h)`
> 
> Space Complexity : `O(1)`
