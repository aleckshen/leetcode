For this question we just need to initialize a previous variable that stores the previous node, and a current variable that stores the current node. The previous variable is set to null initially and the current variable is set to the head. While the current variables next pointer is not null, we can iterate through the current linked list and reverse the pointers. We first set a temporary variable next that stores the next node in the current linked list then we will set the current nodes next pointer to the previous node, then we set the previous node to the current variable and finally we set the current variable to the temporary variable next we set initially. When the current pointer points to null we will have reached the end of the linked list and the previous variable will be the new head of the linked list and we can return the linked last starting from the previous variable.

```python
class Solution(object):
    def reverseList(self, head):
        current = head
        prev = None

        while current:
            nxt = current.next
            current.next = prev
            prev = current
            current = nxt

        return prev
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
