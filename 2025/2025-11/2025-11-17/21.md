For this question we can create a a dummy node that is initialized to zero and the next pointer is set to `None`. We will then create a tail tail variable that represents the dummy node that we created. We want insert variables into our linked list while `l1` and `l2` are non-empty, this will be the condition for our while loop. While this condition is true we will compare the head of `l1` with the head of `l2`, if the head of `l1` is lesser then the head of `l1` then we will insert this value into the linked list we initialized, else we will insert the head of `l2` into the linked list we initialized. 

Notice that our while loop only runs while both `l1` and `l2` are non-empty, well what if one of the linked list's length is longer than the other? This fix is pretty simple as when one of the linked lists become empty, we can just insert the pointer of the last variable in our linked list to the first variable in the non-empty linked list. After this we can return the next variable of the dummy node we initialized at the start as that represents the start of our linked list.

```python
class Solution(object):
    def mergeTwoLists(self, list1, list2):
        dummy = ListNode()
        tail = dummy

        while list1 and list2:
            if list1.val < list2.val:
                tail.next = list1
                list1 = list1.next
            else:
                tail.next = list2
                list2 = list2.next
            tail = tail.next

        if list1:
            tail.next = list1
        elif list2:
            tail.next = list2

        return dummy.next
```

> Time Complexity : `O(n + m)`
> 
> Space Complexity : `O(1)`
