We need to find the minimum element in this array in O(log n) time, this means that we need to implement binary search to find this element. We know that the input array is sorted in increasing order, however the array can be rotated any amount of times. My initial thought is to initialize two pointers, one left pointer at the starting index, and one right pointer and the last index. We will search for the minimum value while the left pointer is lesser than the right pointer. First we can calculate the mid point of the array by adding the left pointer and the right pointer divided by 2 rounded down. 

What we need to do is to come up with a condition to either search the left side of the array or the right side of the array. Notice that if the value at the middle of the array is lesser than the right most value then the right portion of the array is sorted and we can run binary search on the left portion of the array. However the midpoint could also still be the minimum value so we set the new right pointer to the mid point of the array. If the value at the middle of the array is greater than or equal to the right most value then we know that the left portion of the array is sorted and we can run binary search on the right portion of the array. The current mid point value cannot be the minimum value as it is greater the or equal to the right most value so we set out left pointer to the mid point of the array plus one.

Eventually our points will converge and the element that both pointers land on will be the minimum element of the input array.

```python
class Solution(object):
    def findMin(self, nums):
        l, r = 0, len(nums) - 1

        while l < r:
            mid = (l + r) // 2
            if nums[mid] < nums[r]:
                r = mid
            else:
                l = mid + 1

        return nums[l]
```

> Time Complexity : `O(log n)`
> 
> Space Complexity : `O(1)`
