Looking at the constraints we know that the number of hours the guards are gone for is greater then or equal to the length of the input list. This lets us know that the maximum value `k` will be the maximum value in the input list `piles`. We also know that the minimum value of `k` will be `1` as having a minimum value of `0` would mean no bananas being consumed each hour. Now we know the range of values of `k` that we can test for to see if koko eating `k` bananas each hour would be lesser than or equal to `h` hours. After establishing our range of values we could test for every individual value `k` which would take O(n * k) time, however if we implement a binary search algorithm we can find the value `k` in O(n * log(k)) time. The time that it takes for koko to eat a pile of bananas can be calculated by taking the ceiling of `x / k`, where `x` is the number of bananas in `pile[i]` and `k` is the number of bananas consumed each hour that we are testing for.

We can now set two pointers, where the left pointer is equal to `1` and the right pointer is equal to `max(piles)`. While the left pointer is lesser than or equal to the right pointer we can initialize our `k` variable by taking the floor of the `l + k`. This variable `k` will be the amount of bananas consumed by koko each hour that we test for. We will initialize a total time variable that calculate the hours taken for koko to eat `k` bananas each hour. After iterating through the list we can compare the total time we calculate with the `h` hours it takes for guards to get back. We get two cases:
1. If the total time it took for koko to eat all the bananas in `piles` is lesser than or equal to `h` that means that we have found a valid `k` that could be our solution, we will store this in a result variable. However there could still be a smaller minimum value `k` that exists in our range, so we will set our right pointer to `k - 1` and continue our binary search.
2. If the total time it took for koko to eat all the bananas in `piles` is great than `h` that means that our answer is invalid and we need to set out left pointer to `k + 1` to find a value `k` that is greater to ensure koko is able to eat all bananas.

Once the two pointers converge past each other, we can return our result variable which will represent the minimum bananas koko can eat before the guards come back after `h` hours.

```python
class Solution(object):
    def minEatingSpeed(self, piles, h):
        l, r = 1, max(piles)
        res = max(piles)

        while l <= r:
            k = (l + r) // 2
            totalTime = 0
            for banana in piles:
                totalTime += math.ceil(float(banana) / k)

            if totalTime <= h:
                res = k
                r = k - 1
            else:
                l = k + 1

        return res
```

> Time Complexity : `O(n * log(m))`
> 
> Space Complexity : `O(1)`
