There exists a cycle in a linked list if there exists a pointer in the linked list that points backwards to a previous node. Essentially we need to iterate over the nodes in our linked list and check whether the next node in the list has already been visited. To do this my first thought was to create a set that stores each node we iterate over it in it. We can iterate over the linked list while the node isn't in this set otherwise we return false. If we iterate through the entire linked list and we can return true as there are no cycles.

```python
class Solution(object):
    def hasCycle(self, head):
        nodes = set()
        curr = head

        while curr:
            if curr in nodes:
                return True
            nodes.add(curr)
            curr = curr.next

        return False
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
