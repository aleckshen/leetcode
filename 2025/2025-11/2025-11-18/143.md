For this question we need to have a reference to the starting node and the end node. My thought is to first initialize a node that represents the first node in the linked list. Then we can iterate through the linked list to store a reference to the last node in the linked list. I realized here that this approach would not work as the pointers of the second half of the list need to be reversed. I then thought about how I could reverse the second half of the list, then store a reference to the end node of the linked list. One way to do this is through the use of fast and slow pointers. We set the slow pointer to the first node of the linked list and the fast pointer to the second node of the linked list, every time we increment the slow pointer by one we increment the fast pointer by 2. Once the fast pointer reaches the last node of the linked list or the value none, we know that the slow pointer has reached the last node of the first half of the list and we will set that nodes next pointer to null which references the end of the list. Once this is down we can use a while loop and while the second half of the lists pointer is not null we can merge the two linked lists together.

```python
class Solution(object):
    def reorderList(self, head):
        slow, fast = head, head.next

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        second = slow.next
        prev = slow.next = None

        while second:
            nxt = second.next
            second.next = prev
            prev = second
            second = nxt

        first, second = head, prev

        while second:
            first_nxt = first.next
            second_nxt = second.next
            first.next = second
            second.next = first_nxt
            first = first_nxt
            second = second_nxt
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
