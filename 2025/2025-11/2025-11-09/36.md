My first thoughts while looking at this problem was to think about a optimal way to check for duplicates in rows and columns. Here we can utilize a hash set that represents if values are seen or not for every single row and every single column. The tricky part here is to figure out how to check for duplicates in each 3 x 3 grid. For each row and column we have integers from 0-8, we need to find a way in which we can group every index together into 3 groups, 0-2, 3-5 and 6-8. We can achieve this by taking the floor of every index divided by 3. This will ensure that indices 0-2 // 3 will represent the index 0, 3-5 // 3 will represent the index 1 and 6-8 // 3 will represent the index 2. We will construct three hash sets, one for rows, one for columns and one for each 3 x 3 grid. Through each element we iterate over in the board we will check if these values exist in each hash set and return false if they do otherwise return true if we successfully iterate through the whole board.

```python
class Solution(object):
    def isValidSudoku(self, board):
        rows = defaultdict(set)
        cols = defaultdict(set)
        squares = defaultdict(set)

        for r in range(9):
            for c in range(9):
                if board[r][c] == ".":
                    continue
                if board[r][c] in rows[r] or board[r][c] in cols[c]:
                    return False
                if board[r][c] in squares[(r // 3, c // 3)]:
                    return False
                rows[r].add(board[r][c])
                cols[c].add(board[r][c])
                squares[(r // 3, c // 3)].add(board[r][c])

        return True 
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(n^2)`
