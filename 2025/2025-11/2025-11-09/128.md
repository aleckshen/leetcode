We need to return the longest consecutive sequence of numbers, however the solution needs to run in O(n) time so sorting the array and iterating through it wouldn't work as that runs in O(n log n) time. My second thought is to iterate over each number in `nums` and store each number in a hashmap, with the corresponding value being a count of the consecutive sequence of numbers it has. To do this we can consider three if statement.

1. If the number is already in the hashmap we skip this to not increment duplicate values.
2. If the `number + 1` is in the hashmap ONLY, or if the `number - 1` is in the hashmap ONLY, we can check the sequence counter of that value in the hashmap and increment it by 1 and store it in the sequence counter of the current number we are iterating over.
3. If the `number + 1` is in the hashmap AND the `number - 1` is in the hashmap, we sum together the two sequence counters of the `number + 1` and the `number - 1` then + 1 again for the current number being added in the sequence.

After thinking a little more about this solution I realized a error, the sequence counter of all numbers that are consecutive don't all get updated. Only the ones that are checked within the if statement are updated. I also realized that only the sequence counters of the left most values and right most values in a sequence counter need to be updated. For example given a sequence `[1, 2, 3]` the only possible values that could increment the sequence would be 4 or 0, therefore the number `[2]`'s sequence counter would not need to be updated. After realizing this we can update our if statements:

1. If the number is already in the hashmap we skip this to not increment duplicate values.
2. If the `number + 1` is in the hashmap AND the `number - 1` is in the hashmap, we sum together the two sequence counters of the left most values and the right most values and update them.
3. If the `number + 1` is in the hashmap, we add the sequence counter of the `number + 1` by 1 and store it in the current number we are iterating over. We also store this sequence counter in the right most consecutive number by using the sequence counter of the `number + 1` added onto the current number to then retrieve the value of the right most value.
4. If the `number - 1` is in the hashmap, we add the sequence counter of the `number - 1` by 1 and store it in the current number we are iterating over. We also store this sequence counter in the left most consecutive number in the sequence by using the sequence counter of the `number - 1` subtracted onto the current number to retrieve the value of the left most value.

```python
class Solution(object):
    def longestConsecutive(self, nums):
        seq_count = {}

        if nums == []:
            return 0

        for num in nums:
            if num in seq_count:
                continue
            elif num + 1 in seq_count and num - 1 in seq_count:
                count = seq_count[num - seq_count[num - 1]] + seq_count[
                    num + seq_count[num + 1]] + 1
                seq_count[num] = count
                seq_count[num - seq_count[num - 1]] = count
                seq_count[num + seq_count[num + 1]] = count
            elif num + 1 in seq_count:
                seq_count[num] = seq_count[num + 1] + 1
                seq_count[num + seq_count[num + 1]] = seq_count[num]
            elif num - 1 in seq_count:
                seq_count[num] = seq_count[num - 1] + 1
                seq_count[num - seq_count[num - 1]] = seq_count[num]
            else:
                seq_count[num] = 1

        return max(list(seq_count.values()))
```

My code has a lot of redundant checks, with inefficient space utilization which made my code run at a really slow rate. After looking at the optimal solution I changed up my code. We can start by creating a create a hash set of all the numbers in `nums`. Note that the starting sequence of a number is a number that has no left neighbours. We can iterate through the array `nums` and check if `number - 1` is not in the hash set, this ensures that it is a starting sequence of a number. If we do have a starting sequence of a number we can use a while loop to check the length of the sequence. With each distinct sequence we can use a max function that compares the current sequence with the longest sequence thats stored previously (initially set to 0) to then return the longest consecutive sequence.

```python
class Solution(object):
    def longestConsecutive(self, nums):
        hashSet = set(nums)
        longestSeq = 0

        for num in hashSet:
            if (num - 1) not in hashSet:
                length = 1
                while (num + length) in hashSet:
                    length += 1
                longestSeq = max(length, longestSeq)

        return longestSeq
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
