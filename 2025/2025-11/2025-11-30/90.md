This question is a continuation of the subset part 1 problem. In the first subset problem we were given a input array of distinct integers. However for this problem we are given a input array that may contain duplicate integers.

If we tackled the problem initially we would encounter duplicate subsets values. One way to avoid this is to sort the list and change the position of the index pointer while we pop values from out subset. Notice that these duplicate subsets appear from the decision made when popping values from the subset list then append values. For example given the input array `[1, 2, 2]`, when we draw the decision tree for this array we encounter a stage where we have the subset `[1, 2, 3]` and the subset `[1]`. If we make the choice to pop the value from `[1, 2, 3]` then we get `[1,2]`, however if we also choose to append the value from index `i` to [1] then we also get `[1, 2]`. 

This is the main problem we need to solve. Since our input list is sorted we know that these duplicate subsets encounter when the same values branch into different decisions. We also know that these duplicate subsets only occur when we pop from the temporary subset list and try to append another variable. One way to remove this issue is to shifts the index `i` while its in bounds of the length of the input list and the number adjacent to it is equal to the current number. This will ensure that when we encounter adjacent values (duplicate numbers), the index pointer will be shifted before popping so that when its ready to append another variable it wont reuse duplicate variables. 

```python
class Solution(object):
    def subsetsWithDup(self, nums):
        nums.sort()
        res = []
        subset = []

        def dfs(i):
            if i >= len(nums):
                res.append(list(subset))
                return

            subset.append(nums[i])
            dfs(i + 1)

            while i + 1 < len(nums) and nums[i] == nums[i + 1]:
                i += 1
            subset.pop()
            dfs(i + 1)

        dfs(0)
        return res
```

> Time Complexity : `O(n * 2^n)`
> 
> Space Complexity : `O(n)`
