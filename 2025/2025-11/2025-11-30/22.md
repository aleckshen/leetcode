This is a backtracking question that requires you to generate all possible combinations of `n` open and closed parentheses. We need to run a recursive dfs algorithm that generates these combinations. I started by thinking about what parameters I will need to pass into the dfs function. We know that we need a string variable that represents the current combination of parentheses and we also know need to keep track of the open and closed parentheses, we can use these three as the parameters. We know that a combination must consists of `n` open parentheses and `n` closed parentheses, therefore we can set out base case to append the combination string to our results variable when the open and closed variable are both equal to `n`.

For the logic of our solution we will have two if statements:
1. If the number of closed parentheses is lesser then `n` then we will run dfs on the current string combination with a new open bracket added and the open variable incremented by 1.
2. If the number of closed parentheses is lesser then `n` and the number closed parentheses is lesser then the number of open parentheses then we will run dfs on the current string combination with a new closed bracket added and the closed variable incremented by one.

The initial parameters that we will pass in will be a empty string and a integer 0 for both open and closed parentheses. After we run dfs on with these parameters we can return the results list.

```python
class Solution(object):
    def generateParenthesis(self, n):
        res = []

        def dfs(string, openn, closed):
            if openn == n == closed:
                res.append(string)
                return
            
            if openn < n:
                dfs(string + "(", openn + 1, closed)

            if closed < n and closed < openn:
                dfs(string + ")", openn, closed + 1)

        dfs("", 0, 0)
        return res
```

> Time Complexity : `O(4^n / sqrt(n))`
> 
> Space Complexity : `O(n)`
