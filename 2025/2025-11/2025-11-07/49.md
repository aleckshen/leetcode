To solve this problem we can iterate over each string in the input array `strs` and we can store each string in the hashmap with the key being the string sorted in lexicographical order and the value being the list of all strings with the same letters. This ensures that if two strings are anagrams they will be stored in the same letter frequency list.

Doing so will ensure a time complexity of O(n * k log k) where k log k is equal to the time it takes to sort a word and n is equal to the number of words in array `strs`.

```python
class Solution(object):
    def groupAnagrams(self, strs):
        anagrams = {}
        result = []

        for word in strs:
            sort = "".join(sorted(word))
            if sort in anagrams:
                anagrams[sort].append(word)
            else:
                anagrams[sort] = [word]

        for list in anagrams.values():
            result.append(list)

        return result
```

> Time Complexity : `O(n * k log k)`
> 
> Space Complexity : `O(nk)`
