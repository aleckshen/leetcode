My first instinct when looking at this question is to sort the string `t` and sort the string `s`. After doing so we can compare the two strings lexicographically and if they are equal we can return true else return false. After running this solution I noticed the time complexity wasn't efficient as a sorting algorithm would need to be applied to both string `s` and `t` and a for loop in order to compare every single element of the two strings. This would run in O(n log n) as pythons built in sorting function runs in O(n log n).

Too improve the time complexity of this solution we could iterate over each letter in each string and store them in separate hashmaps, where the key is equal to the string letter and the value is equal to the frequency of the letter. If we then compare the frequency of each letter and they match then string `s` must be a anagram of string `t`. With the improved solution we only need to iterate over each string `n` times where `n` is equal to the length of the each string. This gives us a improved time complexity of O(n).

```python
class Solution(object):
    def isAnagram(self, s, t):
        dic_s = {}
        dic_t = {}

        for letter in s:
            if letter in dic_s:
                dic_s[letter] += 1
            else:
                dic_s[letter] = 1

        for letter in t:
            if letter in dic_t:
                dic_t[letter] += 1
            else:
                dic_t[letter] = 1
                
        return dic_s == dic_t
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n + m)` where n + m == len(t) + len(s)
