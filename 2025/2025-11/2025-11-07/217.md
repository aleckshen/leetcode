To solve this problem we can iterate over each value in the array `nums` and check whether its in a hashmap that indicates if a number has appeared before or not. If it's the first time we see this value we add it to a hashmap and store the number as the key. The value itself doesn't matter in this situation as we only care about the value. If the number we iterate over is in the hashmap this means that the value has appeared more than once and we can return true. If we iterate through the whole array `nums` this means that no duplicate value was detected and we can return false. This gives us a overall time complexity of O(n) as we only need to iterate through the array `nums` n times in the worst case where n is equal to the size of the array.

```python
class Solution(object):
    def containsDuplicate(self, nums):
        seen = {}

        for num in nums:
            if num in seen:
                return True
            else:
                seen[num] = 0

        return False
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
