For this problem we need to iterate through each day in the `prices` array and find the maximum different between that number and any number to its right. The most intuitive way to do this is to used a nested for loop to check for all pairs and compute the difference and compare with a maximum profit variable that is initialized to zero at the start.

```python
class Solution(object):
    def maxProfit(self, prices):
        mx = 0

        for i in range(len(prices)):
            for j in range(i + 1, len(prices)):
                mx = max(mx, prices[j] - prices[i])

        return mx
```

However this runs in a time complexity of O(n^2) and given our constraints for this problem we will TLE if we use this approach. To optimize this approach we can use two pointers. Our left pointer will represent the day we bought stock and the right pointer will represent the day we sell stock. Note that we always want to buy stock when when the profit is the lowest to then sell when its higher to maximize as much profit as possible. We can update out left pointer to the index of the right pointer if the value at the right pointer is is lower than the value at the left pointer. We will continue to shift the right pointer and compute the max profit possible, the right pointer will shift while its lesser than the length of the input array. Once the right pointer reaches out of bounds we can return the max profit.

```python
class Solution(object):
    def maxProfit(self, prices):
        mx = 0
        l, r = 0, 1

        while r < len(prices):
            if prices[r] < prices[l]:
                l = r
            mx = max(mx, prices[r] - prices[l])
            r += 1

        return mx
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
