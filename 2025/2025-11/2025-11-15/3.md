Since we are dealing with substrings for this question we can go about it using the sliding window method. We can start by initializing a left pointer that starts at index 0, a length variable set to 0 that will represent the longest substring without repeating characters and a seen set that represents the string that are currently in the sliding window. We will iterate through the entire sub string and shift our right pointer to find characters that are not within the seen set. If the right pointer points to a variable that is not within the seen set we can add this value to the seen set and we can compute the max substring length by taking the difference of the two pointers and adding by one. If the right pointer points to a variable that is within the seen set we will increment out left pointer by one and remove that value from the seen set, this will ensure that no duplicate characters are taken into account. Once we reach the end of our for loop we can return the longest substring without repeating characters.

```python
class Solution(object):
    def lengthOfLongestSubstring(self, s):
        l = 0
        length = 0
        seen = set()

        for r in range(len(s)):
            while s[r] in seen:
                seen.remove(s[l])
                l += 1
            seen.add(s[r])
            length = max(length, r - l + 1)

        return length
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
