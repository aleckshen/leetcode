My first intuition when coming across this problem was to use a nested for loop to calculate the product for all numbers in the array `nums` that is not `nums[i]` and append them to a list to return the answer. However this runs in a time complexity of O(n^2) and the questions asks for a solution of O(n)

Not gonna lie this question had me stumped, couldn't really wrap my head around a solution that would run in O(n) time without using the division operator.

After digging around for some hints, I came across the idea of using a prefix array and a suffix array, where the prefix products of `nums[i]` multiplied by the suffix products of `nums[i]` would result in the product of all numbers except `nums[i]` itself. 

We can further optimize this by iterating through the input array `nums` and storing the prefix product values in the result array, then iterating through the input array `nums` backwards and multiplying the prefix product values with the current suffix product values to reduce the space complexity to O(1) as well.

```python
class Solution(object):
    def productExceptSelf(self, nums):
        result = [1] * len(nums)

        prefix = 1
        for i in range(len(nums)):
            result[i] = prefix
            prefix *= nums[i]

        suffix = 1
        for i in range(len(nums) - 1, -1, -1):
            result[i] *= suffix
            suffix *= nums[i]

        return result
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
