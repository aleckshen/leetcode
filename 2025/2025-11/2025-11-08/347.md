My first initial thought here is to iterate through each number in `nums` and store the frequency of each number in a hashmap. After doing this my thought is to figure out a way in which we can iterate through the key of this hashmap and be able to return the `k` most frequent elements. To achieve this we can sort by the frequencies of each number and iterate through the  frequencies as keys `k` many times and append the value of the key to a list for the answer. To do so we need to invert the current hashmap we have as the keys represent the numbers and the values represents the frequencies.

To do this we can create another hashmap that represents the initial hashmap but inverted. We can then iterate through this hashmap by the key `k` times and append the value to a results list.

After doing this I encountered a problem, if there were numbers that had the same frequency they would get overwritten by the next one as hashmaps cannot contain duplicate keys. To solve for this issue I decided to iterate over the initial hashmap I created, and append it to a list as `(frequency, value)` tuples. We can then sort this in lexicographical order and iterate through it backwards `k` times and append the value to a list to return the result.

This results in a time complexity of O(n log n) where n represents the length of the list `nums` and a space complexity of `m` where `m` represents the number of unique elements stored in my hashmap.

```python
class Solution(object):
    def topKFrequent(self, nums, k):
        dic = {}
        tuple_list = []
        result = []
        k_count = 0

        for num in nums:
            if num in dic:
                dic[num] += 1
            else:
                dic[num] = 1

        for value, freq in dic.items():
            tuple_list.append((freq, value))

        tuple_list.sort()
        
        for freq, value in tuple_list[::-1]:
            if k_count == k:
                break
            result.append(value)
            k_count += 1

        return result
```

> Time Complexity : `O(n log n)`
> 
> Space Complexity : `O(m)`
