For this question my thought was to create a deep copy of each node on the first iteration of the input linked list. We cannot set the pointers on the first iteration yet because if a nodes next or random pointer points to a node that has not been created yet we would run into a error. We can set the pointers of each deep copy nodes on the second iteration of the input linked list. A easy way to store the deep copy nodes is through the use of a hashmap, where each key and value pair is the input node and deep copy node. This allows us to set the pointers easily as we can just iterate through the input list using the current node as a key look up in the hashmap to retrieve the deep copy node. 

One possible edge case that we need to take into account for is if one of the deep copy nodes, next or random pointer points to null. We can easily fix this by adding a key and value pair in our hashmap, that maps from null to null.

```python
class Solution(object):
    def copyRandomList(self, head):
        oldToCopy = { None: None }

        curr = head
        while curr:
            copy = Node(curr.val)
            oldToCopy[curr] = copy
            curr = curr.next

        curr = head
        while curr:
            copy = oldToCopy[curr]
            copy.next = oldToCopy[curr.next]
            copy.random = oldToCopy[curr.random]
            curr = curr.next

        return oldToCopy[head]
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
