For this problem we need to remove the nth node from the end of the linked list. My first thought is to iterate through the linked list to keep track of a count that represents the size of the list. We can then subtract n from this variable to get the number that represents the position of the node we want to remove in the linked list. We can then iterate through the linked list while the the position variable is greater than 0 and decrement the position variable, once the position variable reaches 0 we will have reached the node we want to remove. We can store a reference to the previous node and set the previous nodes pointers to the current nodes next node. This will break the links between the current node we want to remove whilst also joining the node of its previous with its next. 

Some edge cases that I also need to take into account is if the current linked list is of size one, if this is the case we can just return none as the list will be empty. And the last edge case I need to take into account for is if the node we want to remove is the head of the linked list, if this is the case then we can just store a temporary variable the points to the heads next value, dereference the current heads next pointer by setting it to none and then return the next variable we stored as the new head.

```python
class Solution(object):
    def removeNthFromEnd(self, head, n):
        count = 0
        curr = head

        while curr:
            count += 1
            curr = curr.next

        if count == 1:
            return None

        curr = head
        node_count = count - n
        prev = None

        while node_count > 0:
            node_count -= 1
            prev = curr
            curr = curr.next

        if prev == None:
            nxt = head.next
            head.next = None
            return nxt
            
        prev.next = curr.next

        return head
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
