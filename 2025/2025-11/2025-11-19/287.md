The easiest way to solve this question was to create a sorted array and iterate through it and return the current number if it is equal to the next number. However this solution is O(n log n) as it requires sorting and the question also requires only constant extra space. I couldn't find a optimal way to do this so I had to search up the solution. Apparently the most optimal way is to use floyd's algorithm to detect a cycle in a linked list. Once we can identify the cycle in the linked list, then we can return the node that starts that cycle, which is the duplicate number. Essentially what the algorithm does is it uses slow and fast pointers, while the slow and fast pointers land on the same node we stop. We will then initialize another slow pointer and increment this new slow pointer on top of the previous slow pointer we initialized. Once these two slow pointers land on the same node we have reached the starting node of our cycle and we can return the node we are on.

```python
class Solution(object):
    def findDuplicate(self, nums):
        fast, slow = 0, 0

        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break

        slow2 = 0
        while True:
            slow = nums[slow]
            slow2 = nums[slow2]
            if slow == slow2:
                return slow
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
