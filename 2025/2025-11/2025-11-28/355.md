This question was my first time learning backtracking so my understanding of the problem may not be perfect. From my understanding backtracking explores different options (i.e different subset) and choices that lead until a dead end (base case). In our case we are trying to solve for all possible subsets of a array `nums`, we starts by creating a local dfs function that takes a index of a array as a parameter. We will call the dfs function on index 0, which represents the first element of the input array. We will make the choice of appending the element at index `i` to our subset array and the choice of not appending the element at index `i` to out subset array. We will recursively traverse through each possibility and once we reach our base case for every possibility we will append the subset array as a copy to our results list. 

```python
class Solution(object):
    def subsets(self, nums):
        res = []
        subset = []

        def dfs(i):
            if i >= len(nums):
                res.append(list(subset))
                return
            
            subset.append(nums[i])
            dfs(i + 1)

            subset.pop()
            dfs(i + 1)

        dfs(0)
        return res
```

> Time Complexity : `O(n * 2^n)`
> 
> Space Complexity : `O(n)`
