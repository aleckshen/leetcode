This question is basically the same question as kth largest element in a stream except the input is static. We can approach this question the same way and use a min heap of size `k`. We will first heapify the input array into a min heap. While the size of the min heap is greater then `k` we will pop the minimum element of the heap. Once we reach a heap of size `k` we can return the minimum element, which will be the kth largest element in the array.

```python
class Solution(object):
    def findKthLargest(self, nums, k):
        heapq.heapify(nums)

        while len(nums) > k:
            heapq.heappop(nums)

        return nums[0]
```

> Time Complexity : `O(n log k)`
> 
> Space Complexity : `O(n)`
