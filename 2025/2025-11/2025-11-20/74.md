This question requires you to search for a target number in a 2d matrix. The solution requires a time complexity of O(log(n * m)), this means that we need to implement our searching algorithm using binary search. First I created two pointers that represent the rows, while the left pointer is lesser than or equal to the right pointer the algorithm will run. Within this while loop I set another two pointers that represents the column values within the rows, I run a binary search algorithm using these two pointers to find the target value. If I find the target value I return true otherwise the target value isn't in this row, then we have 4 cases:
1. The target value is greater then the max value in the current row then the outer left pointer is equal to the outer middle index plus 1.
2. The target value is lesser then the minimum value in the current row then the outer right pointer is equal to the out middle index minus 1.
3. The target value does not exist then we return false.

If the outer left and right pointers converge past each other it means that the target value is either smaller than the smallest value within the 2D matrix or larger than the largest value within the 2D matrix and we also return false.

```python
class Solution(object):
    def searchMatrix(self, matrix, target):
        outLeft, outRight = 0, len(matrix) - 1

        while outLeft <= outRight:
            outMiddle = (outLeft + outRight) // 2
            row = matrix[outMiddle]

            l, r = 0, len(row) - 1
            while l <= r:
                mid = (r + l) // 2
                if target > row[mid]:
                    l = mid + 1
                elif target < row[mid]:
                    r = mid - 1
                else:
                    return True

            if target > row[-1]:
                outLeft = outMiddle + 1
            elif target < row[0]:
                outRight = outMiddle - 1
            else:
                return False

        return False
```

> Time Complexity : `O(log(n * m))`
> 
> Space Complexity : `O(1)`
