For binary search you want to search for a target number in array `nums`. We can search for this target number in O(log n) instead of a linear search that uses O(n) time complexity through the use of binary search. We will set two pointers, one left pointer representing the starting index, and one right pointer representing the last index. We will calculate the midpoint of the array by doing left pointer plus right pointer divided by two rounded down. After doing so there are 3 cases:
1. The target value is greater then the value at the midpoint of the array, we will shift the left pointer to be the middle index plus by one
2. The target value is lesser then the value at the midpoint of the array, we will shift the right pointer to be the middle index minus by one
3. The target value is equal to the value at the midpoint of the array, we will return the middle index.

This while loop will run while the left pointer is lesser than or equal to the right pointer, if the target value we are looking for is not within the list, the pointers will converge pass each other and we can return the value `-1`.

```python
class Solution(object):
    def search(self, nums, target):

        l, r = 0, len(nums) - 1

        while l <= r:
            mid = (r + l) // 2
            if target > nums[mid]:
                l = mid + 1
            elif target < nums[mid]:
                r = mid - 1
            else:
                return mid

        return -1 
```

> Time Complexity : `O(log n)`
> 
> Space Complexity : `O(1)`
