To solve this problem, we need to compute the height of the left and right subtrees for each node and compare the two values. A binary tree is considered unbalanced if, at any node, the absolute difference between the height of its left and right subtree is greater than 1.

To implement this, we use a global variable `isBalanced` that keeps track of whether the tree remains balanced as we traverse it. We then define a local dfs function that returns the height of each subtree. During each recursive call, we compute the heights of the left and right subtrees, compare them, and if the difference exceeds 1, we update `isBalanced` to False.

Once the dfs traversal completes, we return `isBalanced` to indicate whether the entire binary tree is height-balanced.

```python
class Solution(object):
    def isBalanced(self, root):
        self.isBalanced = True

        def dfs(node):
            if not node:
                return 0

            left = dfs(node.left) 
            right = dfs(node.right) 

            if abs(left - right) > 1:
                self.isBalanced = False
            
            return 1 + max(left, right)

        dfs(root)
        return self.isBalanced
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(h)`
