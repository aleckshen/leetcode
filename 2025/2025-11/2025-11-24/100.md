For this question we can recursively run dfs on the left and right subtrees of `p` and `q` and return true if both `p` and `q` are equal. We will first initialize a base case where if p and q are both `None` then we know that they are identical and we can return true. For the main body of the code we will check if both `p` and `q` are not `None`, if this is not true we will return false. Otherwise we will recursively call the `isSameTree` function on the left and right sub trees of each node and return true if the left and right sub trees are identical. Once we iterate through the entire tree `q` and `r` we will encounter both `None` type nodes for `p.left, q.left`and `p.right, q.right`, this is then handled by the base case and we will return true proving that both trees `q` and `r` are identical.

```python
class Solution(object):
    def isSameTree(self, p, q):
        if not p and not q:
            return True

        if p and q and p.val == q.val:
            left = self.isSameTree(p.left, q.left)
            right = self.isSameTree(p.right, q.right)
            return left and right 
        else:
            return False
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(h)`
