The problem asks us to determine whether a given binary tree `subRoot` is a subtree of another binary tree `root`. We can first start by handling edge cases where `subRoot` is `None`, in which case it's trivially a subtree of any tree. If `root` is `None` but `subRoot` is not, the answer is `False`. The main logic of this solution relies on recursively checking if the current tree rooted at root is identical to subRoot using the helper function `sameTree`. If they are identical, we return `True`. If not, we continue the search by recursively checking the left and right subtrees of root to see if either contains a subtree identical to `subRoot`. If either subtrees contain a identical tree to `subRoot`, the output will be `True`, else the output will be `False`.

```python
class Solution(object):
    def isSubtree(self, root, subRoot):
        if not subRoot:
            return True
        
        if not root:
            return False

        if self.sameTree(root, subRoot):
            return True

        left = self.isSubtree(root.left, subRoot)
        right = self.isSubtree(root.right, subRoot)
        return left or right

    def sameTree(self, p, q):
        if not p and not q:
            return True
            
        if p and q and p.val == q.val:
            left = self.sameTree(p.left, q.left)
            right = self.sameTree(p.right, q.right)
            return left and right
        else:
            return False
```

> Time Complexity : `O(n * m)`
> 
> Space Complexity : `O(n + m)`
