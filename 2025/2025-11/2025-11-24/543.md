One way to look at this question is to return the maximum depth of the left sub tree plus the maximum depth of the right subtree. After writing up the solution I encountered a slight error. The diameter of a binary tree is defined by the length of the longest path between any two nodes in the tree, but I was only considering the root node. I fixed up my implementation to recursively check for every single node in the graph. 

```python
class Solution(object):
    def diameterOfBinaryTree(self, root):
        if not root:
            return 0

        diameter = self.maxHeight(root.left) + self.maxHeight(root.right)
        return max(diameter, self.diameterOfBinaryTree(root.left), self.diameterOfBinaryTree(root.right))

    def maxHeight(self, root):
        if not root:
            return 0

        left = self.maxHeight(root.left)
        right = self.maxHeight(root.right)

        return 1 + max(left, right)
```

However this solution is very slow as it requires you to run the maxHeight function at every single node in the binary tree. Since the maxHeight function is O(n), then then `diameterOfBinaryTree` function would be O(n^2). To optimize this, we can compute the height and diameter simultaneously in a single dfs traversal. We introduce a global variable `res` to store the maximum diameter found so far, and define an inner dfs function that returns the height of each subtree. As dfs computes the height for each node, it also updates `res` with the diameter passing through that node `(left_height + right_height)`. This eliminates redundant work and reduces the time complexity to O(n). 

```python
class Solution(object):
    def diameterOfBinaryTree(self, root):
        self.res = 0

        def dfs(node):
            if not node:
                return 0

            left = dfs(node.left)
            right = dfs(node.right)

            self.res = max(self.res, left + right)
            return 1 + max(left, right)

        dfs(root)
        return self.res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(h)`
