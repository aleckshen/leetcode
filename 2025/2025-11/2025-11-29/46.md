For this question, we need to find all permutations of the input array `nums`. Since this is about permutations not combinations, we must avoid reusing the same index within a single permutation. To do this, we use a visited set that keeps track of which indexes have already been added to the current permutation.

To try every possible value, we loop over all indexes in `nums`. For each index, we check whether it’s in the visited set. If it is, we skip it; otherwise, we add `nums[i]` to the current permutation and mark the index as visited.

Then we recursively call dfs to continue building the permutation. After the recursive call finishes, we backtrack by popping the last element from the permutation and removing its index from the visited set. This allows us to explore other permutations.

```python
class Solution(object):
    def permute(self, nums):
        res = []
        permutation = []
        visited = set()

        def dfs():
            if len(permutation) == len(nums):
                res.append(list(permutation))
                return

            for i in range(len(nums)):
                if i in visited:
                    continue
                visited.add(i)
                permutation.append(nums[i])

                dfs()

                permutation.pop()
                visited.remove(i)

        dfs()
        return res
```

> Time Complexity : `O(n! * n)`
> 
> Space Complexity : `O(n! * n)`
