I initially drew out the decision tree for this problem where any number is allowed to be repeated. However I quickly came to the realization that duplicate sums would be encountered. I tried to implement a way so that after appending a element with index `i` to the sum array, the elements from the index before that would be appended to the array representing the sum. I couldn't really figure out a way around it so I ended up checking the solution instead. 

The solution creates a local dfs function that takes a index, array and total sum parameter. There will be two following base cases:
1. if the target sum is found then we will append a copy of the current array to the results array and return.
2. If the index goes out of bound or the total sum is greater than the sum then we will stop and return. 

The rest of the code handles the backtracking recursion. After we append the current candidate and make the recursive call to explore all possibilities that continue using this same number, we then backtrack by removing the last appended element. This “undo” step is crucial because it restores the current combination to the state it was in before trying that candidate. After backtracking, we make a second recursive call, this time moving to the next index `(i + 1)`. This represents the choice of not using the current candidate anymore. By always either staying on the same index (to reuse the number) or moving forward (to permanently skip it), the algorithm ensures that combinations are built in non-decreasing index order, which prevents duplicate sets from appearing. 

```python
class Solution(object):
    def combinationSum(self, candidates, target):
        res = []

        def dfs(i, current, total):
            if total == target:
                res.append(list(current))
                return

            if i >= len(candidates) or total > target:
                return

            current.append(candidates[i])
            dfs(i, current, total + candidates[i])

            current.pop()
            dfs(i + 1, current, total)

        dfs(0, [], 0)
        return res
```

> Time Complexity : `O(2 * t/m)`
> 
> Space Complexity : `O(t/m)`
