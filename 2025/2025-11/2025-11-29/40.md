This question is a continuation of the original problem combination sum. The tricky part for this question is that we cannot reuse elements to form the target value. For example given the input array `[1,1,2,3]` and the target value of `4`, [1,1,1,1] would not be a possible combination. Also note that in combination sum 2, our input values are not distinct. Therefore we also need to eliminate duplicate sums that could appear from duplicate input values. One way we can solve this is to sort the input array. 

We can append values to our total sum array while recursively running dfs on the next index, this ensures that the same value cannot be reused for a combination. Next to take into account duplicate combinations from duplicate values we can use a while loop. This loop will run while the number at `candidates[i] == candidates[i + 1]`, while this is true and the index `i + 1` is in bounds we will increment i. Note that we originally sorted our input array, this was to ensure that duplicate values would be adjacent to each other. Essentially this while loop increments the index `i` until a non duplicate value is found, this will make sure that no duplicate combinations are formed.

This takes care of all the logic for our recursion and we can just append the combination list to the results list when the total sum of the combination list is equal to the target value.

```python
class Solution(object):
    def combinationSum2(self, candidates, target):
        res = []
        candidates.sort()

        def dfs(i, current, total):
            print(current)
            if total == target:
                res.append(list(current))
                return

            if i >= len(candidates) or total > target:
                return 

            current.append(candidates[i])
            dfs(i + 1, current, total + candidates[i])

            current.pop()
            while i + 1 < len(candidates)  and candidates[i] == candidates[i + 1]:
                i += 1

            dfs(i + 1, current, total)

        dfs(0, [], 0)
        return res
```

> Time Complexity : `O(n * 2^n)`
> 
> Space Complexity : `O(n)`
