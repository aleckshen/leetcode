My first thought is to sort the input list `nums`. After sorting the input we will iterate through the input list `nums`. With each iteration we will fix the number we are currently iterating through and set two pointers. The left pointer is equal to the fixed num plus one and the right pointer is equal to the last index of the input list. we will run the same algorithm implemented in two sum part 2 to find values that sum together with the fixed number to equal to 0. If this is true we will append these values to a list and store that very list in a results list. Also note that for all cases if the left pointer lands on a value that has already been checked before we will shift until it reaches a number that hasn't been checked, this will allow no duplicate values in our results array.

```python
class Solution(object):
    def threeSum(self, nums):
        nums.sort()
        res = []

        for i, x in enumerate(nums):
            if i > 0 and nums[i - 1] == x:
                continue

            l, r = i + 1, len(nums) - 1
            while l < r:
                threeSum = x + nums[l] + nums[r]
                if threeSum > 0:
                    r -= 1
                elif threeSum < 0:
                    l += 1
                else:
                    res.append([x, nums[l], nums[r]])
                    l += 1
                    while nums[l] == nums[l - 1] and l < r:
                        l += 1
            
        return res
```

> Time Complexity : `O(n^2)`
> 
> Space Complexity : `O(1)`
