For this question we can use two pointers. The left pointer will be initialized as the starting index of the input array and the right pointer will be initialized as the last index of the input array. We wil also initialize a max value of 0. We will then create a while loop that runs while these two pointers do not converge. We can compute the max area currently by taking the minimum value between the two left pointers and multiplying it by the right pointers index minus the left pointers index. we will compare this with the max value we initialized, if it is greater than it then we will record the current area computed as the new max value. After doing this we need to update our pointers, if the value the left pointer is pointed to is bigger than the value the right pointer is pointed to then we will decrement the right pointer by one, otherwise we will increment the left pointer by one. After the two pointers converge we can return the max value computed.

```python
class Solution(object):
    def maxArea(self, height):
        mx = 0
        l, r = 0, len(height) - 1

        while l < r:
            if height[l] <= height[r]:
                mx = max(mx, height[l] * (r - l))
            else:
                mx = max(mx, height[r] * (r - l))

            if height[l] > height[r]:
                r -= 1
            else:
                l += 1

        return mx
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
