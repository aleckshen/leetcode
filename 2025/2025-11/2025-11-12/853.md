The most important thing I noticed when looking at this problem was the fact that cars travel in singular lanes, this means that cars behind cannot overtake cars in front. We can first sort the input array by distance in increasing order by position and speed pairs. This allows us to iterate through each pair and take into account if cars reach the same velocity or not. We also know that cars have different velocity, however if a car reaches the same speed of the car in front, then the velocity is reduced to the car in front. Taking this into account we can iterate through the sorted input array in reverse. We do this because if we iterated through the array normally we would encounter incorrect calculations for the time it takes for a car to reach its target value. This is due to the fact that when we detect the collision of a car, we would carry on assuming that it would travel to the target mile in the current speed it's at, however this is not true as the speed has to be reduced to the car in front.

To start coding up this problem we can first initialize a stack. We will sort the input array by positions and store tuples in the array as position, velocity pairs. We will iterate through this array in reverse by pairs and check if the time of the car at the second highest point in the stack has a lower time then the time of the car just appended. If this is true we have a collision and we can pop the car at the top of the stack off to treat it as one fleet. If this is not the case we continue as usual, at the end the remaining elements in the stack will represent the number of car fleets that arrive at the destination.

```python
class Solution(object):
    def carFleet(self, target, position, speed):
        pairs = [(p, s) for p, s in zip(position, speed)]
        pairs.sort(reverse=True)
        stack = []

        for p, s in pairs:
            stack.append((target - p) / float(s))
            if len(stack) >= 2 and stack[-1] <= stack[-2]:
                stack.pop()

        return len(stack)
```

> Time Complexity : `O(n log n)`
> 
> Space Complexity : `O(n)`
