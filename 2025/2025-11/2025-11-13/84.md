When we look at this problem the first instinct is to understand cases in which we can extends the width of rectangles to search for more area in a histogram. 
1. If the height that is currently being iterated over has a height greater than the next height, the width of this rectangle cannot be extended to the right.
2. If the height that is currently being iterated over has a height lesser than the next height, the width of this rectangle can be extended to the right
3. If the height that is currently being iterated over has a height that is equal to the next height, the width of this rectangle can be extended to the right.

Notice that the extension of a rectangles width will depends on the right most height in a histogram. We will use a stack here, where the values of the stack represent a index and height pair. We will continue to push items to out stack while the height of the right rectangle is greater then the current, if its smaller we cannot extends our rectangle to the right so we compute the maximum area possible and pop it from the stack.

After iterating through the height array we will still have values within our stack that are not popped (values that continue extending to the end of the stack), we can compute the areas of these heights by taking length of the height array subtracted by the starting index of the height then multiply by height of the current rectangle to compute the largest area for that height.

```python
class Solution(object):
    def largestRectangleArea(self, heights):
        stack = [] # (index, height) pairs
        mx = 0

        for i, h in enumerate(heights):
            start = i
            while stack and stack[-1][1] > h:
                index, height = stack.pop()
                mx = max(mx, height * (i - index))
                start = index
            stack.append((start, h))

        for i, h in stack:
            mx = max(mx, h * (len(heights) - i))

        return mx
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
