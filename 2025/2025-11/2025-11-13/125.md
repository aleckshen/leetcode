My first thought is to iterate over string, `s` and check if each character is a number, a letter or non-alphanumeric. We will initialize a empty string that represents the string `s` with all letters in lowercase and no strings other than alphanumeric strings. Upon each character we iterate over we can add it to the string if its alphanumeric otherwise we skip that string. After doing so we iterate through the string and check if its the same backwards and forwards.

```python
class Solution(object):
    def isPalindrome(self, s):
        alphaNum = ""

        for ch in s:
            if ch.isdigit():
                alphaNum += ch
            elif ch.isalpha():
                alphaNum += ch.lower()
            else:
                continue

        return alphaNum == alphaNum[::-1]
```

However this solution is not optimal as we have to iterate over the string `s` twice roughly and also use extra storage to store the new alpha-numeric string. To optimize this we can use two pointers. We will increment the left pointer by 1 until it reaches a alpha-numeric value and decrement the right pointer until it reaches a alpha-numeric value. We will then compare these two values, if its not equal we return false, otherwise we increment the left pointer by 1 and decrement the right pointer by 1. We will do this while the left pointer is lesser than the right pointer, once the two pointers converge we will have successfully identified that the string `s` is a palindrome and we can return true.

```python
class Solution(object):
    def isPalindrome(self, s):
        l, r = 0, len(s) - 1

        while l < r:
            while l < r and not self.alphaNum(s[l]):
                l += 1
            while l < r and not self.alphaNum(s[r]):
                r -= 1
            if s[l].lower() != s[r].lower():
                return False
            l += 1
            r -= 1

        return True

    def alphaNum(self, ch):
        return (ord('A') <= ord(ch) <= ord('Z') or
                ord('a') <= ord(ch) <= ord('z') or
                ord('0') <= ord(ch) <= ord('9'))
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
