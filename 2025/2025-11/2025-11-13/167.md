We know the input list here is sorted so we can use two pointers. Set the left pointer to the left most index and the right pointer to the right most index. We will have a while loop with the condition `l < r`, while this condition is true we check if the two numbers at index `l` and index `r` add together to the target value. If it does we return the index `l` and `r`, else if the value is larger then the target number we decrement `r` else if the value us lesser than the target number we increment `l`. Since there always exist exactly one solution and the input list is sorted, the two values that sum up to the target value will be found before the pointers converge.

```python
class Solution(object):
    def twoSum(self, numbers, target):
        l, r = 0, len(numbers) - 1

        while l < r:
            if numbers[l] + numbers[r] < target:
                l += 1
            elif numbers[l] + numbers[r] > target:
                r -= 1
            else:
                return [l + 1, r + 1]

        return []
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(1)`
