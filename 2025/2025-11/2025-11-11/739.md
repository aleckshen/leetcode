For this question the intuitive approach is to iterate over all temperatures and have a nested for loop that checks if each following temperature is greater then the current. If the temperature is not warmer we increment a counter variable by one and continue iterating over the following temperatures, otherwise if the temperature is warmer we increment the counter variable by one and append it to a results array. We can reset the counter variable to 0 and iterate through the next temperature on the outer loop. However this runs in O(n^2) and is not optimal.

After looking at some hints I found a solution through the use of a monotonic decreasing stack. Each value in the stack will represent a tuple containing the temperature value and the index of that temperature value. We will initialize a result array to be the same size as the input array `temperatures` and zero fill each element. By zero filling the elements of the resulting array we wont have to worry about adding 0 to the resulting array for the temperatures that do not have a day until a warmer temperature appears. We will then iterate through the array `temperatures` by `temp` and `index`. Upon each iteration we will check if the current temperature value is greater than the value at the top of the stack. If it is, then we pop the element at the top of the stack. Using the index of the element we just popped we can calculate the amount of days until it reached a warmer temperature by subtracting that index from the current index we are at and storing that value to the results array.

```python
class Solution(object):
    def dailyTemperatures(self, temperatures):
        res = [0] * len(temperatures)
        stack = []

        for i, t in enumerate(temperatures):
            while stack and t > stack[-1][0]:
                stackTemp, stackIdx = stack.pop()
                res[stackIdx] = i - stackIdx
            stack.append((t, i))

        return res
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
