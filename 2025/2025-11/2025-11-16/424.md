This question I found not so intuitive, it was pretty hard to wrap my head around so I ended up looking at the solution. The most intuitive way to solve this problem was to use the sliding window method. We would first initialize a hashmap the stores the count of every single string and also a variable longest that stores the longest repeating character without replacement. We will start by setting a left and right pointer to 0. We know that the window we are currently in is valid if the window size minus the maximum character count within the window is lesser then or equal to the number of replacement operations. If the current window is valid we can compute the longest repeating character by taking the difference of the right and left pointer added by 1, we then compare this value with the longest variable we initialize previously. If the window isn't valid then we can minus the count of the character the left pointer is point at and shift the left pointer by one until we find a window that is valid. After the right pointer reaches the end we can return the longest variable which will represent the longest repeating character with k replacements.

```python
class Solution(object):
    def characterReplacement(self, s, k):
        count = {}
        longest = 0

        l = 0
        for r in range(len(s)):
            count[s[r]] = 1 + count.get(s[r], 0)

            while (r - l + 1) - max(count.values()) > k:
                count[s[l]] -= 1
                l += 1

            longest = max(longest, r - l + 1)

        return longest
```

> Time Complexity : `O(n * 26)`
> 
> Space Complexity : `O(26)`
