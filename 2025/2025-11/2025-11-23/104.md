To compute the maximum depth of a binary tree, we recursively compute the depths of the left and right subtrees. Each recursive call returns the depth of its subtree, and we add 1 to account for the current node. The maximum of the two subtree depths is then returned as the depth of the current node. Once the recursion completes, the final result represents the maximum depth (or height) of the entire binary tree.

```python
class Solution(object):
    def maxDepth(self, root):
        if not root:
            return 0

        left = self.maxDepth(root.left) 
        right = self.maxDepth(root.right) 
        
        return 1 + max(left, right)
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(h)`
