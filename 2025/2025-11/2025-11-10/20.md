We know a string `s` only contains the 3 types of parentheses, `(`, `{` and `[`. We can iterate over string `s` and check if the current character is one of the three types of parentheses. If the current character is a opening parentheses we can push it to a stack, else if the current element is a closing parentheses we check the top of the stack to see if it matches the corresponding bracket. If it corresponds to the current character we pop the top of the stack and continue, otherwise we return false. If we iterate through the string `s` without returning false and the stack is empty then we can return true.

```python
class Solution(object):
    def isValid(self, s):
        stack = []
        closeToOpen = {")": "(", "}": "{", "]": "["}

        for bracket in s:
            if bracket in closeToOpen:
                if stack and stack[-1] == closeToOpen[bracket]:
                    stack.pop()
                else:
                    return False
            else:
                stack.append(bracket)

        if stack:
            return False
        return True
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
