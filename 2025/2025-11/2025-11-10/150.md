Looking at the example outputs and explanations I was able to grasp a better understanding of this problem. Firstly, we will iterate through the array of strings `tokens`. When we encounter a integer value, we can push it onto a stack. When we encounter a operand we we will pop the top value in the stack, let this value be `operand1`, we then pop the top value in the stack again, let this value be `operand2`. We will then use the current operator we are iterating over to perform the following calculation: `operand2 operator operand1`, where operator is one of the following options: `+, -, //, *`. We will perform this calculation and push the value onto the current stack. After iterating through the array `tokens` we will have evaluated the arithmetic expression written in reverse polish notation and we can pop the result from the stack and return it.

```python
class Solution(object):
    def evalRPN(self, tokens):
        stack = []

        for token in tokens:
            if token == "+":
                stack.append(stack.pop() + stack.pop())
            elif token == "*":
                stack.append(stack.pop() * stack.pop())
            elif token == "-":
                operand1 = stack.pop()
                operand2 = stack.pop()
                stack.append(operand2 - operand1)
            elif token == "/":
                operand1 = stack.pop()
                operand2 = stack.pop()
                stack.append(int(float(operand2) / operand1))
            else:
                stack.append(int(token))

        return stack.pop()
```

> Time Complexity : `O(n)`
> 
> Space Complexity : `O(n)`
