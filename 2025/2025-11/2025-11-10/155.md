For this question the tricky part is to be able to implement the `getMin()` method that retrieves the minimum element of the stack. The rest of the operations for the `MinStack` class are pretty intuitive. One way we can implement the `getMin()` method is to initialize two stacks for the `MinStack` class. One stack will represent the minimum values being pushed, and the other stack will represent all the values that are pushed. Upon every push of the stack we check the value in the top of the stack representing the minimum values with the current value being pushed. If the current value being pushed is smaller or equal, we push to the minimum stack and push to the regular stack. If the current value being pushed is larger than the value at the top of the minimum stack we just push to the regular stack like normal. When we pop from the stack we check if the current value popped is equal to the value at the top of the minimum stack, if it is we pop from both stacks, otherwise we only pop from the normal stack.

This will ensure that the `getMin()` method will run in O(1) time as the minimum element will always appear at the top of the minimum stack.

```python
class MinStack(object):

    def __init__(self):
        self.stack = []
        self.minimum = []

    def push(self, val):
        if not self.minimum or val < self.minimum[-1] or val == self.minimum[-1]:
            self.minimum.append(val)
        self.stack.append(val)

    def pop(self):
        if self.stack:
            if self.stack[-1] == self.minimum[-1]:
                self.minimum.pop()
            self.stack.pop()
        
    def top(self):
        if self.stack:
            return self.stack[-1]
        
    def getMin(self):
        if self.minimum:
            return self.minimum[-1]
```

> Time Complexity : `O(1)`
> 
> Space Complexity : `O(n)`
