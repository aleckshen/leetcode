Notice that this question requires you to always look at the two maximum stones within the array `stones`. While the two max values are equal, you remove both stones from the array. If both values are different then you remove the heavier stone and change the weight of the less heavier stone to `x - y` where `x` represents the heavier stone and `y` represents the less heavier stone. 

My first intuition was to use a array for this question and sort it, but then I realized when stones `x` and `y` differ in value the weight of stone `y` would change and we would need to resort the array. This would be O(n log n) for every time we changed a stones weight. To resort the array in a faster time we could approach this question using a max heap. We will check the two heaviest stones from the top of the max heap while the length of the heap is greater than 1. We will check the conditions and run the necessary operations. 

This time when the weight of a stone changes we can heapify our heap to reorder it which only requires O(log n) time complexity. This will reduce our time complexity from O(n^2 log n) to O(n log n).

```python
class Solution(object):
    def lastStoneWeight(self, stones):
        stones = [-s for s in stones]
        heapq.heapify(stones)
        
        while len(stones) > 1:
            heaviest = heapq.heappop(stones)
            if heaviest == stones[0]:
                heapq.heappop(stones)
                continue

            heapq.heappush(stones, heaviest - heapq.heappop(stones))
 
        if not stones:
            return 0
        
        return -stones[0]
```

> Time Complexity : `O(n log n)`
> 
> Space Complexity : `O(n)`
